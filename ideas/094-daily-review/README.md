# 094 · 하루 회고 자동 프롬프트 (Daily Review)

## 개요
매일 저녁 6~10시 사이 사용자에게 짧은 회고 질문을 보내고, Claude가 이전 답변을 기억해 점진적으로 맞춤화된 프롬프트를 던지는 SaaS. "쓸 게 없는 일기"의 진입장벽을 없앤다.

## 문제
- 일기/회고를 시작해도 "오늘 뭐 적지"에서 막힘
- 매일 같은 질문은 지루함, 매번 새 질문은 일관성 없음
- 1년치 회고가 쌓여도 검색·인사이트 추출이 어려움

## 솔루션
- 사용자의 어제 답변·주간 키워드를 컨텍스트로 Claude가 오늘의 질문 3개 생성
- 이메일/카톡/PWA 푸시로 전달
- 답변은 자동 태깅·감정 분석
- 주간/월간 회고는 자동 요약 (Claude)

## 타겟 사용자
- 자기 성찰을 습관화하려는 지식 노동자
- 일기 작가 (꾸준함이 어려운 사람)
- 코치/심리상담 받는 사람의 보조 도구

## 핵심 기능
1. **맞춤 프롬프트** — 어제·일주일 답변 컨텍스트로 Claude가 3개 생성
2. **다채널 알림** — 이메일, 카카오 알림톡, PWA 푸시
3. **감정 추적** — 답변에서 감정 키워드 추출, 트렌드 시각화
4. **주간 회고** — 일요일에 7일치 요약 + 다음 주 의도 제안
5. **검색** — 풀텍스트 + 감정/태그 필터

## 수익 모델
| 플랜 | 가격 | 기능 |
|---|---|---|
| Free | $0 | 일 1회, 주간 요약 없음 |
| Pro | $5/월 | 맞춤 프롬프트 + 주간 요약 + 감정 차트 |
| Coach | $19/월 | 코치가 답변을 읽고 코멘트 |

## 경쟁사
- Daylio, Reflectly, Stoic, Day One, Journey

## 차별점
- AI가 "오늘 뭘 물어볼지" 결정 — 사용자의 인지 부하 0
- 이메일/카톡 인입 — 앱 진입 마찰 제거
- 한국어 일기 도구로 차별화 (Stoic 등은 영어 중심)
- Coach 플랜으로 1:1 상담 매칭

## KPI
- 일일 답변율 60% 이상
- 사용자 평균 연속 작성 일수 14일
- Free → Pro 전환율 7%
- 주간 회고 열람율 80%
- 30일 잔존율 55%

## 마일스톤
- M1 (W1-2): PWA + 이메일 인입 + Claude 프롬프트 생성
- M2 (W3-4): 카카오 알림톡 채널 + 답변 저장 + 감정 추출
- M3 (W5-6): 주간 요약 + 트렌드 차트 + Stripe/토스 결제
- M4 (W7-8): pgvector 유사 회고 검색 + 검색 UI
- M5 (W9-10): Coach 매칭 + 댓글/피드백 기능

## 리스크와 가정
- 가정: 한국 사용자는 카카오 알림톡 채널로 접근성을 크게 높일 수 있다
- 리스크: 알림 피로감 → 응답 패턴 학습으로 시각/빈도 자동 조정
- 리스크: 일기 데이터의 민감성 → end-to-end 암호화 옵션 검토
