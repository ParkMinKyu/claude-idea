# 018 · 호스팅형 체인지로그/공지 페이지

## 개요
제품 업데이트를 마크다운으로 작성하면 자동으로 SEO 최적화된 체인지로그 페이지, RSS 피드, 이메일 다이제스트를 생성해 주는 서비스.

## 문제
- GitHub Releases는 비개발자에게 가독성이 떨어지고 SEO·구독 기능이 빈약하다.
- 직접 Next.js 블로그를 만들면 글 발행 흐름·이메일 발송·구독자 관리까지 떠안게 된다.
- 마케팅 팀이 개발자 없이 글을 발행할 채널이 필요하다.

## 솔루션
- MDX 에디터로 작성 → 자동 게시 → RSS / JSON Feed / 이메일 발송
- 카테고리 태그(Improvement / Fix / Feature)와 이모지 배지
- 도메인 연결: `changelog.{customer}.com`
- 임베드 위젯: 사이트 헤더에 "What's new" 알림 점 표시

## 타겟 사용자
- B2B SaaS 마케팅·프로덕트 팀
- 오픈소스 프로젝트 (자체 도메인 chgl 호스팅)
- 인디 해커 (작은 변경도 마케팅화)

## 핵심 기능
1. **MDX 에디터** — 실시간 미리보기, 이미지 드래그 업로드
2. **이메일 다이제스트** — 구독자 대상 주간/즉시 발송
3. **RSS / JSON Feed** — 자동 생성, 카테고리 필터링
4. **임베드 위젯** — 미열람 카운트가 표시되는 종 아이콘
5. **커스텀 도메인 + SEO** — sitemap.xml, OG 이미지 자동 생성

## 경쟁사
- Headway, Canny Changelog, Beamer, AnnounceKit, Featurebase

## 차별점
- MDX 기반(JSX 컴포넌트 임베드 가능) — Headway/Beamer는 WYSIWYG만
- 임베드 위젯·이메일·RSS가 모든 플랜에 포함
- 한국어 SEO 메타데이터 자동 최적화
- API 우선 설계 — `POST /v1/releases` 한 줄로 CI에서 게시

## KPI
- 페이지 LCP < 1.2s (SEO 트래픽 핵심)
- 첫 글 발행까지 평균 시간 < 5분
- 이메일 다이제스트 오픈율 35%+
- 임베드 위젯 클릭률 8%+
- 30일 잔존율 70%+
