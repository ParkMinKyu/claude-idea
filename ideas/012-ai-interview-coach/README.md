# 012 - 모의 면접 피드백

## 개요
회사/직무를 선택하면 Claude가 맞춤 질문을 던지고, 사용자의 답변을 STAR 구조·핵심 메시지·답변 길이 측면에서 분석해 즉각 피드백을 제공하는 모의 면접 SaaS.

## 문제
- 모의 면접은 사람 친구/멘토 시간 필요 → 횟수 제한
- 본인 답변의 약점을 객관적으로 파악하기 어려움
- 회사/직무별 자주 묻는 질문을 모르고 응답 준비

## 솔루션
- 회사명 + JD 입력 → Claude가 예상 질문 10~20개 생성
- 사용자가 텍스트/음성으로 답변 입력
- 답변별 즉시 피드백 (STAR 구조 점수, 강점/약점, 모범 답안)
- 누적 진도 + 약점 영역 자동 추적

## 타겟 사용자
- 이직 준비 직장인 (1~10년차 핵심)
- 신입 취준생 (자소서/면접 통합 부담)
- MBA/대학원 지원자 (영문 면접)
- 임원 후보 (executive coaching 대체)

## 핵심 기능
1. 회사/직무 기반 예상 질문 생성
2. 답변 분석 (STAR 구조, 길이, 키워드)
3. 모범 답안 생성 (사용자 경험 기반 가이드)
4. 약점 영역 누적 추적
5. (Pro) 영문 면접 + 임원 면접 모드

## 수익 모델
| 티어 | 가격 | 한도 |
|------|------|------|
| Free | $0 | 일 5문항 |
| Plus | $19/월 | 무제한, 약점 추적 |
| Pro | $39/월 | 영문, 임원 모드, 음성 분석 |
| 1회 결제 | $9/세션 | 면접 직전 사용자 |

## 경쟁사
- Final Round AI: 미국 중심, 실시간 면접 도움 (논란)
- Interviewing.io: 사람 면접관, 비쌈
- Pramp: 사람 매칭, 무료지만 시간 제약
- 국내 자소설닷컴 등: 자소서 첨삭 중심

## 차별점
- 한국 회사(삼성/네이버/카카오/배민 등) 면접 패턴 학습
- 답변 즉시 피드백 (사람 면접관도 못 함)
- 약점 영역 누적 추적으로 데이터 기반 학습
- 1회 결제 옵션으로 면접 직전 진입 사용자 흡수

## 핵심 지표 (KPI)
- 가입 → 첫 답변 작성 전환
- 사용자당 평균 답변 수
- Free → Plus 전환율 (목표 10%, 절박감 큼)
- 사용자 보고 면접 합격률
- NPS (구직 사이클 짧음 → 추천 영향 큼)
- 1회 결제 비중

## 향후 로드맵
- M1: 질문 생성 + 답변 피드백 (MVP)
- M2: 약점 영역 누적 추적
- M3: 음성 답변 + 길이/속도 분석
- M4: 영문 면접 + 임원 면접 모드

## 리스크와 대응
- 면접 합격 보장 불가 → "합격 보장 X" 명시 + 사용자 자가 점수
- 사용자 답변 데이터 민감 → 옵트인 보관
- 회사별 면접 패턴 변화 → 사용자 피드백으로 시스템 프롬프트 분기 업데이트
