# 083 - 픽업 전용 주문 SaaS

## 개요
배달 없이 "픽업"에만 최적화된 식당 주문 서비스입니다. 손님이 모바일에서 메뉴를 골라 결제하면, 식당은 준비 시간만 입력하고 SMS로 "픽업 준비 완료" 알림을 자동 발송합니다. 배달앱 수수료를 회피하려는 동네 식당 타겟.

## 문제
- 배민/요기요 수수료가 매출의 15~20% — 동네 식당에 과도한 부담
- 픽업만 받는 카페/베이커리/도시락 식당은 배달 인프라가 불필요
- 전화 주문은 실수와 인력 부담이 큼
- 손님은 도착 후 대기 시간이 불확실

## 솔루션
- 식당이 메뉴/가격/픽업 가능 시간대 등록
- 손님은 QR/링크로 모바일 메뉴 접근 → Stripe 결제
- 식당 태블릿에 주문 알림, "준비 중 → 완료" 버튼
- "완료" 누르면 Twilio로 손님에게 SMS 자동 발송

## 타겟 사용자
- 픽업 매출이 30% 이상인 카페/베이커리/김밥집/도시락
- 배달앱 수수료에 부담을 느끼는 동네 자영업자
- 푸드트럭, 팝업 스토어

## 핵심 기능
1. 메뉴 CRUD + 옵션/품절 관리
2. QR 코드 생성 (식당별 고유 URL)
3. Stripe Checkout 결제 (카드/Apple Pay)
4. 식당 대시보드 (주문 큐, 예상 완료시간)
5. Twilio SMS 알림 ("픽업 준비 완료")
6. 매출 리포트 (일/주/월)

## 수익 모델
| 티어 | 가격 | 거래 수수료 |
|------|------|------|
| Starter | $0 | 거래당 3% (+ Stripe + Twilio 패스스루) |
| Growth | $29/월 | 거래당 1% (월 거래 100건 이상 유리) |
| Pro | $79/월 | 0%, 다점포, 충성고객 프로그램 |

추가: 광고 없음, 손님 데이터 식당이 100% 소유.

## 경쟁사
- 배민/요기요: 수수료 부담
- 캐치테이블: 예약 중심, 결제 약함
- Square Online: 글로벌, 한국 가맹점 어려움
- Toast: 미국 POS 강자

## 차별점
- "픽업 only" 단순 워크플로 (배달 옵션 없음)
- 한국어 SMS + 카드 결제 — 5분 셋업
- 식당 수수료가 배달앱의 1/5 수준
- 손님이 앱 설치 불필요 — 웹만으로 완결

## 핵심 지표 (KPI)
- 활성 식당 수 (월 50건 이상 주문)
- 평균 주문 단가
- 식당당 월간 주문 수 (목표 200건)
- 첫 주문 → 재주문률 (목표 40% 이상)
- SMS 알림 도달률 (목표 99% 이상)
- 식당 30일 retention (목표 85% 이상)
