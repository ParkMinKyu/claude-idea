# 021 · 대기자 명단 + 추천 부스트

## 개요
출시 전 제품의 대기자 명단을 운영하면서, 친구를 초대할 때마다 순번이 앞당겨지는 바이럴 메커니즘을 결합한 SaaS.

## 문제
- 대기자 명단을 직접 만들면 추천 트래킹·이메일 발송·랭킹 표시까지 구현해야 한다.
- Mailchimp 폼은 추천 부스트 기능이 없다.
- 출시 전 모멘텀을 만들려면 Robinhood식 "순번이 위로 올라가는" 게임화가 필요하다.

## 솔루션
- 한 줄 임베드 폼 → 가입 시 고유 추천 코드 발급
- 추천 1명 = 10단계 상승, 친구가 가입할수록 순번 상승 알림
- 임계값 도달 시 자동 베타 초대 발송
- 관리자 대시보드에서 현재 줄, 추천 그래프, A/B 카피 테스트

## 타겟 사용자
- 출시 전 SaaS 인디 해커
- 하드웨어/소비재 크라우드펀딩 팀
- 콘퍼런스/뉴스레터 사전 등록

## 핵심 기능
1. **임베드 폼 + 호스팅 페이지**
2. **추천 코드 발급·트래킹** — `?ref=xyz`
3. **순번 상승 게임화** — 가입자 화면에 현재 등수 + "X명 추월 가능"
4. **자동 초대 발송** — 상위 N% 또는 N명 도달 시
5. **분석** — UTM·추천 트리·이메일 도메인 분포

## 경쟁사
- Waitlist.email, Prefinery, Viral Loops, KickoffLabs

## 차별점
- Robinhood 스타일 순번 상승 UI 기본 제공
- 자동 초대 워크플로우(Tally + Zapier 조합 불필요)
- 한국 시장 — 카카오톡 공유 버튼 내장
- 임베드 폼 < 8KB

## KPI
- 신규 가입자 추천 코드 사용률 30%+
- 평균 K-factor 1.2+
- 무료 → 유료 전환율 5%+
- 가입 → 활성 추천(1명 이상 초대) 비율 25%+
- 캠페인 평균 가입자 1만 명 이상 워크스페이스 30%
