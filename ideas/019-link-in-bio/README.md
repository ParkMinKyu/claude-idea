# 019 · 크리에이터용 링크 페이지

## 개요
인스타그램·틱톡 바이오에 부착하는 멀티 링크 페이지. 클릭 분석·예약 게시·결제 링크를 단일 대시보드에서 관리.

## 문제
- Linktree 무료 플랜은 분석 데이터가 빈약, 유료 플랜은 월 $9~24로 부담.
- 한국 크리에이터에게는 카카오페이·네이버페이 결제 링크 결합이 필요한데 글로벌 서비스는 미지원.
- 다국어 페이지(`/en`, `/ko`)와 SEO 최적화가 필요한 경우 직접 만들어야 한다.

## 솔루션
- 드래그로 링크 정렬, 테마 즉시 변경
- 클릭/유입 출처/디바이스 실시간 분석
- 결제 링크(Stripe, Toss) 임베드
- 다국어 페이지 자동 분기

## 타겟 사용자
- 인플루언서, 1인 콘텐츠 크리에이터
- 인디 메이커(제품 출시 페이지로 사용)
- 강연자·코치

## 핵심 기능
1. **링크 빌더** — 드래그 정렬, 아이콘 자동 인식
2. **테마/커스텀 CSS** — 프리셋 12종 + 직접 편집
3. **분석** — 일/주/월별 클릭, 출처, 디바이스
4. **결제 임베드** — Stripe / Toss / Lemon Squeezy 링크 카드
5. **예약 게시** — 특정 시점에 링크 활성/비활성

## 경쟁사
- Linktree, Beacons, Bento, Carrd, Stan Store

## 차별점
- Toss·카카오페이 결제 링크 카드 내장
- Pro 플랜 가격이 Linktree보다 40% 낮음
- 한국어/영어/일본어 자동 분기
- Open API 제공 (CMS·자동화 연동)

- 신규 페이지 활성화율(첫 링크 추가) 80%+

- 무료 → Pro 전환율 6%+
