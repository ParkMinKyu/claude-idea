# 감정 일기 + 통계 (MoodJournal)

## 개요
하루 1~3회 간단한 감정 체크인과 자유 일기를 기록하고, 주간/월간 감정 통계와 트리거 분석을 제공하는 디지털 멘탈 케어 앱.

## 문제
- 감정 일기를 적고 싶지만 매일 길게 쓰기는 부담.
- 자신의 감정 패턴(어떤 날 우울한지)을 파악하기 어려움.
- 정신과 상담 시 객관적 데이터 부족.

## 솔루션
- 감정 5단계 + 태그(불안, 우울, 행복, 평온 등) 빠른 체크인.
- 자유 텍스트 일기 (옵션).
- 주/월간 감정 그래프 + 워드클라우드.
- 감정 트리거 분석 (요일, 시간대, 활동 태그).
- 감정 점수 PDF 보고서 (병원 제출용).

## 타겟 사용자
- 20~30대 스트레스 받는 직장인.
- 정신과 상담받는 환자.
- 자기 이해를 원하는 사용자.

## 핵심 기능
1. 감정 5단계 + 태그 빠른 체크인.
2. 자유 일기 (선택).
3. 주/월간 감정 통계 그래프.
4. 워드클라우드 (자주 쓴 단어).
5. 감정 트리거 분석.
6. PDF 보고서.
