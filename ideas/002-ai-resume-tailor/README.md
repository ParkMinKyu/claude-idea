# 002 - JD 기반 이력서 자동 맞춤화

## 개요
원본 이력서와 채용 공고(JD)를 입력하면, Claude가 해당 공고에 최적화된 이력서 버전을 생성합니다. 키워드 매칭, 강조할 경험 재배치, 본인 경험을 과장 없이 재표현하는 데 초점.

## 문제
- 같은 이력서로 50곳에 지원하면 서류 통과율이 5% 미만인 경우가 흔함
- JD마다 강조할 키워드와 경험이 다르지만, 매번 수동으로 수정하기에는 시간 부담
- ATS(지원자 추적 시스템) 키워드 누락으로 사람 손에 닿기도 전에 탈락

## 솔루션
- 이력서(PDF/Markdown/텍스트) 업로드 + JD 텍스트 붙여넣기
- Claude가 JD에서 핵심 요구사항·키워드를 추출 → 이력서의 어떤 경험을 강조/순서 변경/재서술할지 제안
- 사실 왜곡(없는 경험 추가) 금지를 시스템 프롬프트에 강제
- 최종본을 Markdown/PDF로 export

## 타겟 사용자
- 적극적으로 이직 활동 중인 3~10년차 직장인
- 해외 취업 준비자 (영문 JD ↔ 한글 이력서)
- 신입 개발자 (포트폴리오 다수, 회사별 정렬 필요)

## 핵심 기능
1. 이력서 업로드 (PDF→텍스트 추출 포함)
2. JD 분석: 필수 요건/우대 요건/키워드 추출
3. 맞춤 이력서 생성 (변경 사항 diff 하이라이트)
4. ATS 키워드 매칭 점수
5. (Pro) 다국어 변환 (한↔영)

## 차별점
- 한국어 + 영어 이력서 동시 지원
- 사실 왜곡 방지 가드레일 (Claude 시스템 프롬프트 + post-validation)
- diff 뷰로 "왜 이렇게 바꿨는지" 사용자가 검토 가능
- 1회 결제 옵션으로 진입 장벽 낮춤

## 핵심 지표 (KPI)
- 가입 후 첫 이력서 생성률 (활성화)
- 생성 후 다운로드 전환율
- 평균 ATS 점수 개선 폭
- Free → Pro 전환율 (목표 8%)
- 월간 retention (목표 60%, 구직 사이클 특성 반영)
- 사용자 보고 면접 성공률 (NPS 보조)

## 향후 로드맵
- M1: 한글/영문 단일 이력서 맞춤화 (MVP)
- M2: PDF 입력 + 다국어 변환
- M3: 자기소개서 자동 생성, 면접 예상 질문 연동
- M4: 채용 사이트(원티드, 점핏) API 연동으로 원클릭 지원

## 리스크와 대응
- LLM이 없는 경험을 추가하는 환각 → post-validation으로 원본에 없는 키워드 플래그
- ATS 알고리즘은 회사마다 다름 → 점수는 참고치임을 명시
- 구직 사이클이 짧아 retention 어려움 → 1회 결제 + 합격 후 추천 인센티브
