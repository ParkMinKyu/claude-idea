# 027 · 프리랜서 인보이스 SaaS

## 개요
프리랜서가 인보이스를 작성·발송하고 입금을 추적하는 SaaS. PDF/이메일 자동 발송, 다국가 세금, 결제 링크 첨부.

## 문제
- 한국 프리랜서는 세금계산서·간이영수증·해외 클라이언트용 인보이스 형식이 모두 달라 골치.
- Wave/Bonsai는 한국어/원화 지원이 빈약.
- 결제 링크가 없으면 입금 지연이 발생.

## 솔루션
- 클라이언트 등록 → 인보이스 생성 → PDF + 이메일 자동 발송
- Toss / Stripe 결제 링크 자동 첨부
- 입금 확인(수동/Stripe 웹훅) → 영수증 자동 발송
- 한국 세금 모드(부가세 10%) / 해외 모드 토글

## 타겟 사용자
- 디자이너·개발자·작가 등 프리랜서
- 소규모 에이전시
- 컨설턴트

## 핵심 기능
1. **인보이스 작성기** — 라인 아이템, 세금/할인, 통화
2. **PDF 생성기** — 한국식·서양식 템플릿
3. **결제 링크 자동 첨부** — Toss/Stripe
4. **클라이언트 CRM** — 입금 이력, 평균 결제 일수
5. **연체 알림** — 지정일 후 자동 리마인더

## 경쟁사

## 차별점
- 한국식/서양식 템플릿 모두 지원
- Toss Payments 결제 링크 내장(국내 클라이언트 매끄러움)
- 무료 플랜에 PDF 무제한
- API/Webhook 기본 제공

## KPI
- 첫 인보이스 발송까지 평균 시간 < 5분
- 평균 결제 일수 14일 이내 달성 비율 60%+
- Free → Solo 전환율 6%+
- ARPU 월 $12+
- 결제 링크 사용 인보이스 비율 50%+
