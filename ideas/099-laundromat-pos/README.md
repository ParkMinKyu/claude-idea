# 099 · WashKey — 무인 빨래방 결제/예약 SaaS

## 개요
무인 셀프 빨래방의 세탁기·건조기에 QR 코드를 붙여 손님이 Stripe Terminal 또는 카드로 결제 후 기계를 원격 잠금 해제할 수 있게 하는 SaaS. 사장은 대시보드에서 매출·기계 상태를 실시간으로 본다.

## 문제
- 무인 빨래방 대부분이 동전·지폐 결제만 지원해서 위·변조와 도난 위험이 있고 손님 편의성도 떨어진다.
- 사장이 기계 고장을 알기까지 시간이 오래 걸린다 — 매출 손실이 누적된다.
- 예약 기능이 없어 피크 시간에 손님 이탈이 잦다 (대기 후 떠남).
- 별도 결제 시스템(코인 토큰 자판기)은 도입 비용 ₩500만원+ 으로 부담.

## 솔루션
- 세탁기마다 QR 스티커 한 장 → 손님 스마트폰으로 즉시 결제
- 결제 성공 시 클라우드에서 기계 unlock 명령 송신 (GPIO 모듈 또는 IoT 게이트웨이)
- "10분 후 예약" 같은 슬롯 락 기능 — 손님이 매장 도착 전 예약 가능
- 사장 대시보드: 매출, 기계별 가동률, 청소 알림, 고장 감지

## 타겟 사용자
- 1~3개 매장 운영하는 셀프 빨래방 자영업자
- 코인 빨래방 → 무인 빨래방 전환 중인 기존 매장
- 대학가·원룸촌 무인 빨래방 프랜차이즈 점주

## 핵심 기능
1. **QR 결제** — Stripe Checkout 모바일 페이지, Apple Pay/Google Pay 지원
2. **기계 원격 제어** — MQTT/HTTP webhook으로 unlock 신호
3. **슬롯 예약** — 향후 60분 내 슬롯 락, 미사용 시 자동 해제
4. **매출 대시보드** — 일/주/월 매출, 기계별·시간대별 분석
5. **고장 알림** — 결제 후 unlock 실패 시 사장에게 Push/SMS

## 경쟁사
- ShinyMile, Cents, LaundryCard — 미국 위주, 한국 카드사 미지원
- 동전 자판기 / 토큰 시스템 — 하드웨어 비싸고 도난 취약
- 워시스왓·세탁특공대 — 수거형 모델, 매장형 아님

## 차별점
- "QR 스티커만 붙이면 시작" — 하드웨어 설치 최소화 (IoT 게이트웨이는 옵션)
- 한국 카드사 + Apple Pay + 토스 페이먼츠 동시 지원
- 슬롯 예약 기능 — 경쟁사 대부분 결제만 지원
- ₩29,000 부터 시작하는 저가 진입 (경쟁사 평균 $99/월)

## KPI
- QR 스캔 → 결제 완료 < 30초
- 결제 후 unlock 성공률 99.5% 이상
- 매장당 코인 → 카드 전환 후 매출 +20% 이상
- 30일 매장 잔존율 90% 이상
- ARR per 매장 ₩600,000 이상
