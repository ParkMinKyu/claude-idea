# 070 · 웹툰 큐레이션 + 구독

## 개요
독자 취향(장르·작화·전개 속도)을 학습해 맞춤 추천하는 웹툰 디스커버리 앱. 작품 자체는 정식 플랫폼(네이버·카카오)으로 딥링크하고, 자체 구독은 인디 웹툰 작가의 후원·미공개분 열람 권한을 판다.

## 문제
- 네이버/카카오 웹툰은 자체 추천이 신작·자사 IP에 편향돼 있어, 독자가 취향 작품을 발견하기 어렵다.
- 트레바리·왓챠피디아의 웹툰 큐레이션은 메타데이터 위주이며 작가 후원 채널이 없다.
- 인디·아마추어 작가는 글로벌 플랫폼(Tapas, Webtoon Canvas) 외에 한국어 후원 채널이 약하다.

## 솔루션
- 평점/북마크/완독 데이터를 바탕으로 작품 임베딩 → 콘텐츠 기반 추천
- 정식 작품은 외부 딥링크(+ 클릭당 어필리에이트 수익)
- 인디 작가 채널: 월 ₩4,900 멤버십 = 미공개 회차·이북·창작 비하인드
- 독자 리뷰는 스포일러 토글 + 좋아요 정렬

## 타겟 사용자
- 주 5+ 회차 웹툰을 보는 헤비 리더 (20~30대 여성 비중↑)
- 새로운 작품 발견에 갈증을 느끼는 독자
- 자체 팬 채널을 갖고 싶은 인디 웹툰 작가

## 핵심 기능
1. **추천 엔진** — 콘텐츠 기반 + 협업 필터링 하이브리드 (작품 임베딩)
2. **리스트 / 폴더** — "이번 주 정주행", "완결작 추천" 등 사용자 큐레이션
3. **인디 작가 멤버십** — 월·연 구독, 미공개 회차 잠금 해제
4. **딥링크 어필리에이트** — 외부 플랫폼 결제 시 수익 셰어
5. **스포 토글 리뷰** — 본문 클릭 시 펼침, 별점 + 태그(작화/스토리/완결성)

## 수익 모델
| 채널 | 가격/수수료 |
|---|---|
| Reader 무료 | 광고 1개/일, 추천 무제한 |
| Reader Plus | ₩4,900/월 광고 제거 + 다중 디바이스 동기화 |
| 인디 작가 멤버십 | 작가가 가격 설정, 플랫폼 수수료 12% |
| 어필리에이트 | 외부 결제 시 5~10% 셰어 |
| 광고 | DA 광고, 콘텐츠 추천형 |

## 경쟁사
- 네이버 웹툰, 카카오웹툰, 레진코믹스, 봄툰, Tapas, Webtoon Canvas
- 큐레이션: 왓챠피디아, 라프텔

## 차별점
- "추천만" 특화 = 작품을 보유하지 않아 합법 분쟁 0
- 인디 작가 직접 후원이 같은 앱 안에서 가능 (Tapas는 분리)
- 한국어 태그 시스템 (작화체, 회귀물, 빙의 등 한국 웹툰 클러스터 학습)
- 회차 단위 진도 트래킹 + "오늘의 한 회차" 푸시

## KPI
- 가입 후 14일 이내 첫 외부 클릭 70% 이상 (Activation)
- 추천 클릭률 (CTR) 15% 이상
- Reader Plus 전환율 3%
- 인디 작가 멤버십 평균 ARPU ₩3,500/월
- 30일 잔존 60% 이상

## 사용 시나리오
1. 헤비 리더가 매주 추천 받고 외부 플랫폼으로 결제 → 어필리에이트 수익
2. 인디 작가가 미공개 회차를 멤버십에만 공개해 안정적 월 수입 확보
3. 독자 모임이 "이번 분기 정주행" 큐레이션 리스트를 공유

## MVP 범위
- v0.1: 작품 메타 DB + 태그 검색 + 외부 딥링크
- v0.2: 추천 엔진 (콘텐츠 기반)
- v0.3: 인디 작가 멤버십 + 정산
- v1.0: 협업 필터링 + 사용자 큐레이션 리스트 + 광고

## 리스크 / 가정
- 정식 작품 메타데이터 수집의 합법성 → 공개 API/공개 페이지만 사용
- 어필리에이트 수수료가 작아 단가 수익 부족 → 멤버십·구독 중심으로 전환 설계
- 인디 작가의 결제 정산 KYC 부담 → 토스 Connect로 자동화

## 운영 / 컴플라이언스

- 작가 정산 세금 처리 (사업자/기타소득) 가이드 제공
