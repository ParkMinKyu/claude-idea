# 054 - Focus Blocker

산만한 사이트(소셜·뉴스·쇼핑)를 일정에 따라 차단하는 Chrome Extension (MV3).

## 개요
사용자가 설정한 차단 사이트 목록과 일정(예: 평일 9-18시)에 맞춰 자동으로 사이트를 차단하고, 차단 페이지에 동기부여 메시지나 할 일을 보여줍니다. "5분만 보기" 옵션, 화이트리스트 도메인, 일별 통계도 제공합니다.

## 문제
- 의지력만으로 SNS 줄이기 어려움
- 기존 차단 도구는 영구 차단이라 불편
- 작업 시간과 휴식 시간이 섞임
- 모바일 차단은 OS 제한 다양

## 솔루션
- 도메인 패턴별 일정 등록 (요일·시간)
- 시간 외에는 정상 접속, 일정 내엔 차단 페이지로 리다이렉트
- "5분 휴식" 일회성 우회 (Pro는 비활성화 가능)
- 일일 사용 통계 시각화

## 타겟
- 학생, 원격 근무자
- 디지털 디톡스 희망자
- ADHD 사용자

## 핵심 기능
- 도메인/패턴 차단 (정규식 지원)
- 요일/시간대 일정
- 일회성 우회 (5분, 횟수 제한)
- 차단 페이지 커스텀 (인용구, 할 일)
- 일/주 통계
- 스트릭 (Pro)

## 수익 모델
- Free: 차단 사이트 10개, 일정 3개
- Pro ($3/월 또는 $24/년):
  - 무제한 사이트 + 일정
  - 우회 비활성화 (Hard Mode)
  - 통계 + 스트릭 시각화
  - 디바이스 동기화
  - 페이지 콘텐츠 차단 (특정 키워드)

## 경쟁사
- Cold Turkey (데스크톱, 강력)
- StayFocusd (Chrome, 무료)
- Freedom (멀티플랫폼, $39/년)
- LeechBlock NG (Firefox 중심)

## 차별점
- MV3 기반 (장기 호환성)
- 시간대별 일정이 시각적이고 직관적
- "5분 우회" 통계가 사용자 의식 환기
- 가격 경쟁력

## KPI
- 차단된 방문 수 / 일
- 우회 사용률 (낮을수록 좋음)
- Pro 전환율 (목표 8%)
- 7일/30일 리텐션
- 스트릭 평균 일수 (Pro)
- 가장 많이 차단된 도메인 TOP10

## 마일스톤
- M1: 도메인/일정 차단 + 차단 페이지
- M2: 통계 + 우회 카운트
- M3: Pro 결제 + Hard Mode
- M4: 동기화 + 키워드 차단
- M5: 모바일 컴패니언 (PWA, screen time API)

## 리스크
- 사용자가 차단을 끄려고 확장 비활성화 → "1주일 후 재활성" 옵션
- declarativeNetRequest rule 한도 (5000) → 사용자에게 가시화
