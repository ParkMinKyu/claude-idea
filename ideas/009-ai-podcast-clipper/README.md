# 009 - 팟캐스트 숏폼 클립 자동 추출

## 개요
1~2시간 길이의 팟캐스트/유튜브 인터뷰 음성을 입력하면, Whisper로 전사 → Claude가 "가장 바이럴 가능성 높은 30~60초 구간"을 자동 식별하고 자막+썸네일 메타데이터까지 생성하는 도구.

## 호스트가 직접 30분씩 풀영상을 보며 클립을 찾는 노동을 자동화.

## 문제
- 1시간 팟캐스트에서 숏폼 클립 5개 만들려면 영상 편집자 시간 3~4시간 필요
- 좋은 후크 구간을 놓치면 도달 손해
- TikTok/Reels/Shorts용으로 매주 5~10개 클립이 필요한데 인력 부담

## 솔루션
- 오디오 파일 업로드 → Whisper로 단어별 timestamp 전사
- Claude가 전사문에서 "독립적으로 흥미로운 구간" 선정 (시작/종료 timestamp + 후크 카피)
- ffmpeg로 자동 클리핑 + 자막 burn-in
- 클립별 추천 캡션/해시태그 생성

## 타겟 사용자
- 팟캐스트 운영자 (개인 + 채널)
- 유튜버 (긴 인터뷰 클리핑)
- 미디어 컴퍼니의 SNS 운영자
- 콘텐츠 마케터

## 핵심 기능
1. 오디오/비디오 업로드 (mp3, mp4, wav)
2. Whisper 전사 + 단어 timestamp
3. Claude 기반 바이럴 구간 식별 (5~10개 클립)
4. 자동 자막 + ffmpeg 클리핑
5. 클립별 SNS 캡션/해시태그 생성

## 차별점

- Claude 기반 "왜 흥미로운가" 설명 함께 제공 (호스트 학습)
- API 제공 → 다른 영상 워크플로우와 통합 가능
- 가격 경쟁력 (Opus Clip 대비 30% 저렴)

## 핵심 지표 (KPI)
- 시간당 추출 클립 수 (사용 빈도)
- 클립 다운로드율 (생성 → 사용)
- Free → Creator 전환율 (목표 8%)
- 월간 retention (목표 80%)
- 사용자 채널 평균 조회수 향상 (자가 보고)

## 향후 로드맵
- M1: 오디오 업로드 + 클립 메타데이터 (MVP)
- M2: ffmpeg 자동 클리핑 + 자막 burn-in
- M3: 9:16 변환 + 화자 얼굴 추적 (영상 입력)
- M4: 채널 연동 자동 업로드 (YouTube Shorts API)
