# 075 · 한국 스톡 사진 마켓

## 개요
한국인 모델·한국 풍경·한국 문화에 특화된 스톡 사진 마켓플레이스. Shutterstock·Getty는 외국인 모델·서양 배경 위주라 한국 마케터·디자이너가 어색한 시각을 가져다 쓰는 문제를 해결한다.

## 문제
- 글로벌 스톡은 한국적 시각 자료가 부족하며 "Asian" 카테고리가 일본·중국과 섞여 있다.
- 한국 마케터는 모델 동의서·초상권 이슈로 자체 촬영 부담이 크다.
- 한국 작가의 스톡 사진 진입은 키워드 영문화·세금 신고 부담으로 어렵다.
- 게티 이미지 한국 라이센스는 매우 비싸다 (장당 수십만 원).

## 솔루션
- 한국인 모델·한국 문화(한복·전통시장·아파트단지·지하철 등) 카테고리 강화
- 모든 모델은 표준 모델 동의서(전자서명) + 미성년자 보호자 동의 필수
- 작가 정산: Stripe Connect로 자동, 한국 작가는 토스페이먼츠 + 사업자 등록 안내
- 라이센스: 일반/상업/확장 3단계, 회사 인쇄·디지털 OOH 명시

## 타겟 사용자
- 한국 마케터, 콘텐츠 에디터, 광고 대행사
- 출판사·교과서 편집자 (한국 문화 시각 자료)
- 한국인·재외동포 작가 (수익 채널)
- 학원·교육 콘텐츠 제작사

## 핵심 기능
1. **카테고리·태그 검색** — "한국인 직장인 30대 여성" 한국어 자연어 검색
2. **모델 동의서 관리** — 전자서명, 동의 범위 메타데이터 (상업·교육·정치 사용 가능 여부)
3. **라이센스 발급** — 결제 시 PDF 라이센스 자동 발급, 영수증·세금계산서
4. **작가 대시보드** — 다운로드 수·정산·인기 키워드 분석
5. **유사 검색** — 업로드한 이미지와 유사 스타일 추천 (임베딩)

## 수익 모델
| 채널 | 가격/수수료 |
|---|---|
| 일회 라이센스 | ₩9,900 (일반) / ₩29,000 (상업) / ₩99,000 (확장) |
| 정기 구독 | ₩39,000/월 10장, ₩99,000/월 50장 |
| 작가 정산 | 다운로드 시 40~50% (구독 풀은 비례 분배) |
| 기업 라이센스 | 협의, ₩300,000/월~ |

## 경쟁사
- Shutterstock, Getty Images, Adobe Stock, 클립아트코리아, 토픽포토

## 차별점
- 한국 모델·풍경 절대량 우위 (큐레이션된 50,000장+ 목표)
- 한국어 자연어 검색 (Whisper·Claude 임베딩)
- 모델 동의서·세금 처리 완전 자동화
- 사업자/세금계산서·현금영수증 발행 기본

## KPI
- 검색 → 다운로드 전환율 6% 이상
- 작가 가입 후 첫 사진 승인까지 평균 < 24시간 (모더레이션 SLA)
- 월 다운로드당 평균 가격 ₩15,000+
- 30일 기업 구독 잔존 80%
- 작가 1인당 월 평균 정산 ₩200,000 이상
- ARR per active workspace ₩600,000+

## 사용 시나리오
1. 광고 대행사 PM이 "한국인 30대 직장인" 검색 → 라이센스 즉시 구매·다운로드
2. 출판사 편집자가 교과서용 한국 풍경 사진을 일괄 구매
3. 프리랜서 사진가가 한복 시리즈를 등록 → 월 ₩300,000 정산

## MVP 범위
- v0.1: 업로드 + 검색 + 결제 + 다운로드
- v0.2: 모델 동의서 전자서명 + 라이센스 PDF 자동
- v0.3: 구독 플랜 + 시각 유사 검색
- v1.0: 기업 라이센스 + API + 사내 자산 관리

## 리스크 / 가정
- 모델 동의서 위조·만료: 매년 재확인 절차
- 저작권/초상권 분쟁: 표준 약관 + 보험 가입(작가 비용)
- 글로벌 스톡 대비 인지도: SEO + 콘텐츠 마케팅 중심

## 운영 / 컴플라이언스
- 개인정보보호법 + 초상권 가이드 준수
- 미성년자 모델: 보호자 동의서 의무
- 청구서·세금계산서 자동 발행 (기업 구매)
- 환불 정책: 다운로드 전 100% / 다운로드 후 사유 검토
