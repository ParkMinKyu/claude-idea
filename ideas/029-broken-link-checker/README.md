# 029 · 사이트 깨진 링크 점검

## 개요
사이트맵이나 시작 URL부터 크롤링해 깨진 내부/외부 링크를 찾아 리포트하는 SaaS. SEO·UX 손실 방지.

## 문제
- 큰 사이트에서 깨진 링크는 SEO 점수와 사용자 신뢰를 갉아먹는다.
- Screaming Frog는 데스크톱 앱·라이선스 비싸고 자동 스케줄 부족.
- 자체 cronjob은 false positive·rate limit 처리가 골치.

## 솔루션
- 시드 URL → cheerio로 HTML 파싱 → 링크 추출 → 동시 fetch
- robots.txt 준수, 도메인별 rate limit
- 일/주 단위 스케줄 크롤 → 변경 diff 리포트
- 페이지별 깨진 링크 정렬, 외부/내부 분류, CSV/Slack export

## 타겟 사용자
- SEO·콘텐츠 마케터
- 사내 IT/웹 운영
- 디지털 에이전시

## 핵심 기능
1. **사이트 크롤러** — 동시성 제어, robots.txt 준수
2. **링크 상태 분류** — 200/301/404/5xx/timeout
3. **스케줄 크롤** — 일/주 cron
4. **diff 리포트** — 새 깨진 링크만 알림
5. **export** — CSV, Slack, Notion DB

## 경쟁사
- Screaming Frog, Ahrefs Site Audit, Sitebulb, Dead Link Checker

## 차별점
- 클라우드 호스팅 — 데스크톱 설치 불필요
- Ahrefs 대비 1/10 가격, 깨진 링크 특화
- 한국어 사이트 URL 인코딩 안정성
- 무료 플랜에 스케줄 없지만 1회 크롤 무제한

## KPI
- 크롤 평균 P95 < 5분/1,000 페이지
- 신규 깨진 링크 감지율(검증된) 95%+
- 무료 → Indie 전환율 5%+
- 사이트당 평균 깨진 링크 발견 50개+
- 월간 리포트 열람율 70%+
