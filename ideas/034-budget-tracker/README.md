# 소비 카테고리 자동 분류 (SmartSpend)

## 개요
SMS 결제 알림과 캘린더 이벤트를 분석해 거래를 자동으로 카테고리에 분류하는 가계부 앱.
사용자가 일일이 입력하지 않아도 자동으로 한 달 가계부가 완성됩니다.

## 문제
- 가계부 앱은 매번 수동 입력이 귀찮아 한 달도 못 가서 중단됩니다.
- 카드사 앱은 분산되어 있어 통합 지출 파악이 어렵습니다.
- 자동 분류 정확도가 낮은 기존 가계부 앱.

## 솔루션
- SMS 알림 파싱 (사용자 동의 후) → 금액, 가맹점, 결제 시각 추출.
- 가맹점명을 온디바이스 ML 모델로 카테고리 자동 분류.
- 캘린더 이벤트 연동 (회의 = 점심 지출, 여행 = 교통 지출).
- 사용자가 수정하면 모델이 학습.

## 타겟 사용자
- 20~40대 직장인.
- 가계부 작성을 시도했다가 포기한 사용자.
- 카드 사용 빈도가 높은 사용자.

## 핵심 기능
1. SMS 자동 파싱 (한국 카드사 포맷 지원).
2. 가맹점 카테고리 자동 분류 (TFLite).
3. 수동 거래 추가.
4. 월/주/카테고리별 지출 분석.
5. 예산 설정 및 초과 알림.
6. CSV 내보내기.

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩14,900 일회성: 광고 제거, 무제한 카테고리, CSV/Excel 내보내기.

### 구독
- 월 ₩3,900: 가족 가계부 공유, 자산 통합 관리, 카드사 API 직접 연동.

### 광고
- 무료 사용자에게 통계 화면 네이티브 광고.

## 경쟁사
- 뱅크샐러드: 종합 자산관리, 무겁고 데이터 수집 광범위.
- 토스 가계부: 간결하나 분류 수정이 제한적.
- 머니플렉스: 광고 과다.

## 차별점
- SMS 파싱 정확도 95%+ (한국 카드사 22곳 지원).
- 학습형 분류기로 개인화.
- 가계부+캘린더 매칭으로 컨텍스트 인사이트.
- 가벼운 설치 용량 (< 15MB).

## KPI
- 30일 리텐션 35%.
- 자동 분류 정확도 90% 이상.
- 평균 월간 거래 처리 50건/유저.
- 프리미엄 전환율 5%.
- 평점 4.4 이상.
