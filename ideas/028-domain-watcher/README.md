# 028 · 도메인 만료/가용 알림

## 개요
관심 도메인을 등록하면 만료 임박·재등록 가능 시 이메일/Slack으로 알림. CLI + 웹 SaaS 듀얼 인터페이스.

## 문제
- 보유 도메인 만료를 놓쳐 잃는 사례가 매년 발생.
- 원하는 도메인이 드롭될 순간을 기다리려면 수동 whois 폴링이 필요.
- 도메인 드롭 캐처 서비스는 비싸고 한국어 대응이 부족.

## 솔루션
- 도메인 리스트 등록 → 매일 whois 조회 → DB 비교 → 변경 시 알림
- 만료 30/14/7/1일 전 단계별 이메일
- 재등록 가능(available) 순간 즉시 알림
- CLI(`domwatch add foo.com`) + 웹 대시보드 동기화

## 타겟 사용자
- 도메인 투자자
- 다중 도메인 관리 에이전시
- 만료 위험 감지 필요한 IT 관리자

## 핵심 기능
1. **whois 폴링** — 만료일·상태(active/expired/available)
2. **단계별 알림** — 만료 D-30/14/7/1
3. **재등록 알림** — 상태 전이 즉시 push
4. **CLI 도구** — `add/list/remove/run`
5. **다중 채널** — 이메일/Slack/Discord/Telegram
