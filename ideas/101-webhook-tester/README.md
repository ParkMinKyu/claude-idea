# 101 · 웹훅 수신/검사 도구

## 개요
임시 또는 영구 엔드포인트(bin)를 발급해 들어오는 웹훅을 실시간으로 캡처하고, 헤더·바디·서명을 분석해 주는 개발자 도구. RequestBin·Webhook.site의 셀프호스팅 가능한 오픈코어 대안을 지향한다.

## 문제
- 외부 서비스(GitHub, Stripe, Shopify 등)의 웹훅을 연동할 때 페이로드 형태와 서명 검증을 로컬에서 확인하기 어렵다.
- ngrok + 콘솔 로그 조합은 서명 검증 실패 원인(타임스탬프 만료, raw body 변형)을 진단해 주지 않는다.
- 기존 SaaS는 무료 플랜의 보관 기간이 짧고, 민감한 페이로드를 외부 서비스에 흘려보내야 하는 보안 부담이 있다.

## 솔루션
- 고유한 bin URL을 발급하고 POST 요청을 100건까지 버퍼링한다.
- raw body를 보존해 GitHub/Stripe/Generic HMAC 서명을 byte-for-byte 검증한다.
- Content-Type을 인식해 JSON/form/raw로 파싱하고, 잘못된 JSON을 즉시 표시한다.
- "테스트 발신기"로 올바른 서명 헤더를 생성해 재현 테스트를 돕는다.

## 타겟 사용자
- 결제·인증 웹훅을 연동하는 백엔드 개발자
- 서드파티 통합을 구축하는 SaaS 팀
- 자체 호스팅이 필요한 보안 민감 조직(금융, 헬스케어)

## 핵심 기능
1. **bin 캡처 엔드포인트** — Fastify raw body parser로 모든 요청을 무손실 저장
2. **멀티 프로바이더 서명 검증** — GitHub(`X-Hub-Signature-256`), Stripe(`Stripe-Signature` t/v1 + 타임스탬프 허용오차), Generic HMAC
3. **페이로드 인스펙터** — Content-Type 기반 파싱, 크기/헤더 수/수신 시각 메타데이터
4. **테스트 발신기** — 시크릿으로 올바른 서명을 계산해 헤더 문자열 생성
5. **실시간 뷰어** — SSE로 캡처된 요청을 라이브 스트리밍(상용판)

## 수익 모델
오픈코어: 캡처 엔진과 서명 검증 코어는 MIT 라이선스로 공개, 협업·보관·팀 기능은 상용.

| 플랜 | 가격 | bin 보관 | 요청 보관 | 팀 |
|---|---|---|---|---|
| OSS (self-host) | $0 | 무제한 | 메모리/직접 DB | - |
| Free (cloud) | $0 | 1개 | 24시간, 50건 | 1명 |
| Pro | $12/월 | 20개 | 30일, 10k건 | 3명 |
| Team | $39/월 | 무제한 | 90일, 무제한 | 10명 + SSO |
| Enterprise | 협의 | 무제한 | 커스텀 + 온프렘 | SAML/감사로그 |

## 사용 시나리오
1. 개발자가 대시보드에서 새 bin URL을 발급받는다.
2. 외부 서비스(GitHub/Stripe)의 웹훅 설정에 bin URL을 등록한다.
3. 이벤트가 발생하면 요청이 라이브 뷰어에 실시간으로 나타난다.
4. 서명 검증 결과(valid/invalid + 사유)와 파싱된 페이로드를 확인한다.
5. 실패 시 "테스트 발신기"로 올바른 서명을 역산해 원인을 좁힌다.

## 경쟁사
- **Webhook.site** — 무료/인기, 단 보관 짧고 서명 검증 미약, 클라우드 전용
- **RequestBin(Pipedream)** — 강력하나 자동화 플랫폼에 종속
- **Beeceptor** — 모킹 중심, 서명 검증 비핵심
- **Hookdeck** — 프로덕션 게이트웨이 지향(가격대 높음)
- **ngrok inspect** — 로컬 한정, 영구 bin/팀 기능 없음

## 차별점
- 서명 검증 로직을 오픈소스로 공개해 보안 감사 가능 (경쟁사는 블랙박스)
- 단일 바이너리/컨테이너로 온프렘 설치 가능 → 민감 페이로드 외부 유출 없음
- 프로바이더별 서명 규격(타임스탬프 허용오차 포함)을 코드로 검증 + 실패 사유 명시
- "테스트 발신기"로 올바른 서명을 역산해 통합 디버깅 시간 단축

## KPI
- 첫 bin 생성 후 첫 요청 캡처까지 평균 시간 < 2분 (Activation)
- 서명 검증 기능 사용 세션 비율 40% 이상 (핵심 가치 검증)
- OSS GitHub Star → Cloud 가입 전환율 측정
- Free → Pro 전환율 5% 이상
- 캡처 요청 손실률 < 0.01%

## 로드맵
- v0: 캡처 + 멀티 프로바이더 서명 검증 + 인스펙터(현재 MVP)
- v1: SSE 라이브 뷰어, 영구 bin, 팀 워크스페이스
- v2: 요청 리플레이/포워딩(localhost 터널), 검색·필터
- v3: 온프렘 엔터프라이즈 이미지, SAML SSO, 감사 로그
