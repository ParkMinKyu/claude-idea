# 087 · 회의록 템플릿 SaaS (Meeting Notes)

## 개요
회의 유형(1:1, 스프린트 회고, 킥오프, 외부 미팅)에 맞는 MDX 템플릿을 한 번의 클릭으로 생성하고 팀과 공유하는 SaaS. 회의록의 형식·태깅·후속 액션 추출을 표준화한다.

## 문제
- 팀마다 회의록 포맷이 제각각 → 검색·재활용이 어려움
- Notion·Confluence는 자유도 높지만 매번 빈 페이지에서 시작해 일관성 결여
- 액션 아이템이 회의록 본문에 묻혀 추적이 안 됨

## 솔루션
- 회의 유형별 검증된 MDX 템플릿 30+종
- 액션 아이템 `- [ ] @name (due: 2026-01-30) text` 문법을 파싱해 별도 추적
- 슬러그 URL 공유, 비로그인 읽기 허용 (조직 옵션)
- Slack·Linear·Jira로 액션 자동 전송

## 타겟 사용자
- 회의 기록 표준화를 원하는 10~100명 규모 팀
- 원격 근무 비중이 높은 기술 조직
- 1:1 미팅을 정례적으로 운영하는 매니저

## 핵심 기능
1. **템플릿 갤러리** — 1:1, 회고, 디자인 리뷰, RFC, 외부 미팅 등
2. **MDX 에디터** — 슬래시 커맨드, 멘션, 체크박스
3. **액션 추출** — 본문에서 `- [ ] @user (due:)`를 파싱해 대시보드 노출
4. **공유 링크** — 토큰 기반 읽기 전용 URL
5. **검색** — 제목/본문/참석자/태그 풀텍스트

## 수익 모델
| 플랜 | 가격 | 인원 | 노트 수 |
|---|---|---|---|
| Free | $0 | 3명 | 50 |
| Team | $8/유저/월 | 무제한 | 무제한 + 통합 |
| Business | $16/유저/월 | 무제한 | + SSO, 감사로그 |

## 경쟁사
- Notion, Confluence, Fellow.app, Hugo, Tactiq

## 차별점
- MDX 기반 → 사용자 정의 컴포넌트 삽입 가능 (`<Poll/>`, `<Decision/>`)
- 액션 아이템 추출이 첫 번째 사용 가치 (Fellow는 별도 모듈)
- 템플릿 마켓플레이스 + 수익 셰어
- 한·일·영 다국어 템플릿 기본 제공

## KPI
- 회의 종료 → 노트 작성 완료 시간 < 5분 (평균)
- 액션 아이템 완료율 70% 이상 (1주 이내)
- Free → Team 전환율 5%
- 워크스페이스 당 월 활성 노트 작성자 60%
- NRR 110% 이상
