# 014 - UI 스크린샷 → UX 개선안

## 개요
앱/웹 화면 스크린샷을 업로드하면, Claude vision이 사용성 휴리스틱(닐슨 10원칙)에 따라 UX 문제를 진단하고, 우선순위별 개선안을 제시하는 디자인 리뷰 도구.

## 문제
- 디자인 리뷰 받을 시니어/멘토가 없는 1인 개발자/소규모 팀
- UX 리서치/사용성 테스트는 비싸고 시간 부담
- "이거 이상한 거 같은데 왜 그런지 모르겠어" 진단 어려움

## 솔루션
- 스크린샷 1~5장 업로드 (모바일/웹)
- Claude vision이 각 화면을 분석 → 문제점/심각도/개선안 추출
- 닐슨 휴리스틱, 접근성(WCAG), 모바일 베스트프랙티스 기반
- 우선순위 (P0/P1/P2) + 예상 수정 비용

## 타겟 사용자
- 1인 개발자 / 인디 메이커
- 디자이너 없는 초기 스타트업
- 주니어 디자이너 (셀프 학습)
- PM (출시 전 셀프 체크)

## 핵심 기능
1. 스크린샷 업로드 (multi)
2. 휴리스틱별 문제 진단
3. 우선순위 + 개선안 + 예시 (텍스트)
4. PDF 리포트 export
5. (Pro) Figma 플러그인 + Before/After 비교

## 수익 모델
| 티어 | 가격 | 한도 |
|------|------|------|
| Free | $0 | 월 3장 분석 |
| Plus | $9/월 | 월 100장, PDF export |
| Pro | $29/월 | Figma 플러그인, 무제한 |
| 1회 결제 | $5/장 | 불규칙 사용자 |

## 경쟁사
- Visily, Uizard: AI 디자인 생성 중심
- Maze: 사용성 테스트, 비쌈
- Attention Insight: 히트맵 예측
- ChatGPT vision: 일회성, UX 전문성 약함

## 차별점
- UX 휴리스틱 학습된 시스템 프롬프트 (단순 "보기 좋다/나쁘다" 아닌 원칙 기반)
- 모바일 vs 웹 컨텍스트 자동 구분
- 한국어 UI 텍스트 분석 (영문 도구는 한글 가독성 판단 부정확)
- 1회 결제로 신규 사용자 진입 장벽 낮춤

## 핵심 지표 (KPI)
- 사용자당 평균 업로드 수
- PDF 리포트 다운로드율
- Free → Plus 전환율 (목표 8%)
- Figma 플러그인 설치 수 (Pro 가치)
- NPS (디자인 커뮤니티 추천 영향 큼)
