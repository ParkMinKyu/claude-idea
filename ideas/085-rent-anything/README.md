# 085 - 일일 대여 마켓플레이스

## 개요
드론, 캠핑 장비, 카메라, 악기, 보드게임 등 1~7일 단위로 빌려 쓰는 물건을 P2P로 대여해주는 마켓플레이스입니다. Stripe Connect로 보증금과 정산을 자동 처리하고, 분쟁 조정 흐름을 내장합니다.

## 문제
- "한 번 쓸 건데 사기는 아깝다" 상황이 흔하지만 마땅한 P2P 대여 플랫폼이 없음
- 당근 대여는 보증금/계약 보호 없음
- 전문 렌탈샵은 가격이 비싸고 사용 가능 품목이 제한적
- 대여인은 파손/미반납 위험 부담

## 솔루션
- 호스트(대여인)는 물품 등록(사진/일일가/보증금/위치)
- 게스트는 캘린더로 기간 선택 → 카드 결제 (대여료 + 보증금)
- 반환 후 호스트가 상태 확인 → 보증금 자동 환불 또는 보상 청구
- 분쟁 시 플랫폼 조정 (Stripe Connect 자금 보관)

## 타겟 사용자
- 캠핑/등산 한 번 시도해보는 입문자
- 영상/사진 프로젝트 1회성 장비 필요한 프리랜서
- 이벤트/파티 용품 (프로젝터, 마이크, 보드게임)
- 부업으로 사용 빈도 낮은 장비를 빌려주려는 소유자

## 핵심 기능
1. 물품 리스팅 (사진, 일일가, 보증금, 가능 기간 캘린더)
2. 검색/필터 (카테고리, 위치, 가격)
3. Stripe Connect 결제 + 보증금 분리 보관
4. 대여 기간 캘린더 차단 (중복 예약 방지)
5. 반환 체크 + 보증금 환불 / 보상 청구
6. 리뷰 (양방향: 호스트↔게스트)

## 수익 모델
| 항목 | 수수료 |
|------|------|
| 거래 수수료 | 대여료의 12% (호스트 8% + 게스트 4%) |
| 보증금 | 100% 게스트 환불 (분쟁 외) |
| 프리미엄 호스트 | $9/월 — 상위 노출, 무제한 등록 |
| 보험 (Phase 2) | 건당 $2 — Trov/Slice 연동 |

## 경쟁사
- Fat Llama (UK), Ruckify (US): 글로벌 강자, 한국 미진출
- 당근 마켓: 거래 위주, 대여 보호 없음
- 렌탈샵 (롯데렌탈, SK렌탈): B2C 전문, P2P 아님
- 트렁크2: 한국 P2P 대여 시도했으나 트래픽 부족

## 차별점
- Stripe Connect 기반 안전 결제 + 보증금 자동 환불
- 카테고리 특화 진입 (드론/캠핑/카메라 우선 → 신뢰 형성)
- 한국어 + 위치 기반 검색 (반경 5km 우선)
- 양방향 리뷰 — 무책임한 호스트/게스트 자연 도태

## 핵심 지표 (KPI)
- GMV (월간 거래 총액)
- 리스팅당 평균 대여 일수
- 분쟁 발생률 (목표 2% 미만)
- 게스트 → 호스트 전환율 (대여 경험 후 본인 등록)
- 호스트 30일 retention (목표 70% 이상)
- 평균 응답 시간 (호스트 메시지 답변, 목표 6시간 이내)

## 출시 로드맵
- M1: 카메라/드론 카테고리만, 리스팅 + 결제 + 보증금
- M2: 캘린더 차단, 양방향 리뷰, 위치 검색
- M3: 카테고리 확장 (캠핑/악기/보드게임), 채팅 알림
- M4: 호스트 보험 옵션, 분쟁 조정 자동화 (사진 비교 AI)
- M5: 배송 옵션 (택배 대여), 비즈니스 모드 (소상공인 렌탈샵)
