# 090 · 딥워크 캘린더 차단 (Calendar Blocker)

## 개요
Google/Outlook 캘린더에 딥워크(deep work) 블록을 자동으로 미리 잡고, 미팅이 침범하지 못하도록 보호하는 SaaS. 매니저·미팅 폭증에 시달리는 IC(개인 기여자)를 위한 도구.

## 문제
- 캘린더가 비면 동료가 자동으로 미팅을 채워 넣어 집중 시간이 사라짐
- 수동으로 "Focus" 블록을 잡아도 동료가 무시하고 추가
- Reclaim.ai 등은 강력하지만 월 $8 이상으로 부담

## 솔루션
- 주간 딥워크 목표(예: 10시간)를 설정하면 빈 슬롯에 자동 블록 생성
- 블록 제목/색/공개 여부 커스터마이즈
- 새 미팅 요청 감지 시 우선순위 규칙 적용 (이동/거절/수락)
- 일일 리포트: 실제로 보호된 딥워크 시간 vs 침범 시간

## 타겟 사용자
- 시니어 IC, 스태프 엔지니어
- PM, 디자인 리드
- 회의 폭증에 시달리는 매니저

## 핵심 기능
1. **목표 기반 블록** — "오전 10시간/주, 9-12시 선호"
2. **자동 스케줄러** — 매주 일요일 23시 다음 주 블록 생성
3. **침범 감지** — 새 미팅이 블록과 겹치면 룰에 따라 처리
4. **리포트** — 보호 시간, 침범 시간, 미팅 시간 비율
5. **다중 캘린더** — Google + Outlook 동시 지원

## 수익 모델
| 플랜 | 가격 |
|---|---|
| Free | 1개 캘린더, 주 5시간 보호 |
| Pro | $5/월 무제한 보호 + 다중 캘린더 |
| Team | $9/유저/월 + 팀 동기화 |

## 경쟁사
- Reclaim.ai, Clockwise, Motion, Sunsama

## 차별점
- "자동 블록 + 침범 감지"만 집중, 다른 기능 없음
- 가장 저렴한 가격대 ($5)
- 데이터 보관 0 (OAuth 토큰 외 캘린더 본문 저장 안 함)
- 다국어 UI (한·영·일)

## KPI
- 가입 후 첫 자동 블록까지 < 3분
- 사용자 평균 주간 보호 시간 8시간 이상
- Free → Pro 전환율 7%
- 침범 감지 정확도 95% 이상
- 30일 잔존율 55%
