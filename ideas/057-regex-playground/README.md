# 057 - Regex Playground (AI 정규식 생성기)

## 개요
자연어로 "한국 휴대폰 번호를 매칭하는 정규식 만들어줘"라고 입력하면 Claude가 정규식을 생성하고, 실시간으로 테스트 텍스트에서 매칭 결과를 시각화하는 웹 도구입니다. 생성된 패턴은 JavaScript / Python / Go / Java 코드 스니펫으로 즉시 내보낼 수 있습니다.

## 문제
- 정규식 문법은 학습 곡선이 가파름 (lookahead, backreference 등)
- ChatGPT로 생성한 정규식이 동작하는지 매번 별도 도구에서 검증해야 함
- 언어별 정규식 방언 차이 (PCRE vs RE2 vs JS)
- 팀에서 공유한 복잡한 정규식의 의도 파악이 어려움

## 솔루션
- 자연어 → 정규식 생성 (Claude)
- 정규식 → 자연어 설명 (역방향)
- 실시간 매칭 하이라이팅 (테스트 문자열에서)
- 그룹 캡처 시각화 (트리 뷰)
- 언어별 코드 스니펫 자동 변환
- 패턴 라이브러리 (검증된 일반 패턴: 이메일, URL, 한국 주민번호 등)

## 타겟
- 풀스택 / 백엔드 개발자
- 데이터 엔지니어 (텍스트 파싱)
- QA / 자동화 엔지니어
- 기술 작가, 로그 분석가

## 핵심 기능
1. **AI 생성**: 한/영 자연어 → 정규식
2. **AI 설명**: 정규식 → 자연어
3. **실시간 매칭**: 입력하는 즉시 하이라이트
4. **그룹 시각화**: named/unnamed 캡처 그룹 트리
5. **코드 export**: JS, Python, Go, Java, Ruby
6. **패턴 라이브러리**: 큐레이션된 100+ 검증 패턴
7. **공유 URL**: 패턴 + 테스트 케이스 영구 링크
8. **테스트 케이스 저장** (Pro)

## 수익 모델
- **오픈코어**: 매칭 엔진 + 시각화 MIT 오픈소스
- **Free**: AI 생성 일 5회, 무제한 수동 테스트
- **Pro ($12/월)**: AI 무제한, 패턴 저장, 팀 공유
- **Team ($39/월, 5인)**: 공유 라이브러리, SSO
- **Enterprise**: 셀프호스팅, 자체 모델 옵션

## 경쟁사
- regex101.com (강력하나 AI 없음)
- regexr.com (UI 양호, AI 없음)
- ChatGPT (생성만 가능, 검증 없음)
- iHateRegex (라이브러리만)

## 차별점
- AI 생성 + 즉시 검증을 한 화면에서 (regex101은 AI 없음, ChatGPT는 검증 없음)
- 언어별 방언 자동 변환 (JS의 lookbehind → Python re 변환)
- 한국어 패턴 특화 (주민번호, 사업자번호, 우편번호)
- 패턴 신뢰도 점수 (Claude가 일반 케이스 / 엣지 케이스 자동 테스트)

## KPI
- AI 생성 요청 / DAU
- 평균 세션 시간 (목표 5분+)
- Free → Pro 전환율 (목표 3%)
- 공유 링크 바이럴 계수
- 코드 export 클릭률 (활용 지표)
- 라이브러리 패턴 별점 / 사용 수
