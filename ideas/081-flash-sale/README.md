# 081 - 한정 시간 세일 알림 서비스

## 개요
사용자가 관심 상품/브랜드를 등록하면, 한정 시간 세일(플래시 세일)이 시작될 때 웹/모바일 푸시로 즉시 알리는 서비스입니다. "놓치면 끝" 성격의 세일을 자동 추적합니다.

## 문제
- 플래시 세일은 1시간~24시간 한정이라 SNS/이메일로는 늦음
- 여러 쇼핑몰에서 산발적으로 진행되어 일일이 확인 불가
- 인기 모델은 5분 내 매진 — 알림 즉시성이 중요
- 가격 알림(Pricewatch)과 달리 시작 시점 알림이 핵심

## 솔루션
- 쇼핑몰 메인/이벤트 페이지를 5분 간격으로 크롤링
- 신규 한정 세일 감지 → 관심 카테고리 매칭 사용자에게 즉시 푸시
- 종료 30분 전 "마지막 기회" 리마인드
- 푸시 + 이메일 + (Phase 2) 텔레그램 다채널

## 타겟 사용자
- 쇼핑 알림에 민감한 20~40대
- 한정판 스니커즈/굿즈 수집가
- 가성비 추구하는 학생/직장인

## 핵심 기능
1. 관심 브랜드/카테고리 구독
2. 5분 단위 크롤링 (전체 모니터링 100+ 사이트)
3. Web Push (브라우저/모바일 PWA)
4. 세일 상세: 할인율, 종료 시각, 직링크
5. 알림 빈도 조절 (시간대, 최소 할인율)
6. (Phase 2) 매진 추적 + 알림

## 수익 모델
| 채널 | 비중 |
|------|------|
| 어필리에이트 | 60% — 사용자가 알림 통해 클릭 시 |
| 프리미엄 알림 | 25% — $4/월: 5분 → 1분 간격, 무제한 카테고리, 다채널 |
| 광고 | 10% — 사이트 내 배너 |
| 데이터 API | 5% — 가격비교/리뷰 사이트에 세일 데이터 판매 |

## 경쟁사
- 다나와 핫딜 알림: 가격 중심, UX 노후
- 뽐뿌, 알구몬: 커뮤니티 신고 기반, 지연 발생
- Honey, RetailMeNot: 쿠폰 중심, 한정 세일 알림 약함
- 슬릭딜스(SlickDeals): 미국 시장, 한국 미지원

## 차별점
- 알림 즉시성에 집중 (1분 간격 가능)
- Web Push로 앱 설치 없이 시작 가능 → 신규 사용자 진입장벽 낮음
- 한국 + 직구 사이트 동시 커버
- 알림 빈도/시간대를 사용자가 세밀 제어 → 스팸성 알림 회피

## 핵심 지표 (KPI)
- DAU + 푸시 구독자 수
- 평균 알림 → 클릭 전환율 (목표 15% 이상)
- 알림 발송부터 사용자 클릭까지 시간 (목표 2분 이내)
- 알림 비활성화 비율 (목표 5% 이내)
- Free → Pro 전환 (월간 5% 이상)
- 어필리에이트 RPM (목표 $30 이상)

## 출시 로드맵
- M1: 핵심 쇼핑몰 20곳 + Web Push 알림 + 카테고리 구독
- M2: 종료 임박 리마인드, 시간대 침묵 옵션, 이메일 백업
- M3: PWA 모바일 설치, 텔레그램 봇
- M4: 매진 알림 + 재고 변화 트래킹
- M5: AI 큐레이션 — 사용자 관심사 기반 자동 추천
