# 130 · 가짜 데이터 생성 API

## 개요
JSON 스키마(간이 DSL)를 입력하면 그에 맞는 현실적인 가짜 데이터를 생성해 주는 API·CLI. Mockaroo의 셀프호스트 가능한 결정적(deterministic) 대체재를 지향한다. 시드 기반으로 재현 가능한 데이터를 만든다.

## 문제
- 개발·테스트·데모용 더미 데이터를 매번 손으로 만드는 건 번거롭다.
- 무료 가짜 데이터 서비스는 양·필드 제한이 빡빡하고 결정적이지 않다.
- 테스트에서 동일 시드로 재현 가능한 데이터가 필요한데 마땅한 API가 적다.

## 솔루션
- 필드 타입(name/email/uuid/int/bool/date/enum 등)을 선언하는 간이 스키마
- 시드 기반 의사난수로 재현 가능한 데이터 생성
- 단건/배치 생성, 중첩 객체·배열 지원
- API/CLI/라이브러리로 제공

## 타겟 사용자
- 프론트엔드/백엔드 개발자 (목업 데이터)
- QA 엔지니어 (테스트 픽스처)
- 데모·세일즈 엔지니어

## 핵심 기능
1. **시드 RNG** — 동일 시드 → 동일 출력 (재현성)
2. **타입 생성기** — name/email/uuid/int/float/bool/date/enum/lorem
3. **스키마 컴파일** — 중첩 객체·배열 스키마 → 레코드 생성
4. **배치 생성** — count 지정으로 대량 생성
5. **출력 포맷** — JSON(기본), 향후 CSV/SQL

## 경쟁사
- Mockaroo, JSON Server, Faker.js(라이브러리), Mockend, json-generator

## 차별점
- 결정적(시드) 생성으로 테스트 픽스처에 바로 사용 가능
- 생성기 코어가 순수 함수라 라이브러리·API·CLI 모두 동일 동작
- 외부 의존성 없는 경량 구현 → 엣지/서버리스 배포 용이
- 한국어 이름·주소·전화번호 로케일 우선 지원(확장)

## 사용 예시
```bash
# 스키마 파일로 결정적 가짜 데이터 100건 생성
npx mockgen schema.json --count 100 --seed 42

# API 서버
npm run serve  # POST /generate { schema, count, seed }
```
출력: 동일 (스키마, count, seed) → 항상 동일한 JSON 배열
