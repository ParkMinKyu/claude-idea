# 134 · Sitemap Generator (사이트맵 자동 생성)

## 개요
시드 URL을 입력하면 같은 호스트의 내부 링크를 BFS로 크롤링해 표준 `sitemap.xml`을
자동 생성합니다. 5만 개 URL을 초과하면 사이트맵 인덱스로 자동 분할합니다. 정규화·
크롤·XML 빌드 로직을 순수 함수로 분리하고 네트워크는 주입식으로 설계해 오프라인
테스트가 가능합니다.

## 문제
- 사이트맵을 손으로 관리하면 페이지 추가/삭제 때마다 누락이 발생합니다.
- 크롤링 중복·추적 파라미터(utm 등)로 사이트맵이 지저분해집니다.
- 대형 사이트는 5만 URL 한도를 넘어 인덱스 분할이 필요합니다.
- nofollow·외부 링크 처리 규칙을 일관되게 적용하기 어렵습니다.

## 솔루션
URL 정규화(해시/슬래시/추적 파라미터 정리), 동일 호스트 한정 크롤, 표준 XML
빌드, 자동 인덱스 분할을 제공합니다. CLI/CI/예약 작업으로 주기적 재생성이 가능하며
검색엔진에 자동 핑할 수 있습니다.

## 타겟 사용자
- SEO를 챙기는 마케터·콘텐츠 팀
- 사이트맵 자동화를 원하는 개발자/에이전시
- 헤드리스 CMS·이커머스 등 페이지가 자주 바뀌는 사이트

## 핵심 기능
1. 동일 호스트 한정 BFS 크롤링 (maxPages 제한)
2. URL 정규화 및 중복/추적 파라미터 제거
3. 표준 `sitemap.xml` 생성 (lastmod/changefreq/priority)
4. 5만 URL 초과 시 사이트맵 인덱스 자동 분할
5. nofollow/외부 링크 정책 옵션
