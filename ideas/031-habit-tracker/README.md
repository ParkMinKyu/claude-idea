# 위젯 중심 습관 트래커 (Habit Widget)

## 개요
홈 화면 위젯에서 한 번의 탭으로 습관 체크인을 완료할 수 있는 초경량 습관 트래커 앱입니다.
앱을 열지 않고도 매일의 루틴을 기록할 수 있다는 점이 핵심 가치입니다.

## 문제
- 기존 습관 트래커 앱은 매번 앱을 열고 여러 화면을 탐색해야 해서 마찰이 큽니다.
- 매일 알림을 받아도 앱을 켜는 것 자체가 귀찮아서 사용자가 이탈합니다.
- 단순한 체크인 데이터를 위해 무거운 SNS형 UI를 강제하는 앱이 많습니다.

## 솔루션
- Glance API 기반 홈 화면 위젯에서 즉시 체크인.
- 위젯에서 오늘의 습관 목록과 연속 일수(streak)를 한눈에 표시.
- 앱 본체는 통계 및 습관 관리용으로만 사용.

## 타겟 사용자
- 20~40대 자기개발에 관심 많은 직장인.
- 미니멀한 UI를 선호하는 사용자.
- 운동, 독서, 명상 등 매일 반복 가능한 루틴을 가진 사람.

## 핵심 기능
1. 홈 화면 위젯에서 원탭 체크인.
2. 습관별 연속 일수(streak) 및 완료율 추적.
3. 캘린더 뷰에서 월간 기록 확인.
4. 일별 푸시 알림 (시간 커스터마이즈).
5. 다크 모드 및 위젯 테마 변경.
6. CSV 데이터 내보내기.

## 수익 모델
### 앱 내 결제 (Freemium)
- 무료: 습관 3개까지, 기본 테마.
- 프리미엄 (일회성 ₩9,900): 습관 무제한, 모든 위젯 테마, CSV 내보내기.

### 구독
- 월 ₩2,900 / 연 ₩19,000: 클라우드 백업, 다기기 동기화, 고급 통계.

### 광고
- 무료 사용자에 한해 통계 화면에서 배너 광고(AdMob).

## 경쟁사
- Habitica: 게이미피케이션 중심, 복잡함.
- Streaks (iOS): Android 미지원.
- Loop Habit Tracker: 오픈소스, 위젯이 제한적.
- HabitNow: 광고가 많고 UI가 복잡.

## 차별점
- Glance API 기반의 빠르고 가벼운 위젯 경험.
- 앱 본체보다 위젯이 중심인 설계.
- 한국 사용자에 맞춘 카카오톡 공유, 한글 폰트 최적화.
- 다양한 위젯 사이즈(1x1, 2x2, 4x2)와 테마 제공.

## KPI
- DAU/MAU 비율 50% 이상 (위젯 사용으로 일일 활성도 높음).
- 위젯 설치율 70% 이상 (앱 설치 사용자 중).
- 평균 체크인 횟수: 사용자당 일 3회 이상.
- 7일 리텐션 40%, 30일 리텐션 20%.
- 프리미엄 전환율 5% 이상.
- 앱스토어 평점 4.5 이상.
