# 079 - 클래스 예약 / 결제 플랫폼

## 개요
요가/필라테스/원데이클래스 등 소규모 강사가 본인의 클래스를 등록하고, 학생이 일정/슬롯을 골라 결제까지 한 번에 처리하는 예약 SaaS입니다. Calendly에 결제와 정원 관리가 결합된 형태입니다.

## 문제
- 강사는 인스타 DM으로 예약 받고 계좌이체 안내 → 노쇼와 결제 누락 빈번
- Calendly는 결제 연동이 약하고 정원(class size) 개념이 없음
- 네이버 예약은 진입장벽 높고 수수료 구조 불투명
- 환불/취소 정책이 강사마다 달라 분쟁 발생

## 솔루션
- 강사가 클래스(제목/설명/길이/정원/가격) 등록
- 캘린더에 반복 슬롯 자동 생성 (요일/시간 기반)
- 학생이 슬롯 선택 → Stripe 결제 → 자동 확인 이메일/SMS
- 노쇼 방지: 결제 시점 환불 정책 명시, 시작 24h 전 취소 가능

## 타겟 사용자
- 요가/필라테스 1인 강사, 작은 스튜디오
- 베이킹/캘리그래피 원데이클래스 운영자
- PT 트레이너 (1:1 세션 예약)
- 외국어 튜터 (1:1 온라인)

## 핵심 기능
1. 클래스 CRUD + 반복 일정 (Cron pattern)
2. 학생 셀프 예약 + Stripe Checkout 결제
3. 정원 관리 + 자동 마감
4. 취소/환불 정책 설정 (시작 N시간 전까지 환불)
5. 자동 리마인더 이메일 (24h 전, 1h 전)
6. 강사 대시보드 (수강생 리스트, 매출, 환불)

## 수익 모델
| 티어 | 가격 | 수수료 |
|------|------|------|
| Free | $0 | 거래당 5% (+ Stripe 수수료) |
| Pro | $19/월 | 거래당 2%, 무제한 클래스 |
| Studio | $49/월 | 0%, 강사 5명, 자체 도메인 |

추가: 광고 없음, 수강생 데이터 100% 강사 소유.

## 경쟁사
- Calendly + Stripe Payment Link: 통합 약함, 정원 관리 없음
- Acuity Scheduling: 글로벌 강자, 한국어 미지원
- MindBody: 대형 스튜디오용, 비싸고 복잡
- 네이버 예약: 진입장벽 높음, 검색 의존

## 차별점
- 1인 강사 타겟 — Calendly의 단순함 + 정원/결제 통합
- 한국어 + 카카오톡 알림 (Phase 2)
- 환불 정책을 슬롯별로 차등 설정 (오프라인 vs 온라인)
- 강사 자체 페이지(slug) 자동 제공 — 인스타 링크용

## 핵심 지표 (KPI)
- 강사 활성 수 (월 1회 이상 클래스 운영)
- 학생 결제 전환율 (페이지 방문 → 결제)
- 노쇼율 (목표 5% 미만)
- 환불율 (목표 3% 미만)
- 클래스당 평균 정원 충족률 (목표 70% 이상)
- Free → Pro 전환 (월 거래 $1,000 시점)

## 출시 로드맵
- M1: 클래스 등록 + 학생 셀프 예약 + Stripe 결제
- M2: 환불 정책 자동 평가, 자동 리마인더 이메일
- M3: 카카오 알림톡 연동, Google Calendar 양방향 동기화
- M4: 패키지(N회권), 멤버십, 그룹 디스카운트
- M5: 강사 자체 도메인 매핑, 다국어(영어/일본어) 학생 페이지
