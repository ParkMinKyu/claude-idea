# 140 · PR Size Labeler (PR 크기 자동 라벨)

## 개요
풀 리퀘스트의 diff 통계를 분석해 `size/XS`~`size/XXL` 라벨을 자동으로 부여하는
도구입니다. 락파일·생성물·벤더 디렉터리는 "유효 변경량"에서 제외해 실제 리뷰
부담을 더 정확히 반영합니다. diff 파싱과 라벨 결정 로직이 순수 함수라 GitHub
Action·봇·CI 어디서나 재사용됩니다.

## 문제
- 큰 PR은 리뷰가 늦고 품질이 떨어지지만 크기를 한눈에 알기 어렵습니다.
- 락파일/생성물 수천 줄이 PR 크기를 왜곡합니다.
- 수동 라벨링은 일관성이 없고 빠뜨리기 쉽습니다.
- "너무 큰 PR을 쪼개라"는 신호를 자동화하기 어렵습니다.

## 솔루션
unified diff를 파싱해 파일별 추가/삭제를 집계하고, 무시 패턴을 적용한 유효
변경량으로 라벨을 결정합니다. 임계 초과 시 분할 권고 플래그를 함께 반환해 리뷰
워크플로를 개선합니다.

## 타겟 사용자
- 코드 리뷰 효율을 높이려는 엔지니어링 팀
- 오픈소스 메인테이너(기여 PR 분류)
- 플랫폼/DevEx 팀(리뷰 SLA 관리)

## 핵심 기능
1. unified diff 파싱 (추가/삭제, 리네임 처리)
2. 락파일/생성물/벤더 제외 "유효 변경량" 계산
3. XS~XXL 라벨 자동 결정 (임계 커스터마이즈)
4. 대형 PR 분할 권고 플래그
5. GitHub Action / CLI(stdin) 통합

## 수익 모델 (가격 티어)
- Free / OSS: 공개 리포 무료
- Pro ($4/리포/월): 사설 리포, 커스텀 임계/무시 규칙
- Team ($29/월): 조직 정책, 리뷰 통계 대시보드, 분할 권고 봇
- Enterprise (협의): 셀프호스트, 감사, SSO

## 경쟁사
- GitHub `pascalgn/size-label-action` 등 오픈 액션
- CodeClimate/리뷰 도구의 부분 기능
- 자체 스크립트 조합

## 차별점
- 락파일/생성물 제외로 "실제 리뷰량"에 가까운 라벨
- 파서/결정 로직을 순수 함수로 분리해 봇·CI·엣지 재사용
- 분할 권고 등 워크플로 액션까지 제공
- 임계/무시 규칙을 조직 단위로 표준화

## KPI

- 분할 권고 후 실제 분할률
- 리뷰 소요 시간(라벨별), Free→Pro 전환율
- 조직 정책 채택 리포 수
