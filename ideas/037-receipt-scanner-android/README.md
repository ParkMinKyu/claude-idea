# 모바일 영수증 보관/검색 (ReceiptVault)

## 개요
종이 영수증을 사진으로 찍으면 OCR로 가맹점·금액·날짜를 추출해 카테고리화하고,
나중에 자유롭게 검색할 수 있는 모바일 영수증 아카이브.

## 문제
- 종이 영수증은 보관이 번거롭고 잃기 쉽습니다.
- 연말정산, 사업자 비용 처리에 영수증 검색이 어렵습니다.
- 카드 결제 내역만으로는 어떤 상품을 샀는지 기억하기 어려움.

## 솔루션
- 카메라로 영수증 촬영 → ML Kit OCR로 텍스트 추출.
- 가맹점/금액/날짜 자동 파싱.
- 검색 (가맹점, 금액 범위, 날짜, 메모).
- PDF/CSV 내보내기.
- 클라우드 백업 옵션.

## 타겟 사용자
- 자영업자, 프리랜서 (사업비 영수증 보관).
- 연말정산이 복잡한 직장인.
- 보증/환불 영수증을 보관해야 하는 일반 사용자.

## 핵심 기능
1. 카메라 촬영 → OCR → 자동 필드 추출.
2. 영수증 이미지 + 파싱 데이터 저장.
3. 키워드/금액/날짜 검색.
4. 태그(사업용, 의료비, 교육비 등).
5. PDF/CSV 내보내기.
6. 클라우드 백업 (옵션).

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩12,900: 무제한 저장, OCR 무제한, 광고 제거.

### 구독
- 월 ₩3,900: 클라우드 백업 (무제한), 팀 공유, OCR API 고급(영수증 외 송장).

### 광고
- 무료 사용자에게 보관 50개 제한 + 배너 광고.

## 경쟁사
- Expensify: 글로벌, 한국 지원 약함.
- 캠스캐너: 일반 스캐너, 영수증 특화 부족.
- 신한 SOL 영수증 보관: 신한 사용자 전용.

## 차별점
- 한국 영수증 포맷 (사업자번호, 부가세) 최적화.
- 오프라인 OCR (ML Kit) - 데이터 외부 전송 없음.
- 카테고리 자동 분류 + 연말정산용 보고서 템플릿.

## KPI
- 평균 월 영수증 스캔 15건/유저.
- OCR 정확도 92%+ (한글 영수증).
- 30일 리텐션 30%.
- 프리미엄 전환율 6%.
- 평점 4.5 이상.
