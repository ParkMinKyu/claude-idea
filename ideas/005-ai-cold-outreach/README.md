# 005 - 링크드인 프로필 기반 콜드메일 생성

## 개요
타겟의 LinkedIn URL 또는 프로필 텍스트를 입력하면, 발신자의 제품/서비스 설명과 결합해 개인화된 콜드메일을 자동 생성합니다. 단순 템플릿이 아닌, 상대방의 경력·관심사·최근 활동을 반영한 진짜 1:1 메일.

## 문제
- B2B 영업/리크루팅에서 콜드메일 회신율 평균 1~5%
- 회신율을 올리려면 개인화 필요하지만, 1통당 10~15분 소요 → 하루 20통이 한계
- 템플릿만 쓰면 회신율 1% 이하

## 솔루션
- LinkedIn URL 붙여넣기 → 공개 프로필 정보 파싱 (또는 텍스트 직접 입력)
- 발신자 정보(회사, 제품, 가치 제안) 1회 등록
- Claude가 상대방의 경력에서 hook을 잡아 자연스러운 메일 생성
- A/B 테스트용 3가지 톤(친근/전문가/유머) 동시 생성

## 타겟 사용자
- B2B SaaS 영업 (SDR, AE)
- 헤드헌터/리크루터
- 1인 컨설턴트 (잠재 고객 발굴)
- VC associates (스타트업 발굴 outreach)

## 핵심 기능
1. LinkedIn 프로필 입력 (URL 또는 텍스트)
2. 발신자 프로필 저장 (제품/가치제안/원하는 액션)
3. 3가지 톤 메일 동시 생성
4. 후속 메일(follow-up) 시퀀스 자동 생성
5. (Pro) Gmail 발송 + 회신 추적

## 수익 모델
| 티어 | 가격 | 한도 |
|------|------|------|
| Free | $0 | 월 10통 |
| Starter | $19/월 | 월 200통 |
| Pro | $49/월 | 월 1000통, 시퀀스, Gmail 연동 |
| Team | $99/사용자/월 | CRM 연동, 팀 템플릿 |

## 경쟁사
- Lavender: 콜드메일 코칭, $29~
- Lemlist: 시퀀스 자동화 중심
- Apollo.io: DB + outreach, 가격 부담
- Instantly: 대량 발송 중심, 개인화 약함

## 차별점
- LinkedIn → 메일 1단계 워크플로우 (다른 도구는 데이터/발송 분리)
- Claude의 hook 발굴 능력 (단순 "X대학 출신이시네요" 수준이 아닌, 최근 발표/이직 등 깊이 있는 개인화)
- 3가지 톤 동시 제공 → 사용자가 데이터로 톤 선택 가능
- 한국어 비즈니스 메일 톤 강점

## 핵심 지표 (KPI)
- 사용자당 월 평균 발송 통 수
- 회신율 (사용자 자가 보고 + 추적)
- Free → Starter 전환율 (목표 12%)
- 월간 retention (목표 75%)
- 시퀀스 사용률 (Pro 가치 검증)
- NPS (영업 사용자 특성상 추천 영향 큼)

## 향후 로드맵
- M1: 단일 콜드메일 생성 (MVP)
- M2: 후속 시퀀스 자동 생성
- M3: Gmail 발송 + 회신 추적
- M4: CRM(Hubspot, Salesforce) 연동

## 리스크와 대응
- LinkedIn ToS 위반 우려 → 사용자가 직접 텍스트 붙여넣는 방식 (스크래핑 X)
- 스팸 분류 위험 → 발송은 사용자 Gmail에서, 대량 발송 차단
- 회신율은 산업/타겟별 큰 편차 → 사용자별 개인 베이스라인 비교 리포트로 가치 입증
