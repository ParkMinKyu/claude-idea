# 023 · 제품 로드맵 투표

## 개요
사용자가 기능 요청을 올리고 다른 사용자가 투표하는 공개 로드맵 SaaS. 우선순위 가시화와 사용자 참여 동시 달성.

## 문제
- Canny·Featurebase는 핵심 기능부터 월 $50+로 비싸다.
- GitHub Issues는 비개발자 진입장벽이 높고 시각화가 빈약하다.
- 직접 만들면 인증·중복 투표 방지·로드맵 보드까지 떠안게 된다.

## 솔루션
- 공개 보드: Backlog / Planned / In Progress / Shipped
- 이메일 인증으로 1인 1투표
- 관리자: 상태 변경 시 투표자에게 자동 이메일
- Slack/Discord 연동: 신규 요청·완료 알림

## 타겟 사용자
- SaaS PM·CS 팀
- 오픈소스 프로젝트 메인테이너
- 사내 IT 부서(직원 요청 접수)

## 핵심 기능
1. **공개 로드맵 보드** — 4단계 칸반
2. **투표/댓글** — 이메일 인증, 우선순위 가시화
3. **상태 변경 자동 알림** — 투표자에게 진척 메일
4. **태그·필터** — 카테고리, 우선순위, 우리/그들
5. **API & 임베드** — 사이트에 요청 폼 임베드

## 수익 모델
| 플랜 | 가격 | 보드 | 사용자 | 비공개 보드 |

| Free | $0 | 1 | 무제한 | X |
| Starter | $19/월 | 3 | 무제한 | O |
| Growth | $49/월 | 무제한 | 무제한 | + 멤버 + API |
| Business | $129/월 | 무제한 | 무제한 | + SSO |

## 경쟁사
- Canny, Featurebase, ProductBoard, Frill, Sleekplan

## 차별점
- 한국어 UI/이메일 템플릿 기본
- Frill 대비 임베드 위젯 더 가벼움(15KB → 8KB)
- 무료 플랜에 비공개 댓글·관리자 노트 허용
- 투표 → 출시 워크플로우 자동화(상태 변경 시 메일/Slack)

## KPI
- 보드 활성화 후 30일 내 투표 100+ 비율 40%
- 게시물 평균 투표 수 8+
- 무료 → 유료 전환율 5%+
- 상태 변경 → 투표자 응답률 15%+
- 30일 잔존율 70%+
