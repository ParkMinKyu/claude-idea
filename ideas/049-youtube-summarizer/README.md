# 049 - YouTube Summarizer

YouTube 영상의 자막을 추출해 Claude API로 요약·챕터·핵심 인용구를 만들어주는 Chrome Extension.

## 개요
긴 영상(강의, 인터뷰, 뉴스)을 보기 전에 5-10초 요약, 챕터, 핵심 인용을 사이드패널로 제공합니다. 사용자가 영상의 가치를 빠르게 판단하고, 필요한 구간만 점프 재생할 수 있습니다.

## 문제
- 1시간짜리 영상이 알고리즘에 의해 추천되는데, 시청 전에 가치를 알기 어려움
- 자막은 영어가 많고 한국어 요약은 거의 없음
- 챕터가 없는 영상은 원하는 구간을 찾기 어려움

## 솔루션
- YouTube 트랜스크립트 API 호출 → 텍스트 추출
- Claude API에 보내 요약 + 챕터 + 핵심 인용 생성
- 결과를 영상 옆 사이드패널/팝업에 렌더
- 챕터 클릭 시 해당 timestamp로 점프

## 타겟
- 영어 강의/팟캐스트 시청자
- 학습자, 리서처
- 영상 콘텐츠 큐레이터

## 핵심 기능
- 1-클릭 요약 (3가지 길이: 짧음/보통/자세히)
- 자동 챕터 생성 + 타임스탬프 점프
- 핵심 인용 5개
- 한국어 자동 번역 (Pro)
- 시청 기록에 요약 저장

## 수익 모델
- BYOK (Bring Your Own Key): 사용자가 자기 Claude API 키 입력 시 무료
- Hosted Free: 일 5회 요약 (당사 키)
- Pro ($6.99/월):
  - 일 100회
  - 자동 번역 / 다국어
  - 영상 히스토리 저장 + 검색
  - PDF/마크다운 export

## 경쟁사
- Eightify ($9.99/월)
- Summarize.tech
- YouTube 공식 AI 챕터 (미국 한정 베타)

## 차별점
- BYOK 옵션 (사용자가 비용 통제)
- 한국어 우선 (한글 자막 + 한국어 출력)
- Claude 4.7 1M 컨텍스트로 풀 트랜스크립트 처리

## KPI
- 요약 / 사용자 / 일
- BYOK vs Hosted 비율
- Pro 전환율 (목표 4%)
- 평균 절약 시간 (영상 길이 - 요약 읽기 시간)
