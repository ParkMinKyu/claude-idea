# 071 · 인디 작가 오디오북 플랫폼

## 개요
독립 출판 작가가 자기 책을 오디오북으로 직접 출판·판매할 수 있는 마켓플레이스. 작가는 자기 목소리·성우 외주·AI 합성(허용 가능 라이선스 한해) 중에서 선택하고, 청취자는 챕터 단위 결제 또는 월 구독으로 듣는다.

## 문제
- 윌라/밀리의 서재는 대형 출판사 위주이며, 인디 작가의 입점이 까다롭다.
- Audible(글로벌)은 ACX 가입이 한국 작가에 어렵고 한국어 시장이 작다.
- 작가가 직접 오디오북을 만들려면 챕터 분할·메타데이터(M4B)·DRM 등 기술 부담이 크다.
- 청취자는 책 단위 ₩20,000 결제가 부담스러워 첫 구매가 어렵다.

## 솔루션
- 작가용 업로드: MP3/M4A 챕터 업로드 → 자동 M4B 생성 + 챕터 마커
- AI 합성 옵션: 작가가 자기 책 텍스트를 업로드하면 라이선스 검증된 한국어 TTS로 샘플 생성
- 청취자: 첫 챕터 무료 → 챕터·전권·구독 결제 옵션
- 워터마크(가청 임계 이하 PRNG)로 유출 추적

## 타겟 사용자
- 독립 출판 / 인디 작가 (소설·자기계발·에세이)
- 출퇴근·운동 중 음성 콘텐츠를 듣는 30~40대
- 1인 출판사·번역가

## 핵심 기능
1. **챕터 업로드 + M4B 생성** — 챕터 마커·메타데이터 자동 삽입
2. **샘플 자동 추출** — 첫 5분 자동 클립 (구매 전 미리듣기)
3. **유연한 결제** — 챕터 ₩500~/ 전권 / 월 구독 ₩9,900
4. **재생 위치 동기화** — 디바이스 간 책갈피
5. **워터마킹** — 사용자 ID 기반 오디오 워터마크 삽입

## 수익 모델
| 채널 | 가격/수수료 |
|---|---|
| 청취자 단권 구매 | 작가 가격 책정, 플랫폼 수수료 25% |
| 챕터 구매 | 챕터당 ₩500~ |
| 무제한 구독 | ₩9,900/월, 작가 정산은 청취 시간 비례 |
| AI TTS 옵션 | 분당 ₩30 작가 비용 (라이선스 포함) |

## 경쟁사
- 윌라, 밀리의 서재(오디오), 오디언, Audible, Audiobookstore

## 차별점
- 입점 장벽 거의 없음 + 작가 정산 비율 75% (윌라 50% 수준 대비)
- 챕터 단위 마이크로 결제 (Audible/윌라는 권 단위 또는 구독만)
- 청취 시간 기반 정산 (구독 풀에서 비례 분배)
- 오디오 워터마킹으로 작가 권리 보호

## KPI
- 첫 작품 출판까지 평균 < 30분 (업로드 + 메타데이터)
- 무료 첫 챕터 → 유료 전환율 8% 이상
- 월 구독 잔존 12개월 50% 이상
- 작가 1인당 월 평균 정산 ₩100,000 이상
- 평균 작품 평점 4.0+ (5점 만점)

## 사용 시나리오
1. 자기계발 작가가 자기 책을 직접 녹음 → 챕터당 ₩1,000 판매 → 월 ₩300,000 정산
2. 출퇴근 청취자가 ₩9,900 구독으로 무제한 청취
3. 인디 소설가가 AI TTS로 시제품을 빠르게 출시 후 반응 좋으면 성우 외주

## MVP 범위
- v0.1: 챕터 업로드 + 구매 + 재생 + 워터마크
- v0.2: 무제한 구독 + 청취 시간 정산
- v0.3: 자동 트랜스크립트 + 다국어
- v1.0: AI TTS 옵션 + 작가 분석 대시보드

## 리스크 / 가정
- 오디오북 DRM은 완벽하지 않음 → 워터마크 + 신뢰 기반 운영
- TTS 라이선스 분쟁: 합법 한국어 TTS 공급사 화이트리스트 운영
- 청취 시간 정산 어뷰징: 봇 탐지 + 정산 상한선

## 운영 / 컴플라이언스
- 출판 ISBN/ISRC 등록 옵션 안내
- 음원 저작권 분쟁 처리 SLA + 가이드
- 작가 정산 사업자/기타소득 처리 자동 분류
