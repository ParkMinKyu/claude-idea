# 132 · Favicon Generator (파비콘 멀티사이즈 생성)

## 개요
하나의 고해상도 소스 이미지를 업로드하면 브라우저·iOS·Android·Windows 타일에
필요한 모든 파비콘 사이즈를 자동 생성하고, 웹 앱 매니페스트(`site.webmanifest`)와
HTML `<head>` 링크 태그까지 한 번에 만들어 주는 도구입니다. 사이즈 계획과
매니페스트/태그 생성 로직은 순수 함수로 분리해 어디서든 재사용 가능합니다.

## 문제
- 파비콘은 16px부터 512px까지 표준 사이즈가 제각각이라 수작업이 번거롭습니다.
- iOS `apple-touch-icon`, Android 매니페스트, MS 타일 메타 규칙이 모두 다릅니다.
- 작은 소스를 업스케일하면 흐릿한 아이콘이 배포됩니다.
- 올바른 `<head>` 태그 세트를 빠뜨리면 일부 플랫폼에서 아이콘이 깨집니다.

## 솔루션
소스 한 장에서 "업스케일 금지" 규칙으로 가능한 사이즈만 골라 리사이즈하고,
PWA 호환 매니페스트와 정확한 HTML 태그를 생성합니다. 결과를 ZIP으로 내려받거나
CDN에 직접 게시할 수 있습니다.

## 타겟 사용자
- 새 사이트/앱을 빠르게 런칭하는 개인 개발자와 인디 메이커
- 다수 클라이언트 사이트를 관리하는 에이전시
- 디자인 자산 파이프라인을 자동화하려는 프런트엔드 팀

## 핵심 기능
1. 소스 → 표준 멀티사이즈 파비콘 자동 생성 (업스케일 방지)
2. PWA 호환 `site.webmanifest` 생성
3. 정확한 `<head>` 링크/메타 태그 생성 (apple/android/MS 포함)
4. ZIP 다운로드 및 CDN 직접 게시
5. 가장 가까운 비업스케일 소스 선택 로직

- 의존성 최소화로 서버리스 환경에서 가볍게 동작
