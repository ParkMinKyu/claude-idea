# TECH STACK · 128 코드 → 이미지

## 언어 / 런타임
- **Node.js 20+** (ESM) — 서버리스/엣지 배포 친화
- 외부 의존성 0 (SVG 문자열 직접 생성)

## 코어 아키텍처
- `src/tokenizer.js` — 언어 무관 휴리스틱 토크나이저 (문자열/주석/키워드/숫자/일반)
- `src/themes.js` — 색상 팔레트 정의 (배경/전경/토큰 색)
- `src/render.js` — 토큰 → SVG. 폰트 메트릭(고정폭) 기반 레이아웃, 윈도우 크롬, 라인 넘버
- `src/escape.js` — XML 이스케이프 유틸
- `src/cli.js` — 파일/스탠다드 입력 → SVG 파일 출력

## 렌더링 모델
- 고정폭 폰트 가정(`ch` 단위) → 글자폭 = fontSize * 0.6 휴리스틱
- 줄 높이 = fontSize * 1.5
- 캔버스 크기 = 가장 긴 줄 + 패딩, 줄 수 * 줄 높이 + 헤더

## 토크나이저 (휴리스틱)
- 더블/싱글 쿼트 문자열, `//` 및 `#` 라인 주석, 숫자, 키워드 화이트리스트
- 정확한 파싱이 목표가 아니라 "보기 좋은 하이라이트"가 목표

## 테스트
- **vitest** — 토크나이저 분류, 이스케이프, SVG 출력 구조(요소 포함 여부, 줄 수)를 검증. 브라우저 불필요

## 배포 / 인프라 (프로덕션 계획)
- API: Cloudflare Workers / Vercel Edge (SVG 반환)
- PNG 변환(옵션): resvg-wasm 또는 sharp(노드)
- 캐시: 입력 해시 기반 CDN 캐시
