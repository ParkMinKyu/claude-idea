# 082 - 어필리에이트 링크 클로커 / 트래커

## 개요
인플루언서/크리에이터가 사용하는 여러 어필리에이트 링크를 짧고 깨끗한 도메인으로 클로킹하고, 클릭 수/지역/유입경로 통계를 한 곳에서 보는 SaaS입니다. Linktree + Pretty Links의 기능을 가볍게 통합합니다.

## 문제
- Amazon/Coupang 등 어필리에이트 URL은 길고 못생겨 SNS 공유 어려움
- 어느 콘텐츠/플랫폼에서 클릭이 나오는지 추적 불가
- 다수 프로그램의 통계를 매번 각자 대시보드에서 확인해야 함
- 링크 만료/리다이렉트 깨짐을 모니터링하지 못함

## 솔루션
- 사용자 단일 도메인(예: go.user.com)으로 모든 어필리에이트 링크 클로킹
- 슬러그 단축 + UTM 자동 부여 + 만료/타겟 변경 시 1곳에서 수정
- 클릭 분석: 시간대, 국가, 디바이스, 유입 URL
- 깨진 링크 자동 알림 (HTTP 4xx/5xx 모니터링)

## 타겟 사용자
- 블로그/유튜브 크리에이터, 인플루언서
- 어필리에이트 마케터, 콘텐츠 크리에이터
- 작은 미디어/뉴스레터 운영자

## 핵심 기능
1. 링크 단축 + 슬러그 커스터마이징
2. 다중 어필리에이트 프로그램 지원 (Coupang, Amazon, AliExpress, iHerb)
3. 클릭 분석 대시보드 (시간/국가/디바이스/유입)
4. 링크 만료/리다이렉트 모니터링
5. 그룹/태그 (콘텐츠별 묶음)
6. (Phase 2) A/B 분기 — 동일 슬러그에 2개 타겟 분배

## 수익 모델
| 티어 | 가격 | 한도 |
|------|------|------|
| Free | $0 | 링크 25개, 분석 7일 |
| Pro | $9/월 | 무제한 링크, 90일, 자체 도메인 |
| Business | $29/월 | 5 시트, 90일+API, A/B 테스트 |

추가: 거래 수수료 없음 (어필리에이트 수익은 사용자 100% 소유).

## 경쟁사
- Pretty Links (WordPress): 플러그인, 다중 사이트 어려움
- Bitly: 일반 단축, 어필리에이트 분석 약함
- Geniuslink: 다국가 라우팅 강점, 가격 부담 ($10+)
- ThirstyAffiliates: WordPress 의존

## 차별점
- 자체 도메인 1개로 모든 플랫폼 (블로그/유튜브/인스타) 통합
- 어필리에이트 프로그램별 utm/태그 자동 부여
- 한국 사용자 친화 (Coupang Partners 직링크 지원)
- 가벼운 가격 + 깨진 링크 알림 — 운영 부담 절감

## 핵심 지표 (KPI)
- 활성 사용자 (월 1+ 클릭 발생 링크 보유)
- 누적 단축 링크 수
- 평균 사용자당 월간 클릭
- Free → Pro 전환율 (목표 8%)
- 깨진 링크 비율 (목표 1% 미만)
- 자체 도메인 사용률 (목표 50% 이상)
