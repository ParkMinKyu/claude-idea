# 096 · SaunaDispatch — 헬스장 락커/타올 관리 SaaS

## 개요
헬스장·사우나·요가 스튜디오에서 락커 배정, 타올/가운 대여, 회원 체크인을 한 화면에서 관리하는 운영 도구. 데스크 직원이 종이 장부와 엑셀에서 벗어나 모바일·태블릿으로 즉시 처리하도록 만든다.

## 문제
- 락커 키를 분실하거나 중복 배정되면 회원 컴플레인으로 직결되지만, 대부분 매장은 화이트보드 + 종이 명단에 의존한다.
- 타올·가운 재고가 어디서 새는지 추적이 안 돼서 월 손실이 수십만원 규모인데, 일반 POS는 이런 대여물품을 지원하지 않는다.
- 회원 PT/사우나 잔여 횟수 파악이 어려워 환불 분쟁이 잦다.
- 기존 솔루션(체크인 키오스크)은 락커·타올 회수 흐름을 다루지 않는다.

## 솔루션
- 락커 그리드 뷰: 비어있음/사용중/청소필요 상태를 색으로 즉시 표시
- 타올 대여 시 회원 ID에 자동 연결, 미반납 시 다음 방문에 알림
- 회원 권종(시즌권, 횟수권) 잔여를 체크인 시 자동 차감
- 직원 인계 시 교대 보고서 자동 생성(미반납·청소대기 락커 요약)

## 타겟 사용자
- 회원 200~3000명 규모 동네 헬스장·필라테스·요가 스튜디오
- 호텔/리조트 내 사우나·스파 운영팀
- 골프 연습장·실내 클라이밍 짐 같은 락커가 핵심인 시설

## 핵심 기능
1. **락커 관리** — 락커 번호별 상태(idle/in_use/dirty) 토글, 회원 매핑, 자동 만료 알림
2. **대여 트래킹** — 타올/가운/슬리퍼 출고와 회수, 미반납 리포트
3. **체크인/체크아웃** — 회원 검색 → 락커 배정 → 권종 차감을 1 화면에서
4. **권종 관리** — 시즌권, 10회권, 무제한권 잔여 자동 계산
5. **운영 리포트** — 일별 매출, 락커 회전율, 분실 타올 수 요약

- 모바일 우선 UI — 데스크에 PC 없이 태블릿 한대로 운영 가능
- 한국 헬스장 권종(시즌·횟수) 모델 기본 지원
- 월 39,000원부터 시작하는 소형매장 친화 가격

- 30일 잔존율(매장) 85% 이상
- ARR per 매장 ₩1,200,000 이상
