# 092 · 스크린샷 OCR + 검색 (Screenshot Organizer)

## 개요
스크린샷 폴더(`~/Desktop`, `~/Screenshots`)를 자동 감시하고 Tesseract OCR로 텍스트를 추출해, "그 디자인 시안 어디 있더라" 같은 자연어 검색이 가능한 데스크톱 앱.

## 문제
- 스크린샷이 매일 쌓이지만 파일명이 `Screenshot 2026-05-18 at 14.32.55.png` → 검색 불가
- 디자인 시안, 에러 메시지, 인용구 등이 모두 시각 정보로만 존재
- 클라우드 OCR 서비스는 프라이버시 우려 + 비용

## 솔루션
- 폴더 감시 → 새 PNG/JPG에 OCR 자동 적용
- 추출된 텍스트는 로컬 SQLite FTS5 인덱싱
- 메뉴바 검색 (`Cmd+Shift+G`)로 즉시 찾기
- 한국어/영어/일본어 멀티 언어 모델

## 타겟 사용자
- 디자이너, PM (시안 관리)
- 개발자 (에러 메시지 캡처 검색)
- 학생·연구자 (PDF·강의자료 캡처)

## 핵심 기능
1. **자동 폴더 감시** — chokidar로 스크린샷 폴더 워치
2. **OCR 파이프라인** — Tesseract.js 워커풀, GPU 가속 옵션
3. **풀텍스트 검색** — FTS5, 결과는 썸네일 + 매치 하이라이트
4. **태그/컬렉션** — 수동 태깅 + 자동 분류 (앱/색감 기반)
5. **클립보드 검색** — 클립보드 이미지도 임시 OCR 가능
