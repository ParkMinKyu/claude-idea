# 136 · Email Template Tester (이메일 HTML 렌더 테스트)

## 개요
이메일 HTML을 정적 분석해 주요 메일 클라이언트(Outlook, Gmail, Apple Mail 등)에서
깨질 수 있는 패턴을 찾아내는 도구입니다. flex/grid, 외부 스타일시트, `<script>`,
Gmail 클리핑 한도 초과 등 잘 알려진 비호환 사례를 규칙으로 인코딩해 즉시 경고합니다.
규칙 엔진은 순수 함수라 CI에 쉽게 통합됩니다.

## 문제
- 이메일 HTML은 웹 표준과 다르게 클라이언트별 지원이 제각각입니다.
- Outlook은 Word 렌더링 엔진이라 flex/grid·position이 깨집니다.
- Gmail은 102KB를 넘으면 본문을 잘라(clip) 추적/CTA가 사라집니다.
- 실제 발송 전에 호환성을 검증할 자동화 수단이 부족합니다.

## 솔루션
HTML을 파싱해 클라이언트별 위험 패턴을 탐지하고 심각도(error/warning/info)와 함께
영향을 받는 클라이언트를 알려줍니다. CLI/CI 게이트로 발송 전에 회귀를 차단하고,
크기 한도·alt 누락 등 실무 체크리스트를 자동화합니다.

## 타겟 사용자
- 마케팅 이메일/뉴스레터를 만드는 그로스·CRM 팀
- 트랜잭션 이메일 템플릿을 관리하는 개발자
- 이메일 디자인 시스템을 운영하는 에이전시

## 핵심 기능
1. 클라이언트별 비호환 패턴 탐지 (flex/grid, 외부 CSS, script 등)
2. 심각도 분류 및 영향 클라이언트 표시
3. Gmail 클리핑(102KB) 등 크기 한도 경고
4. img alt/width 누락 등 접근성·렌더 체크
5. CLI exit code 기반 CI 게이트
