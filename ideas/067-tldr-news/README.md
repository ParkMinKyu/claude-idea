# 067 · 카테고리별 뉴스 요약 뉴스레터 (TLDR-Korea)

## 개요
"5분이면 오늘 흐름이 보이는" 한국어 뉴스 요약 뉴스레터. 사용자가 IT, 스타트업, 금융, 디자인 등 관심 카테고리를 고르면 매일 아침 6시 30분 RSS 수집 → Claude 요약 → 발송한다.

## 문제
- 미디어 사이트는 광고·자극적 헤드라인이 많아 빠른 정보 흡수가 어렵다.
- TLDR(영문) · Morning Brew는 한국 시장과 한국어 뉴스를 다루지 않는다.
- 한국어 큐레이션 뉴스레터(어피티, NEWNEEK 등)는 일반 독자 톤이라 카테고리 깊이가 얕다.
- RSS 리더는 직접 읽고 정리해야 해서 시간이 많이 든다.

## 솔루션
- 카테고리별 RSS 50~100개를 매일 자정~새벽 1시 수집
- Claude(Sonnet)에 "3줄 요약 + 한 줄 시사점" 프롬프트로 요약
- 중복 탐지(시멘틱 + URL 정규화) 후 카테고리당 7~10개 큐레이션
- 06:30 KST에 사용자 선호 카테고리 합본 발송

## 타겟 사용자
- IT/스타트업 종사자, 마케터, PM
- 출퇴근 시간(7~8시)에 빠르게 정보 흡수하고 싶은 직장인
- 영어 TLDR을 구독 중이지만 한국어 시장 정보가 부족한 독자

## 핵심 기능
1. **RSS 수집 워커** — `node-cron` 0시 시작, 카테고리별 fetch + 정규화
2. **LLM 요약** — Claude API로 헤드라인·3줄·한 줄 시사점 생성 (캐싱)
3. **중복 제거** — 제목 임베딩 코사인 유사도 0.85+ 묶기
4. **카테고리 구독 관리** — 사용자가 IT/금융/디자인/스타트업 등 토글
5. **광고 슬롯** — 카테고리당 1개의 스폰서 슬롯 (CPM 정산)

## 수익 모델
| 구분 | 가격 | 비고 |
|---|---|---|
| 무료 구독 | $0 | 카테고리당 광고 1개 포함 |
| Pro | ₩4,900/월 | 광고 제거 + 카테고리 무제한 + 주말판 |
| 스폰서 광고 | CPM ₩30,000~ | 카테고리·노출 수 기반 |
| 채용 슬롯 | ₩300,000/주 | IT/스타트업 카테고리 한정 |

## 경쟁사
- 어피티, NEWNEEK, 미라클레터, TLDR Korea(영문)
- 카테고리 뉴스레터: BYTE, 디독, 까탈로그

## 차별점
- 카테고리 조합 자유 + Pro는 광고 제거 (어피티/NEWNEEK은 단일 편집판)
- LLM 요약 + 휴먼 검수 하이브리드 (모든 요약은 발송 전 편집자 1차 검토)
- 원문 링크에 reading time + 요약 신뢰도 점수 표시
- API 제공으로 사내 인트라넷 임베드 가능 (B2B)

## KPI
- 일일 발송 도달률 95% 이상, 오픈율 35% 이상
- 7일 잔존율 70%, 30일 60%
- 무료 → Pro 전환율 3% 이상
- 카테고리당 평균 광고 CTR 1.5% 이상
- 발송 1건당 요약 토큰 비용 < ₩30 (Claude 캐싱 활용)
- ARR per active reader ₩60,000 이상 (Pro + 광고 평균)

## 사용 시나리오
1. 마케터가 IT + 스타트업 카테고리 구독 → 매일 출근길 5분 흡수 → 팀 슬랙에 공유
2. PM이 디자인 + 프로덕트 카테고리 구독 → 주간 회의 화두 잡기
3. B2B 영업: 컨설팅사 사내에 산업별 요약 임베드 (월 ₩300,000)

## MVP 범위
- v0.1: 1개 카테고리(IT) RSS 수집 → 단일 발송
- v0.2: Claude 요약 + 중복 제거 + 4개 카테고리
- v0.3: 사용자 카테고리 선택 + Pro 광고 제거
- v1.0: B2B API + 사내 인트라넷 임베드 위젯

## 리스크 / 가정
- RSS 미지원·partial RSS 매체 대응: 자체 크롤러 fallback 필요
- 저작권: 헤드라인+3줄 요약은 공정 사용 범위, 본문 인용은 금지
- Claude 비용 급증 시: 다단계 fallback (Sonnet → Haiku → 룰베이스)

## 운영 / 컴플라이언스
- 출처 표기 + 원문 링크 의무 (저작권법 28조 공정 인용 가이드 준수)
- 광고 표기 [광고] 자동 prefix
- 저작권자 요청 시 즉시 색인 제거 SLA 24h
