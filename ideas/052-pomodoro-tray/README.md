# 052 - Pomodoro Tray

트레이/메뉴바 상주형 포모도로 타이머 Electron 앱.

## 개요
화면 한 켠에서 조용히 작업/휴식 사이클을 관리해주는 메뉴바 앱. 25분 집중 + 5분 휴식 + 4세트 후 긴 휴식을 자동으로 진행하고, 일별 통계와 작업 라벨링으로 시간 사용 패턴을 시각화합니다.

## 문제
- 모바일 포모도로 앱은 데스크톱 작업 흐름과 분리됨
- 풀스크린 타이머는 방해 요소
- 사용자가 어떤 작업에 시간을 썼는지 회고 어려움

## 솔루션
- 트레이/메뉴바에 남은 시간 표시 (XX:XX)
- 알림(banner)과 부드러운 사운드
- "현재 작업 라벨" 입력 → 통계 집계
- 일별/주별 차트 (renderer)

## 타겟
- 원격 근무자, 프리랜서
- 학생, 연구자
- ADHD 사용자

## 핵심 기능
- 25/5/15 분 사이클 (커스텀 가능)
- 작업 라벨, 태그
- 일/주 통계
- 자동 시작 / 일시정지 / 스킵
- DnD 모드 (휴식 알림 비활성)
- iCloud/Dropbox export (Pro)

## 수익 모델
- Free: 통계 7일, 라벨 5개
- Pro ($9 lifetime / $2/월):
  - 통계 무제한 + CSV/JSON export
  - 무제한 라벨/카테고리
  - 통합: Toggl, Google Calendar
  - 커스텀 사운드

## 경쟁사
- Be Focused (macOS, freemium)
- Focus To-Do
- Forest (모바일)

## 차별점
- 크로스 플랫폼 트레이 앱
- 매우 가벼움 (RAM < 80MB)
- 라이프타임 라이선스로 구독 피로 최소화
- 오픈소스 코어

## KPI
- 일 평균 완료 포모도로 수
- 7/30일 리텐션 (목표 35%)
- Pro 전환율 (목표 5%)
- 평균 라벨 사용량
