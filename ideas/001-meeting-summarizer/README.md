# 001 - 회의록 자동 요약 / 액션아이템 추출

## 개요
긴 회의 녹취록 또는 텍스트 메모를 입력하면, Claude가 자동으로 핵심 요약, 결정 사항, 액션 아이템(담당자/마감일 포함)을 추출하여 구조화된 회의록을 생성하는 SaaS입니다.

## 문제
- 1시간 회의 후 회의록 정리에 평균 20분 이상이 소요됨
- 누가 무엇을, 언제까지 하기로 했는지 사람마다 다르게 기억함
- Slack, Notion, Jira 등 도구 간 이동으로 액션 아이템이 누락됨
- 비동기 협업 환경에서 회의 참가자가 아닌 사람은 결과를 빠르게 파악하기 어려움

## 솔루션
- Zoom/Meet/Teams 녹취록 또는 직접 입력한 텍스트를 업로드
- Claude가 회의 구조(주제, 결정, 액션)를 분석하여 JSON 형태로 추출
- 액션 아이템은 담당자와 마감일을 자동 식별, 누락 시 사용자 보완 UI 제공
- 결과를 Markdown/Notion/Jira로 원클릭 전송

## 타겟 사용자
- 주 5회 이상 회의가 있는 PM, 엔지니어링 리드, 디자인 리드
- 분산 협업 중인 30~300명 규모의 스타트업
- 컨설팅 펌의 컨설턴트 (고객 미팅 정리 반복)

## 핵심 기능
1. 녹취록(.txt, .srt, .vtt) 업로드 및 직접 붙여넣기 입력
2. Claude 기반 자동 요약 + 결정 사항 + 액션 아이템 추출
3. 액션 아이템 편집기(담당자/기한 수정, 추가/삭제)
4. Markdown export 및 클립보드 복사
5. (Pro) Slack/Notion/Jira 자동 전송 연동
