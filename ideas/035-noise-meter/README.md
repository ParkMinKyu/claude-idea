# 소음 측정 + 지도 제출 (NoiseMap)

## 개요
주변 소음을 dB로 실시간 측정하고, 사용자가 동의하면 익명으로 지도에 제출하여 도시 단위 소음 지도를 만드는 시민 참여형 앱.

## 문제
- 층간소음, 도로소음, 공사소음 등 일상 소음 문제 해결을 위한 객관적 데이터가 부족.
- 환경부 소음지도는 업데이트 주기가 느리고 세밀하지 않음.
- 부동산 계약 시 소음 사전 확인 어려움.

## 솔루션
- 마이크 입력으로 실시간 dB 측정 (보정된 값).
- 익명 제출 옵션 (위치/시간/dB만 전송).
- 지역별 평균 소음 지도 시각화 (네이버/카카오 맵 SDK).
- 시간대별 소음 패턴 분석.

## 타겟 사용자
- 이사 예정자 (소음 사전 조사).
- 층간소음 피해자.
- 도시 환경 시민 활동가.
- 카페/공부 장소 찾는 학생.

## 핵심 기능
1. 실시간 dB 측정 + 그래프.
2. 위치 기반 익명 제출.
3. 지도 위 히트맵 시각화.
4. 측정 기록 저장 및 공유.
5. 소음 알림 (특정 dB 초과 시).
6. CSV 내보내기.

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩7,900: 광고 제거, 무제한 기록, CSV 내보내기, 고급 통계.

### 구독
- 월 ₩2,900: 특정 지역 소음 알림, 시간대 비교, 부동산 보고서.

### 광고
- 무료 사용자: 측정 후 결과 화면에 보상형 광고 1회.

## 경쟁사
- Sound Meter: 측정만 가능, 지도 기능 없음.
- Decibel X: 광고 과다.
- 환경부 소음정보시스템: 웹 기반, 모바일 UX 미흡.

## 차별점
- 시민 참여형 크라우드소싱 지도.
- 한국 주요 도시 부동산 데이터와 연계 가능.
- 가벼운 앱 (< 10MB).
- 보정 옵션 (기기별 마이크 차이 보정).

## KPI
- 일간 측정 횟수 사용자당 평균 2회 이상.
- 익명 제출률 30%.
- 지도 데이터 포인트 월 10만 건 이상.
- 30일 리텐션 25%.
- 프리미엄 전환율 3%.
