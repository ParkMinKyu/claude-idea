# 073 · AI 밈 생성기 + 갤러리

## 개요
사용자가 상황·감정·트렌드를 한 줄로 적으면 Claude(vision)이 어울리는 템플릿을 골라 캡션을 생성하고 canvas로 즉시 이미지를 만든다. 만든 밈은 공개 갤러리에 업로드되어 좋아요·리믹스 가능.

## 문제
- imgflip은 영문 위주, 한글 폰트 처리가 어색하다.
- "한국 밈"(짤) 템플릿은 디시인사이드·트위터에 흩어져 있어 검색이 어렵다.
- 영상 밈·합성은 어렵지만 정적 짤은 1초 만에 만들 수 있어야 한다.
- 모바일 일반 사용자는 캡션 작성에 시간이 걸린다.

## 솔루션
- "내가 월요일에 출근할 때" → Claude이 시각/문맥 매칭으로 템플릿 5개 추천 + 캡션 자동 생성
- Canvas API로 캡션 합성 → PNG/WebP 즉시 다운로드 또는 공유
- 갤러리: 트렌딩, 카테고리(직장·연애·게임·정치풍자), 리믹스 기능
- 안전장치: 인물·혐오 표현은 Claude moderation으로 사전 차단

## 타겟 사용자
- SNS·카톡에 짤을 자주 쓰는 10~30대
- 마케터·콘텐츠 에디터 (브랜드 메신저 짤 제작)
- 디시·X 유저 (트렌드 밈 빠른 생성)

## 핵심 기능
1. **상황 입력 → 템플릿 추천** — Claude vision으로 텍스트/이미지 매칭
2. **자동 캡션** — 톤(웃음/풍자/공감) 선택 후 2~3안 제안
3. **Canvas 합성** — 한글 임팩트체·아웃라인·자동 줄바꿈
4. **공개 갤러리** — 좋아요·리믹스·신고
5. **워터마크 옵션** — 무료는 우측 하단 워터마크, Pro는 제거

## 수익 모델
| 채널 | 가격 |
|---|---|
| Free | 일 5개 생성, 워터마크 포함, 광고 표시 |
| Pro | ₩4,900/월 무제한 + 워터마크 제거 + 광고 제거 |
| 브랜드팩 | ₩49,000/팩 — 브랜드 컬러·로고 합성 워크플로 |
| 광고 | 갤러리 페이지 디스플레이 광고 |
| 템플릿 마켓 | 작가가 템플릿 등록, 다운로드당 ₩100 (수수료 20%) |

## 경쟁사
- imgflip, Kapwing, Canva 밈 템플릿, 픽잇(Pikit)

## 차별점
- 한국 짤 템플릿 큐레이션 + 한글 임팩트 폰트 자동 적용
- Claude vision으로 "상황 → 템플릿" 자연어 매칭 (imgflip은 키워드 검색)
- 갤러리 리믹스(다른 사람의 짤을 캡션만 바꿔 재배포)
- 모더레이션: 인물·혐오·정치 광고 차단

## KPI
- 첫 짤 생성까지 평균 < 30초
- 일일 생성당 평균 공유율 30% 이상
- Free → Pro 전환율 5%
- 갤러리 좋아요 평균 / 생성 짤 비율
- 모더레이션 위반 비율 < 0.1%
- ARR per active user ₩50,000 이상

## 사용 시나리오
1. 일반 사용자가 친구 카톡방에 보낼 짤을 30초 안에 생성
2. 브랜드 마케터가 인스타그램 캠페인용 짤 시리즈 빠르게 양산
3. 디자이너가 자기 템플릿을 마켓에 등록 → 다운로드당 수익

## MVP 범위
- v0.1: 텍스트 입력 → 템플릿 선택 → 캡션 합성 → 다운로드
- v0.2: Claude 자동 추천 + 갤러리
- v0.3: 모더레이션 + 리믹스
- v1.0: 템플릿 마켓 + 브랜드팩 + POD 연동

## 리스크 / 가정
