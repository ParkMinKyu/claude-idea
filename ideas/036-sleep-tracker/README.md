# 가속도계 수면 단계 측정 (SleepSense)

## 개요
스마트워치 없이도 폰을 베개 옆에 두면 가속도계와 마이크로 수면 단계(얕은/깊은/REM)를 추정해주는 수면 트래커.

## 문제
- Galaxy Watch, Apple Watch 등이 없는 사용자는 정확한 수면 분석을 받기 어렵습니다.
- 기존 수면 앱은 단순 수면 시간만 측정.
- 잠꼬대, 코골이 등 부가 정보 부족.

## 솔루션
- 가속도계로 뒤척임 감지 → 수면 단계 추정.
- 마이크로 코골이/잠꼬대 녹음.
- 스마트 알람: 얕은 수면 구간에 깨우기.
- 수면 점수 + 7일 추이 분석.

## 타겟 사용자
- 수면의 질을 개선하려는 20~50대.
- 스마트워치 미보유자.
- 코골이 모니터링이 필요한 사용자.

## 핵심 기능
1. 가속도계 기반 수면 추적 (백그라운드 서비스).
2. 마이크 코골이/잠꼬대 감지 및 녹음.
3. 스마트 알람 (얕은 수면 깨우기).
4. 수면 점수 + 단계별 차트.
5. 수면 사운드 (백색소음 등) 재생.
6. CSV 내보내기.

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩9,900: 광고 제거, 무제한 녹음 보관, 모든 사운드.

### 구독
- 월 ₩2,900: 클라우드 백업, 상세 인사이트 리포트, 헬스커넥트 연동.

### 광고
- 무료 사용자에게 통계 화면 배너 광고.

## 경쟁사
- Sleep Cycle: 글로벌 1위, 가격 비쌈.
- Pillow: iOS 전용.
- AutoSleep: iOS 전용.
- 수면 분석 알람: 광고 과다.

## 차별점
- 가벼운 앱, 한국어 UX, 한국형 백색소음 (빗소리, 카페).
- 헬스커넥트 / 삼성 헬스 연동.
- 스마트워치 없이도 작동.
- 잠꼬대 자동 클립 (재미 요소).

## KPI
- 일간 추적 활성률 60%+ (수면은 매일).
- 평균 사용 일수 월 25일 이상.
- 30일 리텐션 40%.
- 프리미엄 전환율 6%.
- 평점 4.5 이상.
