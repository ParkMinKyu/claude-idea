# 생리 주기 추적 (CycleMate)

## 개요
프라이버시를 최우선으로 설계한 생리 주기 추적 앱. 모든 데이터는 로컬에만 저장되며,
온디바이스 머신러닝으로 다음 주기와 가임기를 예측합니다.

## 문제
- 기존 생리 주기 앱은 데이터를 클라우드에 저장하여 프라이버시 우려가 큽니다.
- 광고와 인앱 결제가 과도하게 노출되어 사용 경험이 나쁩니다.
- 한국어 UX와 한국 의료 기준(평균 주기 28일 등) 반영이 부족합니다.

## 솔루션
- **100% 로컬 저장** (Room DB, 클라우드 옵트인).
- 주기, 증상, 기분, 통증, 분비물 등 기록.
- 평균 주기 길이 학습 기반 다음 주기 예측.
- 가임기/배란일 표시.
- 비밀번호/지문 잠금.

## 타겟 사용자
- 15~45세 여성 사용자.
- 임신 계획 또는 피임을 고민하는 여성.
- 프라이버시에 민감한 사용자.

## 핵심 기능
1. 생리 시작/종료일 기록.
2. 일별 증상/기분/통증 기록.
3. 다음 주기 및 가임기 예측 (Bayesian).
4. 캘린더 뷰 시각화.
5. 앱 잠금 (PIN/생체).
6. 암호화된 백업 (사용자 선택).

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩9,900 일회성: 광고 제거, 무제한 증상 태그, PDF 보고서.

### 구독
- 월 ₩2,900: 파트너 공유, 클라우드 백업(E2E 암호화), 임신 준비 모드.

### 광고
- 무료 사용자에게 통계 화면 배너 (생리용품 카테고리 한정).

## 경쟁사
- Flo: 데이터 프라이버시 논란.
- Clue: 디자인은 좋으나 한국화 미흡.
- 핑크다이어리: 광고 과다.

## 차별점
- 로컬 우선 (Privacy-by-design).
- 한국어 의학 용어와 부드러운 한글 UX.
- 온디바이스 ML 예측 (TensorFlow Lite).
- 오픈소스 공개로 신뢰성 확보 가능.

## KPI
- 30일 리텐션 50% 이상 (월간 사용 필수).
- 평균 일일 기록 항목 3개 이상.
- 프리미엄 전환율 7%.
- 평점 4.6 이상.
- 앱 잠금 활성화율 60%.
