# 104 · UUID/ULID 툴킷

## 개요
UUID(v4, v7)와 ULID를 생성·검증·분석하는 TypeScript 라이브러리 + CLI. v7/ULID의 내장 타임스탬프 디코딩까지 지원한다. 온라인 UUID 생성기들의 타입 안전한 프로그래머블 대안을 지향한다.

## 문제
- 분산 시스템에서 시간 정렬 가능한 ID(v7/ULID)가 점점 표준이 되는데, 기존 도구는 v4만 지원하거나 타임스탬프 디코딩을 못 한다.
- 온라인 생성기는 API/CLI가 없어 자동화·CI 통합이 어렵다.
- ID의 버전/변형(variant)을 빠르게 검증해야 할 때 마땅한 도구가 없다.

## 솔루션
- 의존성 0 코어로 UUID v4(랜덤), v7(시간순), ULID를 생성한다.
- 임의의 ID를 받아 RFC 4122 유효성, 버전, 변형을 판정한다.
- v7과 ULID의 48비트 타임스탬프를 ms 단위로 복원한다.
- 라이브러리, CLI, (상용판) REST API/웹 UI로 동일 코어를 제공한다.

## 타겟 사용자
- 분산 시스템·DB 키 설계를 하는 백엔드 개발자
- CI/시드 데이터에 ID를 대량 생성하는 DevOps
- ID 포맷을 학습·검증하려는 개발자 일반

## 핵심 기능
1. **멀티 포맷 생성** — `uuidV4`, `uuidV7`(시간순), `ulid`(Crockford base32)
2. **검증 + 인스펙션** — 정규식 + 버전/변형 nibble 검사로 위조/오타 탐지
3. **타임스탬프 디코딩** — v7/ULID의 생성 시각을 복원
4. **CLI** — `uuidkit gen v7 -n 100`, `uuidkit inspect <id>`
5. **RNG 주입** — 결정론적 테스트를 위한 난수 생성기 주입 지원

## 사용 시나리오
1. 개발자가 `npm i uuid-toolkit` 후 코드에서 `uuidV7()`을 호출한다.
2. DB 키로 시간순 ID가 필요해 v7/ULID를 선택한다.
3. CI 시드 스크립트에서 `npx uuidkit gen v7 -n 100`으로 대량 생성한다.
4. 운영 중 의심스러운 ID를 `uuidkit inspect <id>`로 버전·생성시각 확인한다.
5. 대량 생성이 필요하면 호스팅 API로 전환한다(API 플랜).

## 경쟁사
- **uuid(npm)** — 표준이나 ULID 미지원, 타임스탬프 디코딩 없음
- **ulid(npm)** — ULID 전용, UUID 미통합
- **nanoid** — 짧은 ID 강점, 시간순/표준 UUID 아님
- **uuidgenerator.net** — 웹 전용, API/CLI 없음

## 차별점
- v4·v7·ULID를 한 패키지에서 일관 API로 제공 + 타임스탬프 디코딩 내장
