# 138 · Secret Scanner (코드 시크릿 스캔)

## 개요
소스 코드·설정 파일에 하드코딩된 자격 증명(API 키, 토큰, 개인 키 등)을 찾아내는
스캐너입니다. 벤더별 정규식 규칙과 Shannon 엔트로피 기반 탐지를 결합해, 알려진
키 형식뿐 아니라 무작위처럼 보이는 미지의 키도 잡아냅니다. 모든 로직이 순수
함수라 pre-commit 훅·CI에 손쉽게 통합됩니다.

## 문제
- 실수로 커밋된 키 하나가 클라우드 자원 탈취·과금 사고로 이어집니다.
- 깃 히스토리에 남은 비밀은 사후 제거가 어렵습니다.
- 정규식만으로는 새로운/사내 키 형식을 놓칩니다.
- 예시/플레이스홀더를 진짜 비밀로 오탐하면 경보 피로가 생깁니다.

## 솔루션
벤더 패턴(AWS/GitHub/Stripe/Slack/Google/JWT/개인 키)과 엔트로피 스크리닝을
함께 적용하고, 플레이스홀더 필터로 오탐을 줄입니다. 발견 시 자동 마스킹으로
안전하게 리포트하며, CI exit code로 머지를 차단합니다.

## 타겟 사용자
- 보안을 신경 쓰는 모든 개발팀(특히 오픈소스/스타트업)
- DevSecOps·플랫폼 엔지니어
- 규제 산업(금융/헬스케어)의 코드 감사 담당

## 핵심 기능
1. 벤더별 정규식 규칙 (AWS/GitHub/Stripe/Slack/Google/JWT/개인 키)
2. Shannon 엔트로피 기반 미지 키 탐지
3. 플레이스홀더/예시 필터로 오탐 감소
4. 자동 마스킹 리포트 (안전한 출력)
5. pre-commit/CI 게이트 (exit code 연동)

## 수익 모델 (가격 티어)
- Free / OSS: CLI 무료, 공개 리포 무제한
- Pro ($7/개발자/월): 사설 리포 CI, 커스텀 규칙, 베이스라인
- Team ($49/월): 조직 대시보드, 히스토리 스캔, Slack 알림
- Enterprise (협의): 셀프호스트, SSO, 감사 리포트, 비밀 회수 워크플로

## 경쟁사
- GitGuardian (시장 리더, 고가)
- TruffleHog / gitleaks (오픈소스 CLI)
- GitHub Secret Scanning (플랫폼 종속)

## 차별점
- 정규식 + 엔트로피 + 플레이스홀더 필터로 정밀도/재현율 균형
- 순수 함수 코어로 pre-commit·엣지·서버 어디든 통합
- 자동 마스킹으로 로그 유출 위험 최소화
- 사내 키 형식까지 커스텀 규칙으로 확장

## KPI
- 스캔된 리포/커밋 수, 차단된 비밀 누출 건수
- 오탐률(플레이스홀더 필터 효과), 평균 처리 시간
- Free→Pro 전환율, 조직 대시보드 채택 수
- 히스토리 스캔으로 발견된 과거 비밀 수
