# 128 · 코드 → 이미지 (Carbon 대안)

## 개요
소스 코드 스니펫을 받아 보기 좋은 SVG 이미지로 렌더링하는 도구·API. Carbon·ray.so의 셀프호스트 가능한 API 우선 대체재를 지향한다. 폰트 임베딩 없이 SVG로 출력해 어디서나 깔끔하게 보인다.

## 문제
- 블로그·문서·SNS에 코드를 공유할 때 텍스트는 깨지기 쉽고 캡처는 화질이 들쭉날쭉하다.
- Carbon은 웹 UI 중심이라 자동화(문서 빌드, 봇)에서 쓰기 불편하다.
- 헤드리스 브라우저 기반 렌더러는 무겁고 서버리스에 올리기 까다롭다.

## 솔루션
- 코드 + 언어 + 테마를 입력받아 토큰화 후 SVG로 직접 렌더
- 윈도우 크롬(맥OS 스타일 신호등), 라인 넘버, 패딩 옵션
- 브라우저 불필요 → 순수 문자열 처리로 빠르고 가벼움
- API/CLI로 문서 파이프라인·봇에 통합

## 타겟 사용자
- 기술 블로거·문서 작성자
- 개발자 도구/DevRel 팀 (SNS 코드 카드 자동 생성)
- 코드 공유 봇·CI를 만드는 개발자

## 핵심 기능
1. **간이 토크나이저** — 문자열/주석/키워드/숫자 분류 (언어 무관 휴리스틱)
2. **테마 시스템** — 다크/라이트 등 색상 팔레트
3. **SVG 렌더러** — 폰트 메트릭 기반 레이아웃, 윈도우 크롬, 라인 넘버
4. **이스케이프 안전** — XML 특수문자 안전 처리
5. **API/CLI** — 코드 입력 → SVG 출력 (PNG는 옵션 변환)

## 경쟁사
- Carbon, ray.so, CodeImage, snappify, silicon(CLI)

## 차별점
- 브라우저 없이 SVG 직접 생성 → 서버리스/엣지에서 초저비용 운영
- 렌더링 코어가 순수 함수라 결정적(deterministic) 출력, 테스트 용이
- API 우선 설계로 문서 빌드·봇 자동화에 최적
- 한글 코드 주석/식별자 폭 보정 및 한국어 UI

## 사용 예시
```bash
# 소스 파일을 SVG 코드 이미지로 렌더
npx code-img app.js --theme dark --out app.svg
```
출력: 윈도우 크롬 + 라인 넘버가 포함된 결정적 SVG (브라우저 불필요)

## 로드맵
- **MVP (현재)**: 휴리스틱 토크나이저, 다크/라이트 테마, SVG 렌더러, CLI
- **v1**: 정밀 하이라이트(Shiki/Prism), 워터마크/브랜드 프리셋, API
- **v2**: PNG 변환(resvg-wasm), 한글 폭 보정, 폰트 임베딩 옵션
- **v3**: 테마 마켓플레이스, SNS 카드 자동화 봇
