# 051 - Clipboard History

데스크톱 클립보드 히스토리 + 검색 + 스니펫 저장 Electron 앱.

## 개요
macOS/Windows/Linux 사용자가 복사한 텍스트/이미지/파일을 자동으로 기록하고, 글로벌 단축키로 빠르게 검색·재사용할 수 있는 데스크톱 앱입니다. 자주 쓰는 항목은 스니펫으로 고정하고, 정규식 검색, 코드 블록 자동 인식 등의 생산성 기능을 제공합니다.

## 문제
- 운영체제 기본 클립보드는 가장 최근 1개만 저장
- 작업 중 복사·붙여넣기 반복 시 이전 내용 손실
- macOS Paste/Maccy는 macOS 전용, 윈도우/리눅스 지원 약함
- 스니펫 매니저는 별도 도구라 관리 부담

## 솔루션
- Electron tray 앱으로 백그라운드 상주
- 글로벌 단축키(기본 Cmd/Ctrl+Shift+V)로 검색 창 즉시 열기
- 텍스트/이미지/파일 경로 자동 기록
- 자주 쓰는 항목 고정 (스니펫)
- 정규식/풀텍스트 검색

## 타겟
- 개발자, 디자이너, 라이터, 번역가
- 멀티 모니터 워크플로우 사용자
- 고객지원 (상용구 반복 사용)

## 핵심 기능
- 자동 히스토리 (텍스트/이미지/파일)
- 글로벌 단축키 검색
- 스니펫 고정 + 카테고리
- 코드 블록 자동 감지 + 신택스 하이라이트
- 민감 정보(비밀번호 매니저 출력) 무시 옵션
- 동기화 (Pro)

## 수익 모델
- Free: 히스토리 500개, 스니펫 10개
- Pro ($14 lifetime / $4 monthly):
  - 무제한 히스토리 (DB 사이즈 한도만)
  - 스니펫 무제한 + 변수/매크로
  - iCloud / Dropbox 동기화 (사용자 폴더 통해)
  - 팀 스니펫 공유

## 경쟁사
- Maccy (macOS, 무료)
- Paste ($30 lifetime, macOS)
- Ditto (Windows, 무료)
- CopyClip 2

## 차별점
- 크로스 플랫폼 (macOS/Win/Linux 모두)
- 코드 블록 자동 인식
- 비밀번호 매니저 출력 자동 제외 (Bitwarden, 1Password 패턴)
- 합리적 lifetime 가격

## KPI
- 일일 검색 횟수
- 평균 활성 사용자당 히스토리 항목 수
- Pro 전환율 (목표 5%)
- 30일 리텐션
- 스니펫 사용량 / 사용자
- 비밀번호 자동 필터 적중률

## 마일스톤
- M1: 트레이 앱 + 기본 히스토리
- M2: 검색 + 스니펫 고정
- M3: 비밀번호 매니저 출력 자동 필터
- M4: 코드 블록 감지 + 신택스 하이라이트
- M5: Pro 결제 + 동기화

## 리스크
- 클립보드 데이터 보안 우려 → 로컬 SQLite + 사용자 제어
- macOS 보안 권한 (accessibility) 요청 거부 → 온보딩 강화
