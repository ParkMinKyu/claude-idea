# 060 - Env Secrets (.env 팀 공유 E2E 암호화)

## 개요
팀원 간 `.env` 파일을 종단간(E2E) 암호화로 안전하게 공유하고 동기화하는 서비스입니다. 서버는 암호문만 저장하며, 평문은 클라이언트(또는 CLI)의 키에서만 복호화됩니다. 1Password 같은 별도 도구 없이도 `dotenvx`처럼 가볍게 사용할 수 있습니다.

## 문제
- Slack / 카톡으로 `.env` 평문 공유 (보안 사고)
- Vault, AWS Secrets Manager는 셋업 비용이 큼
- 1Password CLI는 비싸고 개발자 워크플로우와 거리
- 신규 입사자 온보딩 시 환경 변수 전달이 매번 수동

## 솔루션
- **E2E 암호화**: libsodium NaCl box (X25519 + XSalsa20-Poly1305)
- **CLI**: `envs pull` / `envs push` (Git처럼)
- **웹 대시보드**: 멤버 초대, 환경(`dev/staging/prod`) 관리
- **롤링**: 키 회전, 멤버 제거 시 자동 재암호화
- **감사 로그**: 누가 언제 어떤 변수 접근/변경
- **CI 통합**: 서비스 토큰으로 빌드 시 주입

## 타겟
- 스타트업 / 소규모 개발팀 (5-50명)
- 비밀번호 관리자 없는 사이드 프로젝트 팀
- 보안 컴플라이언스 필요한 핀테크 / 헬스케어

## 핵심 기능
1. **종단간 암호화**: 서버 무관 (제로 노리지)
2. **CLI**: 푸시/풀, 환경별 전환
3. **멤버 관리**: 초대, 역할(읽기/쓰기/관리자)
4. **환경 분리**: dev / staging / prod 격리
5. **키 회전**: 멤버 제거 시 자동
6. **감사 로그**: 모든 접근 기록
7. **Git 훅** (Pro): pre-commit으로 평문 .env 차단
8. **CI 인젝션** (Pro): GitHub Actions, GitLab, CircleCI

## 수익 모델

- **Free**: 1 워크스페이스, 3명, 1환경
- **Pro ($4/사용자/월)**: 무제한 환경, 감사 로그 30일
- **Team ($10/사용자/월)**: SSO, 1년 감사, 키 회전 정책
- **Enterprise**: 셀프호스팅, SOC2, HSM 통합

## 경쟁사

- HashiCorp Vault (셋업 무거움)
