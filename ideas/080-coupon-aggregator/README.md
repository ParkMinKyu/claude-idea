# 080 - 쿠폰 어그리게이터

## 개요
국내외 쇼핑몰의 할인 쿠폰/프로모션 코드를 크롤링·검증하여 한 곳에 모아 보여주는 어그리게이션 사이트입니다. 사용자가 직접 검증("Worked?/Failed?") 투표를 누를 수 있어 코드 만료를 빠르게 반영합니다.

## 문제
- RetailMeNot 등 글로벌 사이트의 80% 코드가 만료/허위
- 한국 사용자는 네이버 카페/디시 등에서 산발적으로 정보 수집 → 시간 낭비
- 쇼핑몰별 자체 공지가 분산되어 비교 불가
- 코드 사용 여부 검증이 자동화되지 않음

## 솔루션
- 주요 쇼핑몰 공식 페이지와 커뮤니티 RSS/스크래퍼로 자동 코드 수집
- 사용자 투표 시스템: "코드 사용 성공" / "만료됨" — 성공률을 노출
- 결제 시점 자동 복사 익스텐션 (Phase 2)
- 알림: 관심 쇼핑몰의 신규 코드 등록 시 이메일/푸시

## 타겟 사용자
- 직구족 (Amazon, AliExpress, iHerb 등 자주 이용)
- 쇼핑 커뮤니티 활동 절약형 소비자
- 학생, 1인 가구

## 핵심 기능
1. 쇼핑몰별 쿠폰 리스트 (성공률, 마지막 확인일 표시)
2. 사용자 투표 (성공/실패) → 성공률 기반 정렬
3. 카테고리/태그 필터 (쿠폰 종류: %할인, 무료배송, $X off)
4. 신규 쿠폰 알림 (이메일/RSS)
5. (Phase 2) 결제 시 자동 코드 적용 익스텐션
6. 어필리에이트 링크 통합

## 수익 모델
| 채널 | 비중 |
|------|------|
| 어필리에이트 수수료 | 70% — Coupang Partners, Amazon Associates 등 |
| 디스플레이 광고 | 15% — Google AdSense (저강도) |
| 프리미엄 알림 | 10% — $3/월, 알림 빈도/채널 무제한 |
| 데이터 라이선스 | 5% — 가격 비교 사이트에 코드 데이터 API 제공 |

## 경쟁사
- RetailMeNot, Honey: 글로벌 강자, 한국 쇼핑몰 커버리지 약함
- 쿠팬: 쿠팡 전용
- 알구몬, 뽐뿌: 커뮤니티, 비정형 데이터

## 차별점
- 한국 쇼핑몰 + 한국인 자주 쓰는 해외 사이트(직구) 동시 커버
- 성공률 기반 정렬 — 첫 번째 코드가 실제로 작동
- 커뮤니티 신뢰성 + 자동 크롤링 결합
- 가벼운 UI (광고 비중 낮춤 → 사용자 신뢰 확보)

## 핵심 지표 (KPI)
- DAU / WAU
- 코드당 평균 성공률 (목표 60% 이상)
- 어필리에이트 클릭 → 전환율
- 신규 쿠폰 등록부터 첫 검증까지 시간 (목표 6시간 이내)
- 알림 구독자 수
- 어필리에이트 수익 / 방문자 (목표 $0.02 이상)
