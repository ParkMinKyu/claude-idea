# 091 · 태그/검색 강화 북마크 (Bookmark Manager)

## 개요
브라우저 기본 북마크 대신 태그·풀텍스트 검색·자동 메타데이터 추출이 1급 시민인 북마크 매니저. Chrome 확장으로 한 번 클릭 저장 + Next.js 웹 대시보드.

## 문제
- 브라우저 기본 북마크는 폴더 트리뿐, 검색이 제목/URL에 한정
- Raindrop은 좋지만 무료 플랜이 협소하고 광고가 늘어남
- Pocket은 종료 (2025년 7월)

## 솔루션
- 확장 클릭 한 번에 저장 + 자동 OG 메타데이터·페이지 본문 fetch
- 태그 자동 제안 (제목+본문 키워드 추출)
- 풀텍스트 검색 (제목/본문/태그/도메인)
- 컬렉션·공유 링크·CSV/HTML export

## 타겟 사용자
- 연구·리서치 직군 (개발자, 디자이너, 마케터)
- Pocket 난민
- 리딩 리스트가 1000개 이상인 헤비 큐레이터

## 핵심 기능
1. **원클릭 저장** — 단축키 `Ctrl+Shift+S`, 현재 탭 즉시 저장
2. **메타 추출** — OG image, description, 본문 텍스트 5KB
3. **태그 자동 제안** — TF-IDF 기반 키워드 5개 제안
4. **검색** — 풀텍스트 + 도메인 필터 + 태그 다중 선택
5. **컬렉션 공유** — 공개 URL로 큐레이션 발행
