# 123 · SSL 인증서 만료 모니터

## 개요
도메인의 TLS 인증서를 주기적으로 조회해 만료일을 추적하고, 임계일(예: 30일/14일/7일) 전에 알림을 보내는 모니터링 서비스. 인증서 만료로 인한 서비스 장애를 예방한다.

## 문제
- Let's Encrypt 자동 갱신이 실패해도 만료 직전까지 아무도 모르는 경우가 많다.
- 여러 도메인/서브도메인의 인증서를 한곳에서 추적하기 어렵다.
- 만료 외에도 약한 서명 알고리즘, 곧 신뢰 해제될 CA, 호스트명 불일치 같은 문제를 놓친다.

## 솔루션
- 인증서의 `notBefore`/`notAfter`를 파싱해 잔여일 계산
- 임계일 기준으로 ok/warning/critical/expired 상태 분류
- 호스트명 매칭, 서명 알고리즘 점검 등 부가 검사
- 임계 도달 시 이메일·Slack·Webhook 알림

## 타겟 사용자
- 다수 도메인을 운영하는 인프라/운영팀
- 클라이언트 사이트를 관리하는 에이전시
- 자체 PKI를 운영하는 보안팀

## 핵심 기능
1. **인증서 파서** — notBefore/notAfter, 발급자, 주체, SAN 추출
2. **만료 임계 분류** — 잔여일 기반 상태(ok/warning/critical/expired)
3. **호스트명 검증** — 와일드카드 포함 SAN 매칭
4. **약한 설정 탐지** — SHA-1 서명, 만료 임박 체인 경고
5. **알림** — 다채널 알림 및 만료 캘린더(.ics) 내보내기

## 경쟁사
- Uptime Robot(SSL 추가 기능), BetterStack, Sematext, certspotter(OSS)

## 차별점
- 인증서 파싱·임계 로직을 순수 함수로 분리해 오프라인 테스트 및 라이브러리화 용이
- 만료일을 .ics 캘린더로 내보내 갱신 일정 관리와 통합
- 약한 서명/호스트명 불일치까지 포함한 종합 헬스 점수 제공
- 한국 인증기업/공공 도메인 대량 모니터링 프리셋

## 사용 예시
```bash
# 여러 도메인의 인증서 상태 점검 (경고/만료 시 exit 1)
npx ssl-monitor example.com api.example.com --json
```
출력 예: `[WARNING] example.com — 20일 남음 (만료 2026-06-09)`

## KPI
- 모니터링 중인 도메인 수
- 사전 알림으로 예방된 만료 건수
- 평균 갱신 리드타임 (알림 → 갱신)
- 유료 전환율
- false positive 알림율

## 로드맵
- **MVP (현재)**: 인증서 파싱, 만료 임계 분류, 호스트명/약한 서명 검사, CLI
- **v1**: cron 모니터링 워커, 이메일/Slack 알림, .ics 캘린더 내보내기
- **v2**: Certificate Transparency 로그 모니터링(오발급 탐지), 대시보드
- **v3**: mTLS 클라이언트 인증서, 체인 신뢰성 검증, 화이트라벨 리포트

## 리스크 & 가정
- 단순 만료 체크는 무료 도구가 많아, "종합 헬스 점수 + 대량 모니터링"이 차별
- 알림 피로(과다 알림)를 막는 임계 튜닝이 리텐션에 중요
