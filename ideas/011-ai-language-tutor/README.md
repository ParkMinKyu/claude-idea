# 011 - 음성 기반 회화 튜터

## 개요
브라우저에서 마이크를 켜고 외국어로 말하면, Claude가 자연스럽게 대답하고 발음/문법 피드백을 함께 제공하는 1:1 회화 파트너. Web Speech API로 STT/TTS를 무료로 처리하여 운영 비용 절감.

## 문제
- 회화 학원은 비싸고 시간 맞추기 어려움 (시간당 5~10만원)
- 앱 회화는 정해진 시나리오 위주 → 자유 대화 부족
- 외국인 친구 만들기 어려움, 실수 부끄러움

## 솔루션
- 토픽 선택 후 마이크 클릭만으로 대화 시작
- Claude가 사용자 레벨에 맞춰 어휘/속도 조정
- 매 응답 후 사용자 발화의 문법 오류·자연스러운 표현 제안
- 새 단어 자동 플래시카드 저장

## 타겟 사용자
- 영어 회화 학습자 (취업, 이직, 유학)
- 일본어/중국어 학습자 (장기 학습자 시장 큼)
- 한국 거주 외국인 (한국어 학습)
- 어학연수 전 워밍업

## 핵심 기능
1. 음성 대화 (Web Speech API STT/TTS)
2. 레벨 자동 조정 (A1~C1)
3. 매 답변 후 피드백 카드 (문법/표현/발음)
4. 단어장 자동 저장 + 복습
5. (Pro) 시나리오 모드 (면접, 출장, 비즈니스)

## 경쟁사
- Speak (Speak Korea): 한국 1위, 시간당 가격 부담
- Cake: B2C 강점, 자유 대화 약함
- ELSA Speak: 발음 교정 중심
- Tandem/HelloTalk: 사람 매칭, 시간 제약

## 차별점
- 24/7 무제한 대화 + 친구 같은 자유 토픽
- 매 응답에 즉각적 피드백 (사람 튜터도 못 함)
- 한국어 모국어 학습자에 특화된 흔한 실수 DB
- Web Speech API로 운영 비용 낮춰 가격 경쟁력

- DAU + 일평균 대화 시간
- Day 7/30 retention (학습 도구 KPI 핵심)
- 단어장 저장/복습 비율
- Free → Plus 전환율 (목표 6%)
- 사용자 자가 평가 레벨 향상 (월간 설문)
- NPS (학습 효능감 핵심)
