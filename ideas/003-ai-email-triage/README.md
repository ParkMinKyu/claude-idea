# 003 - Gmail 우선순위 자동 분류 + 답장 초안

## 개요
사용자의 Gmail 받은편지함을 주기적으로 읽어, Claude가 각 메일의 우선순위(긴급/일반/뉴스레터/스팸)를 분류하고, 즉시 답장이 필요한 메일에는 톤 일관성 있는 답장 초안을 자동 생성하는 서비스입니다.

## 문제
- 직장인 평균 하루 121통의 이메일 수신, 처리에 2.5시간 소요
- 정작 중요한 메일이 뉴스레터·자동 알림에 묻혀 답장이 늦어짐
- 답장 작성 자체가 인지 부담 — "무슨 말로 시작할지" 막막함

## 솔루션
- OAuth로 Gmail 연결 → 최근 메일 N건 가져오기
- Claude가 발신자/제목/본문을 분석해 4단계 우선순위 + 카테고리 라벨 부여
- "긴급" + "응답 필요" 메일에 한해 답장 초안 자동 생성
- 사용자의 과거 보낸 메일을 학습해 톤 매칭 (Pro)

## 타겟 사용자
- 영업, CS, 채용 담당자처럼 메일 응답이 핵심 업무인 직군
- 1인 창업자, 프리랜서 (모든 메일 직접 처리)
- 임원/이사급 (지시 위임 전 1차 분류 필요)

## 핵심 기능
1. Gmail OAuth 연동 + 받은편지함 동기화
2. Claude 기반 우선순위 분류 (긴급/일반/뉴스레터/스팸)
3. 응답 필요 메일 답장 초안 생성
4. 일일 다이제스트 (오전 9시 슬랙/이메일로 요약 전송)
5. (Pro) 사용자 톤 학습 (과거 100통 분석)

## 수익 모델
| 티어 | 가격 | 한도 |
|------|------|------|
| Free | $0 | 일 20통 분류 |
| Pro | $12/월 | 무제한, 답장 초안 |

## 경쟁사
- Superhuman: 빠른 UX 강점, 가격 $30/월
- Shortwave: AI 요약 강점, 한국어 약함
- SaneBox: 분류 전문, AI 답장 없음
- Gmail 기본 Smart Reply: 한 줄 답장 위주

## 차별점
- 한국어 비즈니스 이메일 톤(존댓말, 격식) 처리 품질
- 메일 클라이언트 교체 없이 기존 Gmail 위에 동작 (가벼움)
- 답장 초안이 사용자의 과거 톤을 학습 (Pro)
- 일일 다이제스트로 "메일 안 봐도 중요한 건 놓치지 않는" 경험

## 핵심 지표 (KPI)
- DAU (매일 사용해야 가치)
- 분류 정확도 (사용자 라벨 수정률 < 10%)
- 답장 초안 사용률 (수정 후라도 전송된 비율)
- Free → Pro 전환율 (목표 6%)
- 다이제스트 오픈율
- 평균 이메일 처리 시간 감소 (사용자 자가 보고)

## 향후 로드맵
- M1: 단일 메일 분류 + 답장 초안 API (MVP)
- M2: Gmail OAuth + 자동 라벨링
- M3: 일일 다이제스트 + Slack 전송
- M4: 사용자 톤 학습 (과거 100통 임베딩)

## 리스크와 대응
- Gmail OAuth 심사 까다로움 (read/write 스코프) → 별도 인증 트랙 + DPA 준비
- 자동 분류 오류로 중요 메일 누락 → 사용자가 라벨 수정 시 학습 피드백 루프
- 메일 내용 민감성 → 본문은 처리 직후 폐기, 분류 결과만 저장
