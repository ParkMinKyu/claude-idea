# 물 마시기 알림 (HydraMate)

## 개요
사용자 체중·활동량 기반으로 일일 권장 수분량을 계산하고, 한 시간 단위로 부드럽게 알려주는 수분 섭취 트래커.
귀엽고 게이미피케이션 요소가 가미된 한국형 디자인이 특징입니다.

## 문제
- 실내 근무자, 학생들이 물 마시기를 잊어 만성 탈수 상태에 놓이는 경우가 흔합니다.
- 기존 앱들은 영어권 사용자 중심으로 단위(oz)나 UI가 어색합니다.
- 알림이 거슬려서 끄게 되는 사용자 경험.

## 솔루션
- 체중/활동량 입력으로 일일 목표(ml) 자동 산출.
- 회사/학교 시간대를 학습하여 적응형 알림 스케줄링.
- 한 컵, 텀블러, 생수병 등 한국 사용자 친숙한 컨테이너 프리셋.
- 시각화: 물병 채우기 애니메이션, 7일 그래프.

## 타겟 사용자
- 20~30대 사무직, 학생.
- 헬스/다이어트에 관심 있는 사용자.
- 어린이 자녀의 수분 섭취를 관리하려는 학부모.

## 핵심 기능
1. 사용자 프로필 기반 일일 권장량 계산.
2. 시간대별 적응형 알림 (수면 시간 제외).
3. 원탭 빠른 추가 (컵, 머그, 텀블러, 생수병).
4. 일/주/월 통계 그래프.
5. 연속 달성 일수 보상 시스템.
6. 위젯에서 진행률 확인.

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩6,900 일회성: 광고 제거, 위젯 테마, 무제한 커스텀 컨테이너.

### 구독
- 월 ₩1,900: 가족 공유(최대 5명), 헬스커넥트 동기화, 상세 인사이트.

### 광고
- 무료 사용자에게 통계 화면 하단 배너 광고.

## 경쟁사
- Plant Nanny: 게이미피케이션 강하지만 한국 UX 부족.
- Water Llama: iOS 중심.
- Drink Water Reminder: 광고 과다.

## 차별점
- 한국식 생수병/텀블러 프리셋과 한글 알림 카피.
- 헬스커넥트 연동으로 삼성 헬스, Fit과 동기화.
- 적응형 알림: 회의 시간 자동 회피.
- 가족 모드: 부모가 자녀 수분 섭취 모니터링.

- 평균 일일 컵 추가 4회 이상.
