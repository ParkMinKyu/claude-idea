# 022 · 인시던트/상태 페이지

## 개요
서비스 가동 상태를 실시간으로 공유하는 호스팅형 상태 페이지. 인시던트 타임라인, 컴포넌트별 상태, SSE 기반 실시간 업데이트.

## 문제
- Statuspage(by Atlassian)는 월 $29부터로 인디 메이커에게 비싸다.
- 자체 구축은 인시던트 라이프사이클·구독자 알림·과거 가동률 차트까지 만들어야 한다.
- 실시간 업데이트가 폴링이면 트래픽 비용·UX 모두 손해.

## 솔루션
- 호스팅형 status.{customer}.com
- 컴포넌트 트리(API, Web, Database 등)와 색상 상태
- 인시던트 라이프사이클(Investigating → Identified → Monitoring → Resolved)
- SSE로 변경 즉시 푸시, 폴링 fallback 포함
- 이메일/Slack/RSS 구독

## 타겟 사용자
- SaaS 인프라/SRE 팀
- 인디 SaaS(고객 신뢰 강화)
- 사내 서비스 가시화

## 핵심 기능
1. **컴포넌트 상태 보드** — Operational/Degraded/Outage 색상
2. **인시던트 타임라인** — 마크다운 업데이트, 작성자 표시
3. **SSE 실시간 푸시** — 페이지 자동 갱신
4. **90일 가동률 히트맵**
5. **다채널 구독** — 이메일·Slack·RSS·Webhook

## 경쟁사
- Atlassian Statuspage, BetterStack Status, Instatus, Sorry™

## 차별점
- SSE 기본(타사는 폴링/소켓 유료 옵션)
- Instatus 대비 저렴
- 한국어/일본어 인시던트 템플릿
- 컴포넌트 트리(중첩) 무료 플랜부터 제공

## KPI
- 인시던트 페이지 평균 응답 시간 < 100ms
- 구독자 1,000명 이상 워크스페이스 30%+
- 인시던트 생성 → 첫 업데이트 평균 시간 < 5분
- 무료 → 유료 전환율 4%+
- 30일 잔존율 75%+
