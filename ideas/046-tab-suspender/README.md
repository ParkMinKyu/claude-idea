# 046 - Tab Suspender

비활성 탭을 자동으로 절전(suspend)시켜 RAM/CPU 사용량을 줄여주는 Chrome Extension(MV3).

## 개요
크롬 사용자는 평균적으로 동시에 20개 이상의 탭을 열어두지만, 실제로 활성화된 탭은 1-2개에 불과합니다. 나머지는 백그라운드에서 메모리와 배터리를 소모합니다. Tab Suspender는 일정 시간(기본 30분) 동안 보지 않은 탭을 자동으로 절전 상태로 전환합니다. 다시 활성화하면 즉시 복구되며, 사용자의 작업 흐름을 방해하지 않습니다.

## 문제
- 한 번 켜둔 탭이 계속 백그라운드 자바스크립트를 실행해 RAM 점유율이 치솟음
- 노트북 사용자는 배터리 사용 시간이 짧아짐
- 화이트리스트(예: Slack, Gmail)는 절전 대상에서 제외해야 함
- 기존 솔루션(The Great Suspender 등)이 단종되거나 보안 이슈 발생

## 솔루션
- MV3 `chrome.tabs.discard()` API를 활용해 메모리에서 탭을 내림
- 활성 시간을 추적하여 임계치를 넘으면 자동 discard
- 화이트리스트(URL 패턴), 핀 고정 탭, 오디오 재생 탭은 제외
- 절전 직전 상태(스크롤 위치 등)는 페이지에 의해 복원됨

## 타겟
- 노트북에서 작업하는 지식 노동자, 개발자
- 탭을 30개 이상 열어두는 헤비 사용자
- 화상회의/스트리밍을 자주 사용하는 사용자

## 핵심 기능
- 자동 절전: N분 무활동 탭을 discard
- 화이트리스트 / 블랙리스트 (도메인 패턴)
- 핀 탭, 오디오 탭, 폼 작성 중 탭 자동 제외
- 메모리 절감량 통계 대시보드 (Pro)
- 절전 탭 시각 표시(아이콘 변경)
- 단축키로 즉시 절전 / 복원
- 세션 저장 및 복구 (Pro)

## 수익 모델
- Free: 자동 절전, 화이트리스트 5개, 통계 7일
- Pro ($2.99/월 또는 $24/년):
  - 무제한 화이트리스트
  - 메모리 절감 통계 (전체 기간, CSV export)
  - 세션 자동 백업 / 복구
  - 기기 간 설정 동기화
  - 우선 지원

## 경쟁사
- Tab Wrangler (오픈소스, 무료)
- Auto Tab Discard (무료)
- The Marvellous Suspender (단종 후 포크)
- OneTab (탭 통합형)

## 차별점
- MV3 기반으로 장기 유지보수 가능 (대부분 경쟁사는 MV2)
- "스마트 화이트리스트": 폼 입력/스크롤 활동을 자동 감지해 제외
- 절감 메모리 통계로 사용자에게 가치 가시화
- 절전 후에도 탭 제목/파비콘 유지 (UX 보존)

## KPI
- WAU / MAU
- 평균 절전 탭 수 (사용자당/일)
- Pro 전환율 (목표 4%)
- 메모리 절감량 평균 (자랑 가능한 지표)
- 1-day / 7-day retention
- Chrome Web Store 평점 (목표 4.5 이상)

## 마일스톤
- M1: 자동 절전 + 화이트리스트
- M2: 통계 대시보드 + 단축키
- M3: Pro 결제 (Stripe) + 세션 백업
- M4: 동기화 (chrome.storage.sync) + 다국어
