# 030 · 가격 페이지 A/B 테스트

## 개요
가격 페이지 카피·티어·통화·CTA 버튼을 빠르게 A/B/n 테스트하는 SaaS. 엣지에서 분기, 정적 페이지 캐시 유지.

## 문제
- 가격 페이지 A/B는 전환에 직접 영향을 미치지만, Optimizely는 비싸고 무거운 스크립트로 LCP가 망가진다.
- 자체 구현은 분기·노출 추적·통계적 유의성 계산까지 떠안게 된다.
- 통화·지역·세그먼트별 분기 로직 작성이 까다롭다.

## 솔루션
- 엣지 미들웨어가 사용자 segment(country, plan)·실험 그룹을 결정 → HTML 분기
- 노출/클릭/구독 전환 이벤트 자동 트래킹
- 통계적 유의성·신뢰구간 자동 계산
- "가격 페이지 빌더"로 노코드 변경 + 즉시 실험 시작

## 타겟 사용자
- SaaS 그로스/마케팅 팀
- D2C 이커머스(가격 노출 변경)
- 인디 메이커(가격 산정 실험)

## 핵심 기능
1. **실험 정의** — 컨트롤/배리언트 가격 페이지 JSON
2. **엣지 분기** — Vercel Edge / Cloudflare Workers
3. **이벤트 트래킹** — 노출/CTA/구독 자동 수집
4. **통계 분석** — 베이지안 + 빈도주의 두 가지
5. **자동 정지** — 통계적 유의성 도달 또는 손실 임계치 초과 시

- Optimizely, VWO, GrowthBook, PostHog Experiments, Convert

## 차별점
- 가격 페이지 전용 — 일반 A/B와 달리 결제 funnel 통합
- 엣지 분기 — Client JS 0KB
- 한국 PG(Toss, Bootpay) 결제 전환 트래킹 연동
- 베이지안 정지 규칙 내장

## KPI
- 페이지 LCP < 1s (분기 후에도)
- 실험 평균 통계적 유의성 도달 시간 14일 이내 60%+
- 무료 → 유료 전환율 3%+
- 평균 실험당 분석 페이지 뷰 50+
- 30일 잔존율 70%+
