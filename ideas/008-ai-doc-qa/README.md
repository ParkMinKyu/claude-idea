# 008 - 사내 문서 RAG 질의응답

## 개요
회사 위키, Notion, 구글 드라이브, PDF 매뉴얼 등 사내 문서를 인덱싱하여, "OOO 정책이 뭐예요?" "환급 절차 어떻게 돼요?" 같은 질문에 출처 링크와 함께 정확히 답하는 사내 지식 챗봇.

## 문제
- 신입 온보딩 시 같은 질문 반복 → 시니어 시간 낭비
- 회사 문서가 여러 곳에 흩어져 있어 검색이 안 됨
- ChatGPT는 우리 회사 정보를 모름 + 보안 우려

## 솔루션
- Notion/Drive/Confluence 커넥터로 문서 자동 동기화
- Chroma 벡터 DB에 임베딩 저장
- 질문 시 관련 청크 retrieve → Claude로 답변 + 출처 인용
- Slack 봇 통합 (Slack 채널에서 @ai-doc 멘션)

## 타겟 사용자
- 50~500명 규모 회사의 People Ops/HR
- CS 팀 (반복 문의 내부 매뉴얼화)
- 개발팀 (사내 표준/온콜 가이드 검색)

## 핵심 기능
1. 다중 소스 커넥터 (Notion/Drive/Confluence/PDF 업로드)
2. 증분 동기화 (변경분만)
3. RAG 기반 답변 + 출처 인용
4. Slack/Teams 봇 통합
5. (Pro) 권한 관리 (문서별 ACL 반영)
