# 131 · Color Contrast Checker (접근성 대비 검사)

## 개요
WCAG 2.1 기준 명암비(contrast ratio)를 계산하고 AA/AAA 등급을 판정하는 접근성
검사 도구입니다. 전경색/배경색 한 쌍을 입력하면 1~21 사이의 명암비와 일반 텍스트
및 큰 텍스트에 대한 합격 여부를 즉시 반환합니다. CLI, REST API, Figma/브라우저
플러그인 형태로 동일한 코어 로직을 재사용할 수 있도록 순수 함수로 설계했습니다.

## 문제
- 디자이너와 개발자는 색상 결정 시점에 접근성 합격 여부를 알기 어렵습니다.
- 명암비를 손으로 계산하려면 sRGB 선형화·상대 휘도 공식을 매번 구현해야 합니다.
- 접근성 위반은 출시 후 감사에서 뒤늦게 발견되어 재작업 비용이 큽니다.
- 디자인 시스템 토큰 전체를 한 번에 검사할 자동화 수단이 부족합니다.

## 솔루션
WCAG 공식(상대 휘도, 명암비)을 정확히 구현한 코어 라이브러리와, 색상 조합을
배치로 검사하는 CI/CD 파이프라인을 제공합니다. 디자인 토큰(JSON)을 업로드하면
모든 전경/배경 조합을 검사해 위반 목록과 권장 대체 색상을 리포트합니다.

## 타겟 사용자
- 접근성 규정(WCAG, ADA, 유럽 EAA) 준수가 필요한 제품 팀
- 디자인 시스템을 운영하는 프런트엔드/디자인 엔지니어
- 정부·금융·교육 등 규제 산업의 웹/앱 개발팀
- 접근성 감사 컨설팅 업체

## 핵심 기능
1. WCAG 2.1 명암비 계산 (`#rgb`, `#rrggbb`, `rgb()` 입력 지원)
2. 일반/큰 텍스트별 AA·AAA 등급 자동 판정
3. 디자인 토큰 배치 검사 및 위반 리포트
4. CLI exit code 연동으로 CI 게이트 구성
5. 합격하는 가장 가까운 색상 추천 (Pro 기능)

- Pro ($9/월): 무제한 API, 배치 검사, 색상 추천, CI 토큰
- Team ($39/월): 디자인 토큰 모니터링, Slack 알림, 5인 좌석
- Enterprise (협의): SSO, 온프레미스, 감사 리포트 PDF, SLA

## 차별점
- 디자인 토큰 → CI 게이트로 이어지는 자동화 파이프라인에 집중
- 동일 코어를 CLI/API/플러그인이 공유해 결과 일관성 보장
- 위반 시 "가장 가까운 합격 색상" 제안으로 수정 비용 절감
- 외부 의존성 0으로 가볍고 빠른 실행
