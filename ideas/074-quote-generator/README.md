# 074 · 명언 카드 생성 / 판매

## 개요
명언·짧은 문장으로 SNS 공유용 카드 이미지를 만들어주는 도구. 무료 다운로드 + 디자이너가 만든 프리미엄 템플릿 판매 + 카드를 인쇄(엽서·포스터·티셔츠)해서 판매할 수 있는 POD 연결.

## 문제
- Canva 같은 도구는 무료 폰트·템플릿이 제한적이고 한글 폰트가 약하다.
- 인스타그램 명언 페이지 운영자는 매번 디자인을 새로 짜야 한다.
- 명언 책·다이어리는 인쇄 제작 단가가 높아 인디 작가 진입이 어렵다.

## 솔루션
- 한 줄 입력 → 템플릿·배경·폰트·컬러 자동 매칭 → 카드 즉시 생성
- "오늘의 명언" 자동 큐레이션 (사용자 무료) + 시리즈 30일 PDF 판매
- 프리미엄 템플릿팩 ₩2,900~9,900 (디자이너 매출 셰어)
- 카드 → POD 자동 등록 (엽서 4,900원, 포스터 19,900원)

## 타겟 사용자
- 인스타그램 명언/감성 계정 운영자
- 다이어리 데코·핸드레터링 입문자
- 카페·서점 사장 (인테리어 포스터 인쇄)
- 결혼식·기념일 디자인 필요한 일반 사용자

## 핵심 기능
1. **자동 디자인 매칭** — 문장 분위기(차분/유머/도전) 분석 → 적합 템플릿 추천
2. **한글 캘리그라피 폰트** — 자체 라이선스 폰트 10+ 종 무료
3. **인용 출처 자동 검색** — Claude로 출처 추적 + 출처 미상 경고
4. **시리즈 PDF** — 30일치 카드 묶음 PDF 생성·판매
5. **POD 연동** — Printful/Korea POD로 엽서·포스터 자동 등록

## 경쟁사
- Canva, Adobe Express, 미리캔버스, 망고보드

## 차별점
- 한글 캘리그라피·서예 폰트 빌트인 (Canva는 영문 위주)
- 명언 출처 자동 검증 (잘못된 인용 줄이기)
- "시리즈 30일 PDF" 디지털 상품 즉시 판매
- POD 자동 등록으로 작가가 굿즈 매출까지 연결

- POD 주문 전환율 (생성 → 구매) 1.5% 이상
- 30일 잔존 50% 이상
