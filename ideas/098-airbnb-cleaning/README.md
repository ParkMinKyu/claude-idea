# 098 · TurnoSync — Airbnb 청소업체 일정 자동화

## 개요
Airbnb·Vrbo 예약이 들어오면 체크아웃 시간에 맞춰 청소 작업을 자동 생성하고, 가장 가까운 청소부에게 SMS로 디스패치하는 SaaS. 호스트와 청소업체 사이의 누락·중복 일정을 제거한다.

## 문제
- 호스트가 청소 일정을 카톡·문자로 전달하다 보면 누락이 잦다 — 다음 게스트 체크인 직전에 청소가 안 된 사고가 매주 발생.
- 청소업체는 여러 호스트의 일정을 엑셀로 관리하는데, 예약 변경이 실시간으로 동기화되지 않는다.
- iCal URL을 직접 다루는 호스트는 소수 — UI가 없으면 도입 못 한다.
- Turno(구 TurnoverBnB) 같은 솔루션은 미국 중심이고 한국·일본 청소시장 가격대에 비싸다.

## 솔루션
- Airbnb/Vrbo iCal URL을 등록하면 새 예약을 5분마다 폴링
- 체크아웃 다음 슬롯에 자동으로 청소 작업 생성
- 등록된 청소부 중 우선순위·평점 기반으로 배정, Twilio SMS로 알림
- 청소부가 SMS 링크로 작업 수락/완료 표시, 사진 업로드
- 호스트는 대시보드에서 모든 숙소 청소 상태를 한 눈에 확인

## 타겟 사용자
- 5~50채 단기 임대를 운영하는 슈퍼호스트·STR 운영사
- 호텔식 청소 외주 전문 업체 (한국 게스트하우스 청소 회사)
- 부동산 관리회사 (PMC)

## 핵심 기능
1. **iCal 동기화** — Airbnb/Vrbo/Booking.com iCal feed 자동 수집
2. **작업 자동 생성** — 체크아웃 → 다음 체크인 사이 빈 슬롯에 청소 큐
3. **SMS 디스패치** — Twilio로 청소부에게 알림, 응답 트래킹
4. **사진 체크리스트** — 청소 완료 시 방별 사진 업로드 의무화
5. **결제 정산** — 청소부에게 월말 자동 정산 리포트

## 경쟁사
- Turno (구 TurnoverBnB), Properly, Breezeway, Hostfully Cleaning
- 한국 시장에서는 직접 카톡 운영이 대부분

## 차별점
- iCal "한 줄 등록"으로 시작 — Airbnb 계정 OAuth 불필요
- SMS 우선 디스패치 — 청소부 앱 설치 강요하지 않음 (앱 설치율 낮은 현실 반영)
- 한국·일본 SMS 비용 최적화 (Solapi/Twilio 듀얼 라우팅)
- 사진 체크리스트가 기본 — 호스트가 청소 품질을 클릭으로 검증

## KPI
- 청소 누락 사고 0건/월 (호스트당)
- iCal → 첫 청소 작업 자동 생성까지 < 10분
- 청소부 SMS 응답률 80% 이상
- 호스트 30일 잔존율 75% 이상
- ARR per 호스트 $300 이상
