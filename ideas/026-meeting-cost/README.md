# 026 · 회의 비용 실시간 계산기

## 개요
회의 참가자 수 + 평균 연봉을 입력하면 실시간으로 회의 비용이 카운트업되는 가벼운 웹 도구. 무료/노 로그인 시작, 캘린더 통합·리포트는 유료.

## 문제
- 긴 회의의 비용을 체감하지 못하는 조직이 많다.
- 기존 도구(Meeting Cost Counter 등)는 단순 카운터로 멈춤.
- 캘린더와 연동된 자동 회의 비용 리포트가 부족.

## 솔루션
- 메인 페이지: 사람 수 + 평균 연봉 입력 → 큰 숫자 카운터
- 회의 종료 시 SVG 카드 생성(공유용)
- 유료: Google Calendar 연동 → 다음 회의에 자동 카운터 링크 첨부
- 회사 단위 월간 회의 비용 리포트

## 타겟 사용자
- 회의 절감 캠페인 중인 HR/총무
- 시니어 매니저/임원
- 인디 도구 마니아

## 핵심 기능
1. **실시간 카운터** — 사람 수 × 시급 × 경과 시간
2. **공유 SVG 카드** — "회의에 ₩X 썼습니다" OG 이미지
3. **Google Calendar 연동** — 자동 링크 첨부
4. **월간 리포트** — 회사 평균 회의 비용 트렌드
5. **타이머 모드** — 발표자 시간 측정 → 종료 알림
