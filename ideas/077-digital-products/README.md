# 077 - 디지털 상품 결제 페이지

## 개요
PDF, ZIP, 비디오, 음원 등 디지털 파일을 업로드만 하면 결제 페이지 + 자동 다운로드 링크 발송까지 처리되는 "Gumroad-lite" 서비스입니다. 크리에이터는 Stripe 계정만 연결하면 5분 안에 상품을 판매할 수 있습니다.

## 문제
- Gumroad는 거래 수수료가 높고(최대 10%) UI 커스터마이징이 약함
- Etsy는 디지털 상품 전용이 아니며 검색 의존도가 높음
- 자체 Shopify + 디지털 다운로드 앱은 월 $50+ 비용이 발생
- 1회성 정산이 필요한 인디 크리에이터에게 과한 구조

## 솔루션
- 파일 업로드 → S3 저장 + 결제 페이지 자동 생성
- Stripe Checkout으로 카드 결제 (PG 가입 불필요, Stripe만 연결)
- 결제 완료 webhook → 24시간 만료되는 서명된 S3 URL 이메일 발송
- 본인 도메인 매핑 (Phase 2)

## 타겟 사용자
- 노션 템플릿/피그마 키트 판매 크리에이터
- 인디 게임/에셋 제작자, 음원/샘플팩 판매자
- 전자책(PDF) 저자, 강의 자료 판매 1인 강사

## 핵심 기능
1. 파일 업로드 (드래그앤드롭, 최대 5GB)
2. 결제 페이지 자동 생성 (썸네일, 설명, 가격)
3. Stripe Checkout 통합 (1회 결제, 신용카드)
4. 결제 webhook 검증 + 서명 다운로드 URL 발송
5. 판매 대시보드 (일/주/월 매출, 환불 비율)
6. (Pro) 다중 파일 묶음, 할인 코드, 멤버십 가격

## 수익 모델
| 티어 | 가격 | 거래 수수료 |
|------|------|------|
| Free | $0 | 거래당 5% + Stripe 수수료 |
| Pro | $15/월 | 거래당 2% (소액 결제 친화적) |
| Studio | $39/월 | 0% (대량 거래 시 유리) |

추가: 자체 결제 페이지에 광고 없음, 환불 도구 무료.

## 경쟁사
- Gumroad: 시장 표준이지만 수수료 10%, 디자인 제한
- Lemon Squeezy: Merchant of Record (편하지만 수수료 5%)
- SendOwl: 디지털 다운로드 강점, UI 노후
- Payhip: 가격 경쟁력 있으나 한국 사용자 인지도 낮음

## 차별점
- "Stripe만 연결" — Merchant of Record 모델이 아니라 정산이 즉시
- 수수료 구조가 명확 (Pro 2% vs Gumroad 10%)
- 한국어 결제 페이지 + 원화 표시, 사업자 등록 정보 입력란
- S3 서명 URL 기반 안전한 다운로드, 디바이스 제한 옵션

## 핵심 지표 (KPI)
- GMV (월간 거래 총액)
- 활성 셀러 수 (월 1건 이상 판매)
- 평균 거래액 (ARPU)
- 환불율 (목표 2% 미만)
- Free → Pro 전환율 (월 GMV $500 시점에서 전환 가속)
- 결제 → 다운로드 메일 도달 시간 (목표 30초 이내)
