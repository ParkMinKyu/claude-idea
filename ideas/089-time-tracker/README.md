# 089 · 자동 시간 추적 (Time Tracker)

## 개요
활성 창(active window)과 입력 idle 시간을 5초 간격으로 감지해, 사용자가 어떤 앱에 얼마나 머물렀는지 자동으로 기록하는 데스크톱 앱. RescueTime의 인디 대체재.

## 문제
- 수동 시간 추적(Toggl, Harvest)은 매번 시작/정지를 잊어버림
- RescueTime은 데이터가 자사 클라우드로만 전송 — 프라이버시 우려
- 프리랜서·컨설턴트는 정확한 청구를 위해 자동 추적이 필수

## 솔루션
- Electron으로 macOS/Windows/Linux 동시 지원
- 활성 창 제목·앱 이름·URL(브라우저 확장 연동)을 로컬 SQLite에 저장
- 카테고리 자동 분류 (Productive / Communication / Distract)
- 일/주/월 차트 + CSV/JSON export

## 타겟 사용자
- 프리랜서, 컨설턴트 (시간당 청구)
- 자기 생산성 측정에 진심인 지식 노동자
- 원격 근무자 (스스로의 패턴 파악)

## 핵심 기능
1. **자동 추적** — 5초 폴링, idle 60초 이상은 카운트 제외
2. **카테고리 분류** — 기본 규칙 + 사용자 정의 정규식
3. **일일 리포트** — Top 5 앱, 총 활동 시간, 카테고리별 파이
4. **목표** — "코딩 4시간/일" 같은 목표 + 달성률
5. **프로젝트 매핑** — Git 브랜치/폴더를 프로젝트로 자동 연결

## 경쟁사
- RescueTime, ManicTime, ActivityWatch(OSS), Toggl Track

## 차별점
- 로컬 우선 (cloud는 옵션) — 프라이버시 신뢰
- Git 컨텍스트 자동 인식 (코드 폴더 → 프로젝트)
- Electron이지만 메모리 < 80MB 유지 (네이티브 트레이)
- OSS 코어 + 유료 클라우드/팀 기능

## KPI
- 설치 후 첫 일일 리포트 진입율 80%
- 7일 잔존율 70%
- Free → Pro 전환율 8% (프리랜서 타겟)
- 데이터 export 사용률 30%
- 평균 일일 추적 시간 6시간 이상
