# 050 - Screenshot Annotator

페이지 캡처 + 주석(화살표, 박스, 텍스트, 블러) + 즉시 공유 링크를 제공하는 Chrome Extension.

## 개요
Skitch와 같은 빠른 주석 캡처를 브라우저 안에서 제공합니다. 보이는 화면 또는 전체 페이지를 캡처하고, 그 위에 화살표·박스·텍스트·블러 마스크를 즉시 그려서 PNG로 저장하거나 공유 가능한 단축 URL로 변환합니다.

## 문제
- 운영체제 캡처 도구는 주석/공유가 번거로움
- 디자이너/QA가 버그 리포트할 때 손이 많이 감
- 기존 Loom·Cleanshot은 비싸거나 데스크톱 전용

## 솔루션
- 단축키로 캡처 → 즉시 캔버스 에디터
- 마우스로 도형/텍스트/블러 그리기
- "Copy as PNG" / "Save" / "Share link"(Pro) 한 번 클릭

## 타겟
- QA, PM, 디자이너, 개발자
- 고객지원팀 (스크린샷으로 답변 작성)
- 블로거 / 강사

## 핵심 기능
- 보이는 영역 / 전체 페이지 캡처
- 화살표, 사각형, 원, 텍스트, 형광펜
- 블러 / 픽셀화 (민감정보 가리기)
- 클립보드 복사 / PNG 다운로드
- 공유 링크 (Pro, 백엔드 업로드)
- 캡처 히스토리 (최근 50개)

## 수익 모델
- Free: 로컬 저장만, 클립보드 복사
- Pro ($4.99/월):
  - 공유 단축 링크 (커스텀 도메인 옵션)
  - 클라우드 저장 무제한
  - 팀 폴더 공유
  - GIF 캡처 (베타)

## 경쟁사
- Awesome Screenshot (Freemium)
- Cleanshot X (데스크톱, $29)
- Lightshot (무료, 광고)
- Loom (영상 중심)

## 차별점
- MV3 기반, 가벼움
- 한국어 폰트 깨짐 없음
- 단순한 가격 (1티어), 가성비
- 오픈소스 코어 (신뢰)

## KPI
- 캡처 / 사용자 / 일
- 공유 링크 클릭률
- Pro 전환율 (목표 7%)
- WAU 30일 리텐션 (목표 40%)
- 평균 주석 개수 / 캡처
- 클립보드 vs 다운로드 vs 공유 비율

## 마일스톤
- M1: 보이는 영역 캡처 + 기본 도구
- M2: 풀 페이지 캡처 + 블러
- M3: 공유 링크 (Pro 백엔드)
- M4: 팀 폴더 + 댓글
- M5: GIF 캡처 베타

## 리스크
- 클라우드 저장 비용 → free 사용자는 로컬만, R2 lifecycle 정책
- 비슷한 무료 도구 다수 → UX 차별화 (속도, 깔끔함) 강조
