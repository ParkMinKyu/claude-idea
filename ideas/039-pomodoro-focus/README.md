# 차단 기능 포함 포모도로 (FocusLock)

## 개요
포모도로 타이머와 함께 SNS·게임 등 방해 앱을 자동 차단하는 집중력 향상 앱.
"숲" 스타일 게이미피케이션 + 한국 사용자 맞춤 차단 리스트가 핵심.

## 문제
- 공부/업무 시 스마트폰 알림과 SNS가 큰 방해 요소.
- 의지력만으로는 SNS를 멀리하기 어려움.
- 기존 포모도로 앱은 단순 타이머 기능만 제공.

## 솔루션
- 25분 집중 / 5분 휴식 표준 포모도로 + 커스텀.
- 집중 시간 동안 특정 앱 자동 차단 (AccessibilityService).
- 강제 종료 시 페널티 (오늘의 나무 죽음 등).
- 일/주/월 집중 시간 통계.

## 타겟 사용자
- 수험생, 대학생.
- 재택근무 직장인.
- 집중력이 약한 ADHD 성향 사용자.

## 핵심 기능
1. 포모도로 타이머 (25/5분 기본, 커스텀).
2. 앱 차단 (사용자 선택, 화이트리스트).
3. 게이미피케이션 (나무 키우기, 숲).
4. 일/주 통계 그래프.
5. 친구와 집중 챌린지.
6. 위젯에서 빠른 시작.

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩9,900: 무제한 차단 앱, 모든 테마/나무 종류.

### 구독
- 월 ₩2,900: 친구 챌린지, 상세 통계, 클라우드 동기화.

### 광고
- 무료 사용자에게 통계 화면 배너 광고.

## 경쟁사
- Forest (포레스트): 글로벌 1위, 차단 기능 약함.
- 열품타 (열정품은 타이머): 한국 1위 공부 트래커.
- Pomofocus: 웹 중심.

## 차별점
- 차단 기능 + 게이미피케이션 + 친구 챌린지 통합.
- 한국 앱 (카카오톡, 인스타, 유튜브) 기본 차단 리스트.
- 위젯에서 빠른 시작.
- 가벼운 앱.

## KPI
- 일일 평균 집중 시간 사용자당 60분 이상.
- 30일 리텐션 35%.
- 차단 활성 사용자 비율 70%+.
- 프리미엄 전환율 6%.
- 평점 4.5 이상.
