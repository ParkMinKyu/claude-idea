# 즐겨찾기 정류장 실시간 도착 (TransitNow)

## 개요
자주 가는 버스 정류장/지하철역을 즐겨찾기하고 위젯·잠금화면에서 실시간 도착 정보를 확인할 수 있는 초경량 대중교통 앱.

## 문제
- 카카오맵/네이버지도는 무거워서 단순 도착 정보 확인이 번거로움.
- 출근/등교 시 매번 정류장 검색 반복.
- 알림 위젯이 부족하거나 디자인 불편.

## 솔루션
- 정류장 즐겨찾기 (집/회사/학교 자동 추천).
- 홈 화면 위젯 (다음 3대 도착 시각).
- 알림: 버스 N분 전 알림.
- 잠금화면 라이브 액티비티 (Android 14+).
- 가벼운 앱 (< 10MB).

## 타겟 사용자
- 출퇴근 직장인.
- 통학 학생.
- 대중교통 사용자.

## 핵심 기능
1. 정류장/역 검색 + 즐겨찾기.
2. 실시간 도착 정보 (TOPIS, ODsay API).
3. 홈 화면 위젯 (Glance).
4. 출발 알림 (집에서 출발할 시간).
5. 환승 정보.
6. 다크 모드 / 큰 글씨 모드.

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩4,900: 광고 제거, 무제한 즐겨찾기(무료 5개).

### 구독
- 월 ₩990: 출발 알림 무제한, 위젯 테마, 자동 백업.

### 광고
- 무료 사용자에게 메인 화면 배너 광고.

## 경쟁사
- 카카오맵, 네이버지도: 종합 앱, 무거움.
- TMAP 대중교통: UI 노후.
- 버스타고: 디자인 약함.

## 차별점
- 가볍고 빠른 위젯 중심 UX.
- 즐겨찾기 패턴 학습 (출근 시 자동 추천).
- 한국 공공데이터 적극 활용.
- 시니어 친화 큰 글씨 모드.

- 일일 위젯 탭 사용자당 평균 5회.
- 평균 즐겨찾기 정류장 3개.
- 30일 리텐션 50% (생활밀착).
- 프리미엄 전환율 3%.
- 평점 4.6 이상.
