# 066 · 마이크로 뉴스레터 호스팅 플랫폼

## 개요
누구나 5분 안에 자신만의 뉴스레터를 발행할 수 있는 가벼운 호스팅형 플랫폼. Substack 대안으로 한국어 친화 에디터, 낮은 수수료, 한국 카드 결제(토스/카카오)를 지원한다.

## 문제
- Substack은 결제 수수료 10%에 추가 Stripe 수수료가 붙어 한국 작가에게 비싸다.
- Stibee, Mailerlite 등은 발송 도구일 뿐 구독 결제·페이월·웹 공개 페이지가 약하다.
- 워드프레스 + 메일링 플러그인 조합은 설정·운영 부담이 크다.
- 1만 명 미만 마이크로 뉴스레터는 ESP 월 정액 비용($50+)을 감당하기 어렵다.

## 솔루션
- 마크다운 기반 글쓰기 → 발송 + 웹 공개 페이지 자동 생성
- 구독자별 발송 토큰(`unsubscribe`, `manage`)으로 List-Unsubscribe 헤더 자동 처리
- Resend SDK로 배치 발송 (도메인 미설정 시 공용 도메인)
- 페이월 글: 유료 구독자에게만 전체 본문 노출, 비구독자는 1/3 미리보기

## 타겟 사용자
- 1만 명 이하 구독자를 가진 한국어 뉴스레터 작가
- 브랜드 콘텐츠 마케터(고객 대상 월간 인사이트 발송)
- 1인 기자/전문가 (전문 분야 분석 뉴스레터)

## 핵심 기능
1. **이슈 작성** — 마크다운 + 이미지 업로드, 발송 전 미리보기·테스트 발송
2. **구독자 관리** — CSV 임포트, 더블 옵트인, 태그·세그먼트
3. **발송 엔진** — Resend 배치 API 호출, 발송 결과(오픈/클릭) 추적
4. **유료 페이월** — Stripe/토스페이먼츠 월·연 구독, 무료 미리보기 비율 설정
5. **웹 아카이브** — `{slug}.example.com`에 SEO 최적화된 백넘버 공개

## 수익 모델
| 구분 | 가격 | 비고 |
|---|---|---|
| Free | $0 | 월 500명 / 1,000건 발송 |
| Creator | $12/월 | 5,000명 / 10,000건 발송, 커스텀 도메인 |
| Pro | $39/월 | 25,000명, 무제한 발송, 페이월 |
| 수수료 | 유료 구독 결제액의 3% | Pro 이상은 0% (Stripe 수수료 제외) |

## 경쟁사
- Substack, Beehiiv, Ghost(Pro), Stibee, Mailerlite, Buttondown

## 차별점
- 한국 카드(토스페이먼츠) 결제 내장으로 PG 별도 계약 불필요
- 페이월 미리보기 비율을 글 단위로 조정 가능 (Substack은 전체/부분 두 가지)
- 발송 비용 정산 명세서 PDF 다운로드 (사업자 회계 처리 편의)
- 뉴스레터 끼리 추천하는 "추천 위젯" 빌트인 (Beehiiv 스타일)

## KPI
- 가입 후 첫 이슈 발송까지 평균 시간 < 30분 (Activation)
- 무료 → Creator 전환율 6% 이상 (3개월 누적)
- 발송 도달률(Inbox placement) 95% 이상
- 유료 페이월 활성화율 10% 이상 (Creator 이상 플랜)
- 월간 활성 작가(MAW) 잔존율 70% (월 측정)
- ARR per active newsletter $180 이상
