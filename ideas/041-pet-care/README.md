# 반려동물 일정/일기 (PetDiary)

## 개요
반려동물의 사료/산책/예방접종/병원 일정을 관리하고, 매일의 활동·사진을 기록하는 통합 반려동물 다이어리.

## 문제
- 반려동물 예방접종/심장사상충 약 등 일정 놓치기 쉬움.
- 여러 마리를 키우면 더욱 관리 어려움.
- 추억을 기록하고 싶지만 SNS는 부담스러움.

## 솔루션
- 반려동물 프로필 (이름, 견종, 체중).
- 사료/산책/약/병원 일정 자동 알림.
- 일별 활동 기록 (산책 시간, 사료 양, 사진).
- 동물병원 검색 및 즐겨찾기.
- 연간 헬스 리포트.

## 타겟 사용자
- 강아지/고양이 보호자 (20~50대).
- 다묘/다견 가정.
- 시니어 반려동물 보호자 (관리 항목 多).

## 핵심 기능
1. 반려동물 등록 + 사진 프로필.
2. 일정 알림 (사료, 산책, 예방접종 등).
3. 일기 작성 + 사진 추가.
4. 체중/식사량 추이 그래프.
5. 동물병원 위치 검색.
6. PDF 헬스 리포트 (병원 방문 시 활용).

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩9,900: 무제한 펫(무료 2마리), 광고 제거.

### 구독
- 월 ₩3,900: 클라우드 백업, 가족 공유, 수의사 채팅 1회/월.

### 광고
- 무료 사용자: 일기 화면 네이티브 광고 (펫푸드 카테고리).

## 경쟁사
- 펫프렌즈, 펫시밀러: 쇼핑 위주.
- 위펫 (We:pet): 일정만 관리.
- 11 Pets: 영문 위주.

## 차별점
- 한국 동물병원 데이터베이스 연동 (잘파마, 펫닥 API).
- 일정 + 일기 + 헬스 리포트 통합.
- 다마리 가정 친화적 UX.
- 큐레이션된 한국 반려동물 콘텐츠.
