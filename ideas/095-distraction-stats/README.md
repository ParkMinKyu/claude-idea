# 095 · 집중 통계 대시보드 (Distraction Stats)

## 개요
포커스 차단기·시간 추적기에서 모은 데이터를 한 화면에 모아 "내 집중 점수"를 일/주/월 단위로 시각화하는 대시보드. 089(시간 추적), 054(focus-blocker)와 같은 패밀리 제품군의 허브.

## 문제
- 시간 추적, 차단기, 캘린더가 각각 별개의 통계만 제공
- "오늘 진짜 집중한 시간"이 얼마인지 한눈에 안 보임
- 주간 회고 시 데이터를 직접 모아야 함

## 솔루션
- Electron 에이전트가 089/054 등에서 이벤트를 수집해 통합
- Next.js 웹 대시보드에서 집중 점수 / 차단 회수 / 미팅 비율 시각화
- 매주 일요일에 PDF 리포트 자동 생성
- 목표 대비 진척도 알림 (Slack/이메일)

## 타겟 사용자
- 자기 측정에 진심인 개발자/디자이너
- 원격 근무자 (자기 효율 증명)
- 매니저 (팀이 아닌 본인 시간만 보고 싶은)

## 핵심 기능
1. **집중 점수** — `(coding + writing) / total_active` 0~100 점수
2. **분포 차트** — 시간대별 활동 카테고리 스택 바
3. **차단 통계** — 차단된 사이트 시도 횟수 + 회피한 시간
4. **주간 리포트** — PDF + 이메일 자동 발송
5. **목표 트래킹** — "주 20시간 코딩"같은 목표 진척도

## 수익 모델
| 플랜 | 가격 | 기능 |
|---|---|---|
| Free | $0 | 7일 보관, 일일 대시보드 |
| Pro | $7/월 | 무제한 보관 + 주간 PDF + Slack 통합 |
| Team | $14/유저/월 | 팀 비교(opt-in) + Admin 대시보드 |

## 경쟁사
- RescueTime, Toggl Track, Rize, Saent, Sorted³

## 차별점
- 단독 추적기가 아니라 "허브" — 089/054 등 패밀리 제품 데이터 통합
- 집중 점수가 단일 지표로 제공 (사용자가 외울 필요 없음)
- PDF 주간 리포트는 매니저 보고에도 유용
- 로컬 우선 (Pro에서만 클라우드 동기화)

## KPI
- 일일 대시보드 진입율 70%
- 사용자당 평균 집중 점수 60 이상
- Pro 전환율 10% (이미 추적기 사용자 대상)
- 주간 PDF 열람율 80%
- 30일 잔존율 65%

## 마일스톤
- M1 (W1-2): 이벤트 수집 API + 집중 점수 계산 + 일일 대시보드
- M2 (W3-4): 시간대 분포 차트 + 차단기 통계 통합
- M3 (W5-6): Stripe + 주간 PDF + Resend 이메일 발송
- M4 (W7-8): Slack 일일 요약 + 목표 알림
- M5 (W9-10): Team 플랜 (Clerk Org) + opt-in 비교 대시보드

- 리스크: "감시 대시보드"로 오해될 수 있음 — opt-in 강조, 본인만 보는 모드 기본
- 리스크: PDF 생성 비용 → 주 1회 한정, 캐시
