# 010 - 냉장고 사진 → 레시피 추천

## 개요
냉장고/식료품 보관함 사진을 찍어 업로드하면, Claude vision이 재료를 인식하고, 보유 재료로 만들 수 있는 레시피 3~5개를 영양 정보와 함께 추천하는 모바일 친화 웹앱.

## 문제
- 매일 "오늘 뭐 먹지" 결정 피로
- 냉장고 속 재료를 잊고 새로 사 음식물 쓰레기 발생 (가정당 연 30만원)
- 레시피 사이트는 재료부터 거꾸로 찾기 불편

## 솔루션
- 사진 1장 업로드 → Claude vision이 재료 자동 인식
- "있는 재료로만" / "1~2가지 추가 구매 허용" 옵션
- 알레르기/식단(저탄수, 고단백, 채식 등) 설정 반영
- 레시피별 영양 정보 + 조리 시간 + 난이도

## 타겟 사용자
- 1인 가구 자취생 (재료 활용 어려움)
- 주부/주부 보조 (저녁 메뉴 결정 피로)
- 다이어트/식단 관리자
- 음식물 쓰레기 줄이기 관심층

## 핵심 기능
1. 사진 업로드 + 재료 인식
2. 인식된 재료 편집(추가/삭제)
3. 레시피 추천 + 영양 정보
4. 즐겨찾기 + 장보기 목록 자동 생성
5. (Pro) 주간 식단 계획 + 가족 인원 조정

## 수익 모델
| 티어 | 가격 | 한도 |
|------|------|------|
| Free | $0 | 일 3회 사진 분석 |
| Plus | $5/월 | 무제한, 주간 계획 |
| Family | $9/월 | 4인 식단, 알레르기 프로필 |
| 광고 | - | Free에 식료품 배달 광고 |

## 경쟁사
- SuperCook: 재료 검색 기반, AI 비전 없음
- Whisk: 레시피 큐레이션, 한국 메뉴 약함
- 만개의레시피, 해먹남녀: 한국 레시피 DB 강점, AI 없음
- ChatGPT vision: 일회성, 식단 관리 없음

## 차별점
- 사진 한 장으로 시작 (검색 입력 없음)
- 한국 가정 식자재(된장, 김치, 멸치 등) 인식 정확도
- 한국 레시피 컨텍스트 학습 + 영문 서양 레시피 옵션
- 식료품 배달 앱(컬리, 쿠팡) 장보기 목록 연동 로드맵

## 핵심 지표 (KPI)
- DAU (저녁 시간대 피크)
- 사진당 평균 인식 재료 수 (정확도)
- 레시피 클릭/저장률
- Free → Plus 전환율 (목표 5%)
- 가족 공유 사용률 (Family 가치)
- 광고 클릭률 (Free 수익)
