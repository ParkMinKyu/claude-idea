# 097 · InkSlot — 타투이스트 예약 시스템

## 개요
타투이스트가 인스타그램 DM·카카오톡으로 받던 예약을 자기만의 도메인에서 예약금 결제까지 한 번에 처리할 수 있게 해주는 SaaS. 상담 → 예약금 → 일정 확정의 전 과정을 자동화한다.

## 문제
- 타투이스트 90% 이상이 인스타 DM으로 예약을 받는다 — DM이 묻혀 노쇼와 일정 충돌이 빈번하다.
- 예약금 입금 확인을 수동으로 하다 보니 작업 시작 전까지 확인 못 한 노쇼 손실이 월 수십만 원.
- 시안 첨부, 부위 사진, 알러지 문진 같은 사전 정보를 흩어진 채널에서 모은다.
- 기존 일반 예약 솔루션(네이버예약, Booksy)은 시안 첨부/사이즈·부위 옵션 같은 타투 특화 필드가 없다.

## 솔루션
- 타투이스트별 공개 예약 페이지 (inkslot.app/{artist})
- 손님이 상담 → 시안 업로드 → 부위·사이즈 선택 → Stripe 예약금 결제까지 한 페이지에서
- 예약금 결제가 완료돼야만 슬롯이 잠긴다 — 노쇼 방지
- 캘린더 뷰 + 캔슬·일정 변경 정책 자동 적용 (예: 48시간 전 변경시 환불 50%)

## 타겟 사용자
- 1인 또는 2~5인 타투 스튜디오 (한국·일본·미국 인디 타투이스트)
- 세미 영구화장(PMU), 아이브로우 아티스트
- 피어싱·바디아트 시술자

## 핵심 기능
1. **공개 예약 페이지** — 작가별 갤러리, 운영시간, 예약 슬롯
2. **상담 폼** — 시안 사진, 부위, 사이즈, 통증 알러지 문진
3. **Stripe 예약금 결제** — 슬롯 잠금은 결제 성공 시에만
4. **캘린더** — 작가 본인용 일일/주간 뷰, ICS 내보내기
5. **자동 리마인더** — 24시간 전 이메일/SMS, 후기 요청 D+3

## 수익 모델
| 플랜 | 가격 | 월 예약 | 결제 수수료 |
|---|---|---|---|
| Solo | $19/월 | 50건 | Stripe 표준 + 1.5% |
| Studio | $49/월 | 무제한 | Stripe 표준 + 1.0% |
| Chain | $129/월 | 무제한 | Stripe 표준 + 0.5% |

거래 수수료는 예약금 금액 기준 자동 차감. 평균 예약금이 ₩50,000 가정 시 Solo 플랜 작가의 월 GMV ₩2.5M → 수수료 ₩37,500 추가 수익.

## 경쟁사
- Booksy, Square Appointments — 미용실 위주, 타투 특화 X
- Calendly + 별도 결제 — 통합되지 않아 운영이 불편
- 인스타 DM (대부분 타투이스트의 현 상태)

## 차별점
- "시안 업로드 + 예약금 선결제"가 기본 흐름 — 노쇼 방지가 1순위 가치 제안
- 타투 특화 폼 필드(부위, 사이즈, 컬러/블랙, 알러지)
- 인스타 BIO 링크 한 줄로 즉시 도입 가능
- 한국 카카오톡 알림 + 글로벌 Stripe 동시 지원

## KPI
- 예약 완료까지 평균 클릭 < 8회 (퍼널)
- 노쇼율 < 5% (DM 예약 평균 15%)
- 예약금 → 시술 완료 전환율 90% 이상
- 작가당 ARR $400 이상 (구독 + 수수료)
- 30일 작가 잔존율 80% 이상
