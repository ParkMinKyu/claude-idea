# 007 - PR 자동 1차 리뷰 봇

## 개요
GitHub App을 설치하면 모든 PR에 대해 Claude가 1차 코드 리뷰를 자동 수행합니다. 명백한 버그, 보안 이슈, 컨벤션 위반, 누락된 테스트를 인라인 코멘트로 남겨, 사람 리뷰어의 부담을 줄여줍니다.

## 문제
- 시니어 엔지니어 시간의 20~30%가 PR 리뷰에 소비
- 사소한 지적(네이밍, 누락 import, off-by-one)이 리뷰의 절반
- 작은 팀은 리뷰어가 부족해 PR이 며칠씩 정체됨

## 솔루션
- GitHub App 설치 → 모든 PR에 자동 작동
- Claude가 diff + 변경된 파일 컨텍스트를 읽고 인라인 코멘트
- 리뷰 깊이 설정 (가벼움/표준/엄격)
- 사용자 컨벤션 학습 (.ai-reviewer.yml로 룰 등록)

## 타겟 사용자
- 시니어 1~2명 + 주니어 5~10명 구성의 스타트업
- 오픈소스 메인테이너 (외부 PR 1차 검토 자동화)
- 사이드 프로젝트 1인 개발자 (셀프 리뷰 보조)

## 핵심 기능
1. GitHub App 설치 → PR 자동 트리거
2. Claude 기반 인라인 코멘트 (라인별 지적)
3. PR 전체 요약 코멘트 ("LGTM with minor issues" 등)
4. 룰 설정 파일 (.ai-reviewer.yml)
5. (Pro) 자체 코드베이스 학습으로 컨벤션 자동 추론

## 수익 모델
| 티어 | 가격 | 한도 |
|------|------|------|
| OSS | $0 | 공개 저장소 무제한 |
| Solo | $19/월 | 비공개 5개 저장소 |
| Team | $49/월/저장소 | 비공개 무제한 PR |
| Enterprise | 협의 | self-hosted |

## 경쟁사
- CodeRabbit: 강력하지만 비쌈 ($24/dev/월)
- Codium AI PR-Agent: OSS, 셋업 복잡
- GitHub Copilot for PRs: 베타, 요약 위주
- Sweep, Aider: 코드 작성 중심

## 차별점
- 한국어 코멘트 지원 (한국 팀 친화)
- OSS 무료 정책 + 가격 경쟁력 (CodeRabbit 대비 50% 저렴)
- 룰 파일로 화이트리스트/블랙리스트 명시적 제어
- 사용자 피드백(👍/👎)으로 false positive 학습

## 핵심 지표 (KPI)
- 설치된 저장소 수
- PR당 코멘트 개수 + 채택률 (👍 비율)
- 리뷰 latency (PR open → 봇 코멘트)
- OSS → Solo 전환율
- Team plan churn (목표 월 5% 이하)
- False positive 신고율 (품질 지표)

## 향후 로드맵
- M1: 기본 인라인 리뷰 (MVP)
- M2: 룰 설정 파일 + 카테고리별 토글
- M3: 사용자 피드백 학습 (false positive 감소)
- M4: 코드베이스 컨벤션 자동 추론

## 리스크와 대응
- 잘못된 지적으로 PR 작성자 짜증 → "AI Review" 명시 + 👎 피드백 수집
- 큰 PR diff 토큰 비용 → 파일 단위 분할 + 최대 라인 제한
- 보안: 코드 일시 처리, 로깅 금지, GitHub App 권한 최소화
