# 004 - 계약서 위험 조항 하이라이트

## 개요
계약서 PDF를 업로드하면 Claude가 표준 대비 위험한 조항(과도한 책임 면제, 일방 해지권, 모호한 손해배상 등)을 자동 탐지하여 색상별로 하이라이트하고, 협상 가이드를 제공하는 SaaS입니다.

## 문제
- 스타트업/프리랜서는 법무팀이 없어 NDA·MSA·SOW를 변호사 검토 없이 서명하는 경우가 많음
- 변호사 검토 비용은 시간당 30~50만원, 1건당 100만원 이상
- 영문 계약서는 더욱 진입 장벽 높음

## 솔루션
- PDF 업로드 → PDF.js로 클라이언트에서 텍스트 추출
- Claude가 조항별로 위험도(낮음/중간/높음) + 위험 사유 + 대안 문구 제안
- 하이라이트된 PDF 뷰어로 변호사 위임 전 셀프 체크 가능
- 협상 시나리오별 답변 템플릿 제공

## 타겟 사용자
- 1인 사업자/프리랜서 (NDA, 용역 계약 반복)
- 시리즈 A 이하 스타트업 (외주/입점 계약)
- 사내 법무 보조 직원 (1차 검토 부담 경감)

## 핵심 기능
1. PDF 업로드 + 텍스트 추출
2. 조항 분리 + 위험도 자동 라벨링
3. 인터랙티브 PDF 뷰어 (위험 조항 클릭 → 설명/대안)
4. 위험도 리포트 PDF export
5. (Pro) 자체 계약 템플릿 등록 + 비교 분석

## 수익 모델
| 티어 | 가격 | 한도 |
|------|------|------|
| Free | $0 | 월 1건, 위험도만 표시 |
| Solo | $29/월 | 월 20건, 협상 가이드 |
| Team | $99/월 | 무제한, 5명, 템플릿 비교 |
| 1회 결제 | $9/계약 | 비정기 사용자 |

## 경쟁사
- Ironclad, LinkSquares: 엔터프라이즈, 가격 부담
- Spellbook (legal AI): 영문 중심
- 국내: 법무법인의 정액제 검토 (10만원/건~), AI 자동화 X

## 차별점
- 한국어 계약서 + 한국 민법 컨텍스트 학습 (시스템 프롬프트에 주요 판례/표준약관 임베드)
- PDF.js로 브라우저에서 텍스트 추출 → 계약서 원본 서버 업로드 없음 (보안)
- 1회 결제 옵션으로 신규 사용자 진입 장벽 낮춤

## 핵심 지표 (KPI)
- 가입 → 첫 분석 전환율
- 분석 후 PDF 리포트 다운로드율
- 위험 조항당 평균 클릭 수 (참여도)
- Free → Solo 전환율 (목표 10%)
- 1회 결제 비중 (구독 거부 사용자 흡수)
- 변호사 추천 전환 (제휴 수수료 추가 수익원)

## 향후 로드맵
- M1: PDF 업로드 + 위험도 표시 (MVP)
- M2: 협상 가이드 + PDF 리포트 export
- M3: 자체 템플릿 등록 + 변경 추적
- M4: 변호사 추천 마켓플레이스 연계 (제휴 수수료)

## 리스크와 대응
- 법률 오류로 인한 책임 우려 → "법률 자문 대체 불가" 명시 + 변호사 연결 옵션
- 계약서 데이터 극도 민감 → 클라이언트 측 텍스트 추출 + 무상태 처리
- 한국 민법 컨텍스트 깊이 → 시스템 프롬프트 + 추후 RAG로 판례 보강
