# 086 · 새 탭 = 할 일 목록 (Tab Todo)

## 개요
Chrome/Edge 새 탭(New Tab)을 열 때마다 오늘 해야 할 일 목록이 자동으로 노출되는 MV3 확장 프로그램. 검색창을 띄우는 대신 "지금 무엇에 집중해야 하는지"를 매 탭마다 상기시켜 산만함을 줄인다.

## 문제
- 새 탭을 열면 빈 검색창 → 무의식적으로 유튜브·트위터로 이동
- Todoist·TickTick은 별도 앱을 켜야 해서 행동 마찰이 큼
- 기존 newtab 확장은 위젯 과잉으로 무겁고 광고가 많음

## 솔루션
- 새 탭 진입 즉시 오늘의 할 일 5개 표시
- 인라인 추가/완료 토글 (Enter, Space 단축키)
- 모든 데이터를 `chrome.storage.sync`에 저장 (디바이스 간 동기화)
- 다크 모드 + 한 줄짜리 미니멀 UI

## 타겟 사용자
- 산만함에 자주 빠지는 개발자/지식 노동자
- ADHD 성향의 셀프 매니지먼트가 필요한 사용자
- Notion/Todoist를 쓰지만 매번 열기 귀찮은 사용자

## 핵심 기능
1. **오늘의 5개** — 가장 위 5개만 노출, 그 이상은 "더보기" 토글
2. **빠른 추가** — `n` 키로 새 할 일, `Enter`로 저장
3. **완료 토글** — `Space`로 완료/되돌리기, 완료 시 페이드 아웃
4. **요일 반복** — `mon,wed,fri` 같은 반복 규칙
5. **포커스 모드** — 한 가지만 크게 보여주는 단일 작업 모드
