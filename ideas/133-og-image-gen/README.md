# 133 · OG Image Generator (OG 이미지 동적 생성)

## 개요
URL 쿼리 파라미터(`?title=...&bg=...`)만으로 SNS 공유용 Open Graph 이미지를
실시간 생성하는 서비스입니다. SVG 템플릿에 제목·부제·색상을 주입해 마크업을
만들고, 엣지에서 PNG/JPEG로 래스터화합니다. 템플릿/레이아웃/검증 로직은 순수
함수로 분리되어 캐싱과 테스트가 쉽습니다.

## 문제
- 블로그 글·랜딩 페이지마다 OG 이미지를 디자이너가 일일이 만들기 어렵습니다.
- 동적 콘텐츠(상품, 사용자 프로필)에 맞춘 공유 이미지 자동화가 까다롭습니다.
- 잘못된 사이즈/비율이면 SNS에서 잘리거나 흐릿하게 표시됩니다.
- 텍스트를 그대로 SVG에 넣으면 XML 인젝션·깨짐 위험이 있습니다.

## 솔루션
파라미터 → 검증된 설정 → SVG → 이미지 파이프라인을 제공합니다. 안전한 XML
이스케이프, 자동 줄바꿈, 표준 1200×630 비율을 기본 제공하고, URL 캐싱으로
CDN 친화적으로 동작합니다.

## 타겟 사용자
- 정적/동적 사이트를 운영하는 개발자와 콘텐츠 팀
- 헤드리스 CMS·블로그 플랫폼 통합이 필요한 SaaS
- 상품/프로필 공유 이미지를 대량 생성하는 마켓플레이스

## 핵심 기능
1. 쿼리 파라미터 기반 동적 OG 이미지 생성
2. 다중 템플릿(basic/split/minimal) 및 색상 커스터마이즈
3. 자동 줄바꿈 + 안전한 XML 이스케이프
4. SVG → PNG/JPEG 엣지 래스터화 (sharp/resvg)
5. URL 단위 CDN 캐싱 (불변 응답)

- Business ($49/월): 무제한 캐시, 팀 템플릿, 우선 렌더

## 차별점

- SVG 코어가 순수 함수라 어떤 런타임/엣지에도 이식 가능
- URL 캐싱 우선 설계로 CDN 비용·지연 최소화
- 템플릿을 코드가 아닌 데이터로 다뤄 협업 용이
