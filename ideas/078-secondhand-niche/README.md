# 078 - 카메라 중고 거래 마켓플레이스

## 개요
DSLR, 미러리스, 렌즈, 필름카메라 등 카메라 장비에만 특화된 중고 거래 플랫폼입니다. 일반 중고 플랫폼의 사기 위험을 줄이기 위해 에스크로 결제와 셔터카운트/시리얼 검증 기능을 제공합니다.

## 문제
- 당근/번개장터에서 카메라 거래는 사기 위험이 큼 (특히 100만원+ 렌즈)
- 일반 플랫폼은 "셔터카운트", "수리 이력" 같은 카메라 특화 메타데이터 부재
- 직거래 외 옵션이 없어 지방 거주자가 불리
- 가품/리퍼 식별 가이드가 부족함

## 솔루션
- Stripe Connect 기반 에스크로: 구매자 결제 → 7일 검수 후 셀러 정산
- 카테고리 특화 입력 폼: 셔터카운트, 펌웨어 버전, 수리 이력, 박스 구성품
- 모델 DB 자동완성 (Sony A7M4, Canon RF 70-200 등) — 정형화된 검색
- 검증 배지: 셔터카운트 스크린샷, 시리얼 일치 사진 업로드 시 부여

## 타겟 사용자
- 카메라 장비를 자주 사고파는 사진 동호인, 프리랜서 사진가
- 신품 가격이 비싼 렌즈를 중고로 입문하려는 신규 유저
- 장비를 정리하는 은퇴 사진가, 스튜디오 폐업 사장

## 핵심 기능
1. 카메라 특화 리스팅 폼 (모델 DB, 셔터카운트, 박스 구성품 체크박스)
2. Stripe Connect 에스크로 결제
3. 분쟁 조정 + 7일 검수 자동 정산
4. 시세 트래커 (모델별 30일 평균/최저/최고가)
5. 검증 배지 (셔터/시리얼/박스)
6. (Phase 2) 위탁 판매 — 셀러가 발송, 플랫폼이 검수 후 판매

## 수익 모델
| 항목 | 수수료 |
|------|------|
| 거래 수수료 | 판매가의 6% (셀러 부담) |
| 결제 수수료 | Stripe 표준 (구매자 부담 옵션) |
| 프리미엄 셀러 | $9/월 — 상위 노출, 리스팅 무제한 |
| 광고 | 모델 상단 배너 (카메라 매장 대상) |

## 경쟁사
- MPB.com: 글로벌 강자, 위탁/매입 중심, 한국 미진출
- KEH Camera: 미국 위탁, 같은 모델
- 당근/번개장터: 일반 중고, 사기 위험
- 디시 카메라 갤러리 직거래: 커뮤니티 신뢰 기반, 결제 보호 없음

## 차별점
- 한국 카메라 커뮤니티 전용 — 에스크로 + 카메라 특화 메타데이터
- MPB처럼 위탁이 아닌 P2P 중심으로 셀러 수익 극대화 (수수료 6% vs MPB 30%+)
- 시세 트래커로 거래 가격 투명화 (한국 시장 데이터 누적)
- 검증 배지로 신뢰 형성 (사진 1장 검증으로 가격 +10% 효과)

## 핵심 지표 (KPI)
- GMV (월간 거래 총액)
- 거래 분쟁율 (목표 1.5% 미만)
- 리스팅 → 거래 전환율
- 평균 거래액 (목표 50만원 이상)
- 셀러 재거래율 (목표 30% 이상)
- 검증 배지 부여율 (목표 40% 이상)

## 출시 로드맵
- M1: 리스팅 + 검색 + Stripe Connect 에스크로 (DSLR/미러리스만)
- M2: 카테고리 확장 (렌즈/필름카메라/액션캠), 시세 트래커
- M3: 위탁 판매 — 셀러 발송, 플랫폼 검수
- M4: 모바일 앱 (RN), 알림(찜한 모델 시세 변동)
- M5: 인접 카테고리 — 오디오 장비, 자전거
