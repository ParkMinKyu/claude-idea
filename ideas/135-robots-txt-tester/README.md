# 135 · robots.txt Tester (robots.txt 검증)

## 개요
robots.txt 파일을 RFC 9309 규칙대로 파싱하고, 특정 User-agent가 특정 URL을
크롤링할 수 있는지 판정하는 검증 도구입니다. 최장 일치(longest-match), Allow/
Disallow 우선순위, 와일드카드(`*`)·끝 앵커(`$`)까지 정확히 구현했습니다. 모든
로직이 순수 함수라 테스트와 엣지 배포가 쉽습니다.

## 문제
- robots.txt 규칙의 매칭 우선순위(최장 일치, Allow 우선)는 직관과 다릅니다.
- 잘못된 규칙 하나로 검색엔진이 전체 사이트를 색인하지 못할 수 있습니다.
- 와일드카드/앵커 패턴 동작을 손으로 검증하기 어렵습니다.
- 변경 시 회귀를 막을 자동화된 테스트 수단이 부족합니다.

## 솔루션
robots.txt를 그룹 단위로 파싱하고, 임의의 User-agent/URL 조합에 대해 허용 여부를
즉시 판정합니다. 규칙 변경 전후를 비교(diff)해 의도치 않은 차단/허용을 잡아냅니다.
CI에 붙여 robots.txt 회귀를 방지할 수 있습니다.

## 타겟 사용자
- SEO 담당자 및 기술 SEO 컨설턴트
- robots.txt를 자주 수정하는 웹 개발팀
- 크롤러를 운영하며 정책 준수가 필요한 데이터 팀

## 핵심 기능
1. RFC 9309 준수 robots.txt 파서 (그룹/사이트맵/crawl-delay)
2. User-agent별 최장 일치 + Allow 우선 매칭
3. 와일드카드(`*`)·끝 앵커(`$`) 패턴 지원
4. 특정 UA/URL 허용 여부 단건 검사 (CLI/API)
5. 규칙 변경 diff 및 CI 게이트 (Pro)
