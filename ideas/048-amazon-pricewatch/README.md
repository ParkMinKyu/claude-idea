# 048 - Amazon PriceWatch

아마존 상품의 가격을 추적하고 변동 시 알림을 제공하는 Chrome Extension (MV3).

## 개요
아마존에서 사고 싶은 상품을 즐겨찾기하면 백그라운드에서 주기적으로 가격을 가져와 차트로 보여주고, 사용자가 설정한 목표 가격에 도달하면 데스크톱 알림을 보냅니다. 가격 변동/할인 시점에 자연스럽게 구매를 유도해, 사용자가 손해보지 않게 합니다.

## 문제
- 아마존 가격은 시간대/요일에 따라 자주 변함 (Camelcamelcamel 통계)
- 매번 사이트를 방문하기 번거로움
- 기존 도구는 회원가입 필요, 알림이 이메일로만 옴

## 솔루션
- 상품 페이지에서 "Track" 버튼 클릭으로 즉시 추적 시작
- 백그라운드 fetch로 12시간마다 가격 갱신
- 목표 가격 도달 시 chrome.notifications + 배지
- 30일 가격 히스토리 차트
- Pro: 1시간 단위 추적, 다국가(미국/일본/독일), 메일 알림

## 타겟
- 아마존 헤비 쇼퍼 (미국·일본·독일)
- 디지털 제품 위시리스트 관리자
- 직구족, 셀러

## 핵심 기능
- 원클릭 상품 추적
- 가격 히스토리 차트 (Canvas, SVG)
- 목표 가격 도달 알림
- 다국가 amazon.com / .co.jp / .de
- 위시리스트 export CSV (Pro)
- 가격 하락률 % 표시

## 수익 모델
- Free: 추적 상품 5개, 12시간 주기, 미국만
- Pro ($3.99/월):
  - 추적 상품 무제한
  - 1시간 주기 갱신
  - 다국가, 이메일 알림
  - CSV export, 가격 예측 (베타)

## 경쟁사
- Camelcamelcamel (웹사이트, 무료, 광고)
- Keepa (구독 $19/월)
- Honey (쿠폰 중심)

## 차별점
- 가격이 Keepa의 1/5
- 회원가입 불필요 (Free)
- 다국가 동시 추적
- 페이지 내 인라인 차트 (별도 사이트 방문 불필요)

## KPI
- 추적 중인 상품 수 / 사용자
- 알림 클릭률
- 알림 후 구매 전환 (아피리에이트로 측정 가능)
- Pro 전환율 (목표 6%)
