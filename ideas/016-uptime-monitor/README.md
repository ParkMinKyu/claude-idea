# 016 · 경량 업타임 모니터링 SaaS

## 개요
사이트와 API 엔드포인트의 가용성을 1분 단위로 폴링해서 다운타임을 알려주는 가벼운 SaaS. Pingdom·UptimeRobot의 합리적 가격대 대체재를 지향한다.

## 문제
- 기존 업타임 모니터링 서비스는 무료 플랜 제한이 빡빡(5분 폴링, 50개 모니터)하거나 유료 플랜이 월 $15 이상으로 비싸다.
- 인디 해커·소규모 팀은 SSL 만료, DNS 변경, 단순 HTTP 200 체크만 필요한데 엔터프라이즈 기능 비용까지 지불해야 한다.
- 자체 호스팅 대안(예: Uptime Kuma)은 운영 부담이 있다.

## 솔루션
- HTTP/HTTPS, TCP, Ping 체크를 30/60/300초 간격으로 실행
- 다운 발생 시 이메일·Slack·Webhook으로 즉시 알림
- 응답 시간 그래프와 SSL 만료 카운트다운 제공
- 공개 상태 페이지 자동 생성 (status.{slug}.example.com)

## 타겟 사용자
- 인디 해커, 1인 SaaS 운영자
- 5~30개의 마이크로서비스를 운영하는 소규모 스타트업
- 클라이언트 사이트를 관리하는 프리랜서 개발자

## 핵심 기능
1. **모니터 CRUD** — URL, 메서드, 기대 상태 코드, 폴링 주기 설정
2. **크론 워커** — Node `node-cron`으로 1분 단위 fan-out 실행, 결과를 Postgres에 기록
3. **알림 채널** — 이메일(Resend), Slack incoming webhook, 사용자 정의 webhook
4. **응답 시간 차트** — 최근 24시간/7일 응답 시간 라인 차트
5. **공개 상태 페이지** — 가동률 90일 히트맵을 슬러그 URL로 공유

## 수익 모델
| 플랜 | 가격 | 모니터 수 | 폴링 주기 | 알림 채널 |
|---|---|---|---|---|
| Free | $0 | 5 | 5분 | 이메일 |
| Starter | $9/월 | 25 | 1분 | 이메일 + Slack |
| Pro | $29/월 | 100 | 30초 | 모든 채널 + 다중 리전 |
| Agency | $79/월 | 500 | 30초 | 화이트라벨 상태 페이지 |

## 경쟁사
- UptimeRobot, Pingdom, BetterStack, Hyperping, Uptime Kuma(OSS)

## 차별점
- 1분 폴링이 Starter 플랜부터 가능 (UptimeRobot은 Pro부터)
- 공개 상태 페이지 기본 포함 (BetterStack은 상위 플랜)
- 다국어 알림 템플릿(한·영·일) 기본 제공
- 응답 본문 정규식 검증 무료 플랜부터 허용

## KPI
- 가입 후 첫 모니터 생성까지 평균 시간 < 3분 (Activation)
- 무료 → Starter 전환율 4% 이상 (월 측정)
- 알림 발송 실패율 < 0.1%
- 30일 잔존율 60% 이상
- ARR per active workspace $120 이상
