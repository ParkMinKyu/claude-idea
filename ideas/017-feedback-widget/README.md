# 017 · 임베드형 사용자 피드백 위젯

## 개요
한 줄의 `<script>` 태그로 어떤 웹사이트에도 붙일 수 있는 가벼운 피드백 수집 위젯. 별점·NPS·자유 텍스트·스크린샷을 단일 위젯으로 제공한다.

## 문제
- Hotjar·UserVoice 같은 도구는 비싸고 무겁다(번들 100KB+).
- 자체 구현은 스토리지·관리자 UI·이메일 알림까지 만들어야 해 시간이 든다.
- 개발자는 빠르게 출시한 MVP에서 실제 사용자 피드백을 구조적으로 모을 채널이 필요하다.

## 솔루션
- < 12KB gzip Vanilla JS 위젯, 의존성 0
- 위젯 → REST API → Postgres 저장 → Slack/이메일 알림
- 대시보드에서 감정 분류·태그·해결 상태 관리
- 임베드 코드 1줄: `<script src="https://cdn.fb.example/v1.js" data-key="pk_..."></script>`

## 타겟 사용자
- 인디 해커, 얼리 스테이지 SaaS
- 디자인 에이전시(클라이언트 사이트에 부착)
- 사내 도구 PM(직원 피드백 수집)

## 핵심 기능
1. **위젯 UI** — 플로팅 버튼 → 모달 폼. NPS/별점/자유 텍스트 모드 전환
2. **스크린샷 첨부** — `html2canvas` 동적 로드(옵션)
3. **위젯 설정** — 색상·위치·언어 대시보드에서 즉시 반영(redeploy 불필요)
4. **인박스 + 상태 관리** — Open/Planned/Done 칸반
5. **알림 라우팅** — 키워드별 Slack 채널 분기
