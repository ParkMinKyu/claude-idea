# 025 · 슬랙 스탠드업 자동화

## 개요
정해진 시간에 팀원에게 DM으로 스탠드업 질문을 던지고, 답변을 한 채널에 요약 게시하는 슬랙 봇.

## 문제
- 회의식 스탠드업은 비동기 팀에 비효율적이다.
- 기존 봇(Geekbot)은 사용자당 월 $3로 누적되면 비싸다.
- 응답 모으기·요약·미응답 알림을 자체 구현하면 시간이 든다.

## 솔루션
- Slack OAuth로 워크스페이스 설치
- 시간대별 스탠드업 스케줄(예: 평일 10:00)
- DM으로 질문 → 응답 모음 → 채널 요약 자동 게시
- 미응답자 리마인더, 휴가 자동 제외

## 타겟 사용자
- 원격/하이브리드 개발팀
- 디자인/마케팅 팀
- 스타트업 전체 회사

## 핵심 기능
1. **스탠드업 스케줄** — cron, 타임존, 평일/주말 설정
2. **질문 템플릿** — 기본 3종(어제/오늘/블로커) + 커스텀
3. **DM 수집기** — Slack Block Kit 폼
4. **채널 요약** — 모든 응답을 스레드로 정리
5. **휴가/공휴일 자동 제외** — 외부 캘린더 연동(Google Cal)

## 수익 모델
| 플랜 | 가격 | 사용자 | 스탠드업 수 | 통합 |
|---|---|---|---|---|
| Free | $0 | 5 | 1 | Slack only |
| Team | $2/사용자/월 | 무제한 | 5 | + Google Cal |
| Pro | $4/사용자/월 | 무제한 | 무제한 | + 분석 + API |

## 경쟁사
- Geekbot, Standuply, Friday, Range, DailyBot

## 차별점
- Geekbot 대비 사용자당 33% 저렴
- 한국어 질문 템플릿 기본
- 휴가 자동 제외(타사는 수동)
- 응답 데이터 export (CSV) 모든 플랜 제공

## KPI
- 워크스페이스 설치 → 첫 스탠드업 실행 비율 80%+
- 평균 응답률 75%+
- 사용자당 ARPU 월 $2.5+
- 14일 잔존율 70%+
- 평균 워크스페이스 사용자 15명+
