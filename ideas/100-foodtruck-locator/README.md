# 100 · TruckPin — 푸드트럭 위치/메뉴 SaaS

## 개요
푸드트럭이 오늘의 영업 위치와 메뉴를 한 번 등록하면 고객용 지도, 인스타·카카오 공유 카드, 매장 알림을 자동 생성해주는 SaaS. 트럭 운영자는 위치를 "지금 영업 중"으로 켜고 끄기만 하면 된다.

## 문제
- 푸드트럭은 매일 위치가 바뀌어 단골이 어디로 가야 할지 모른다.
- SNS에 매번 사진 + 위치 게시물 만드는 게 번거롭다 — 결국 안 한다.
- 인근 직장인·학생이 트럭이 왔는지 알 방법이 없다.
- 기존 푸드트럭 앱(Roaming Hunger 등)은 미국 위주, 한국 노점·푸드트럭 시장 미지원.

## 솔루션
- 운영자가 모바일에서 "오늘 위치" 핀 + 영업 시간만 설정
- 자동 생성되는 공개 페이지(truckpin.app/{truck}) — 지도, 오늘 메뉴, 영업시간
- 인스타·카카오톡 공유용 OG 이미지 자동 생성
- "5분 후 영업 종료" 같은 푸시 알림 — 단골 follower에게 발송
- 트럭이 위치 ON/OFF 토글만 하면 매장 알림이 보내짐

## 타겟 사용자
- 1~3대 푸드트럭 운영하는 자영업자
- 일주일 단위로 위치 바뀌는 팝업 카페·디저트 트럭
- 푸드트럭 협회·페스티벌 운영자 (다수 트럭 일괄 관리)

## 핵심 기능
1. **위치 푸시** — 운영자 앱에서 GPS 자동 또는 수동으로 위치 설정
2. **오늘의 메뉴** — 매일 메뉴/가격 수정, 솔드아웃 토글
3. **단골 팔로우** — 손님이 트럭 follow → 영업 시작 시 푸시
4. **지도 위젯** — 동네/지역 페이지에 영업 중인 모든 트럭 표시
5. **분석 대시보드** — 페이지 뷰, 팔로우, 단골 유입 시간대

## 수익 모델
| 플랜 | 가격 | 트럭 수 | 팔로워 푸시 |
|---|---|---|---|
| Solo | $9/월 | 1대 | 500명 |
| Crew | $29/월 | 3대 | 2000명 |
| Fleet | $89/월 | 10대 | 무제한 |

거래 수수료 없음(정액). 추후 매장 픽업 주문 추가 시 주문당 5% 옵션.

## 경쟁사
- Roaming Hunger, Street Food Finder — 미국, 한국 X
- 인스타그램 스토리 — 가장 큰 경쟁자 (현재 운영자 대부분의 선택)
- 네이버 지도 등록 — 위치 변경이 잦은 트럭에 부적합

## 차별점
- "지금 영업 중" 토글 하나가 핵심 — UX 복잡도 최소화
- 인스타 OG 이미지 자동 생성으로 SNS 게시물 시간 절약
- 한국 카카오톡 알림 + 푸시 동시 지원
- 동네 단위 발견 페이지 — 사용자 자연 유입 (SEO)

## KPI
- 트럭 신규 등록 후 첫 위치 핀까지 < 5분
- 트럭당 평균 팔로워 50명 이상 (90일)
- 위치 토글 → 푸시 발송 지연 < 30초
- 30일 트럭 잔존율 70% 이상
- ARR per 트럭 $200 이상
