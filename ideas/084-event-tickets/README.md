# 084 - 소규모 이벤트 티켓팅

## 개요
북토크, 워크샵, 미니 콘서트 등 50~300명 규모의 소규모 이벤트 주최자를 위한 티켓 판매 + QR 입장 SaaS입니다. Eventbrite의 단순한 한국 대안.

## 문제
- 인터파크/예스24는 대형 공연 위주, 등록 어렵고 수수료 부담
- 무료 도구(구글폼)는 결제 연동 없음, 좌석/정원 관리 미흡
- 입장 확인은 명단 종이 출력 → 줄 길어짐
- 환불/취소 정책이 주최자마다 다르고 분쟁 잦음

## 솔루션
- 주최자가 이벤트(제목/일시/장소/티켓 종류) 등록
- 참가자는 결제 → 이메일로 QR 티켓 자동 발송
- 주최자는 모바일로 QR 스캔, 중복 입장 방지
- 환불 정책 사전 명시, Stripe 환불 1클릭

## 타겟 사용자
- 북토크/세미나 주최자, 1인 강사
- 인디 뮤지션, 코미디 공연 기획자
- 커뮤니티/모임 운영자 (개발자 컨퍼런스, 디자인 살롱)
- 클래스/워크샵 (도예, 와인, 향수)

## 핵심 기능
1. 이벤트 + 다중 티켓 종류 (얼리버드, 일반, VIP)
2. Stripe Checkout 결제
3. 자동 이메일 + QR 코드 생성
4. 모바일 QR 스캐너 (PWA 카메라 활용)
5. 입장 통계 (실시간 카운트)
6. (Phase 2) 좌석 지정, 할인 코드

## 수익 모델
| 티어 | 가격 | 수수료 |
|------|------|------|
| Free | $0 | 거래당 2.5% + $0.5 |
| Pro | $19/월 | 거래당 1.5%, 자체 도메인 |
| Studio | $79/월 | 0%, 다이벤트, API |

비교: Eventbrite 글로벌 3.7% + $1.79.

## 경쟁사
- Eventbrite: 글로벌, 수수료 부담, 한국어 약함
- 인터파크/예스24: 대형 공연 중심
- Vingle, 온오프믹스: 한국 커뮤니티 이벤트
- Luma (lu.ma): 무료, 결제 통합 약함

## 차별점
- 한국어 + 원화 결제, 사업자 등록증 발급 지원
- 입장 QR이 핵심 — 종이 명단 제거
- 50~300명 규모에 최적화 (Eventbrite는 대형 위주)
- 환불 자동화 — 주최자 운영 부담 절감

## 핵심 지표 (KPI)
- 활성 주최자 수 (월 1+ 이벤트)
- 평균 이벤트 매출
- 티켓 → 실제 입장률 (목표 85% 이상)
- 환불 처리 시간 (목표 5분 이내)
- Free → Pro 전환 (이벤트당 200매 이상 판매 시점)
- QR 스캔 평균 응답 시간 (목표 1초 이내)

## 출시 로드맵
- M1: 이벤트 + 다중 티켓 + Stripe + QR 이메일
- M2: PWA 모바일 스캐너, 환불 자동화, 입장 통계
- M3: 좌석 지정, 할인 코드, 그룹 티켓
- M4: 자체 도메인 매핑, 매출 정산 리포트 (사업자용)
- M5: 시리즈 이벤트 (구독형 멤버십), 대기열 관리
