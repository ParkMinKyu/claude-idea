# 069 · 숏폼 비디오 CMS

## 개요
크리에이터 자체 사이트에 TikTok·Reels 스타일 숏폼 피드를 호스팅할 수 있는 헤드리스 CMS. 동영상은 Mux 또는 Cloudflare Stream으로 트랜스코딩·HLS 스트리밍하고, 웹훅으로 메타데이터를 가져와 자체 피드 UI에 노출한다.

## 문제
- TikTok·인스타그램은 외부 사이트로의 트래픽 유입이 막혀 있어 크리에이터가 자기 채널·뉴스레터·상품 페이지로 연결하기 어렵다.
- 자체 사이트에 숏폼을 올리려면 트랜스코딩·CDN·자동 화면비 조정·자동 자막 등 인프라가 과중하다.
- WordPress + Video.js 조합은 모바일 세로 풀스크린 UX가 부실하다.
- 광고 삽입·시청 통계가 빈약해서 수익화로 연결되지 않는다.

## 솔루션
- 업로드 URL 발급(Direct upload to Mux) → 트랜스코딩 완료 웹훅 수신 → 피드 자동 갱신
- 모바일 풀스크린 세로 피드(스와이프) + 데스크톱 그리드 두 가지 모드
- 시청률(view ratio) 곡선과 retention drop-off 분석 대시보드
- pre-roll/mid-roll/post-roll 광고 슬롯, 자체 광고주 또는 IMA SDK 연동

## 타겟 사용자
- 인플루언서, 뷰티/요리/피트니스 크리에이터의 자체 채널 사이트
- 미디어/잡지의 숏폼 콘텐츠 섹션 (예: Vogue Korea)
- 이커머스 브랜드 (제품 숏폼 리뷰 페이지)

## 핵심 기능
1. **다이렉트 업로드** — 클라이언트가 Mux로 직접 PUT, 백엔드는 토큰만 발급
2. **자동 트랜스코딩 + HLS** — 9:16 자동 크롭, 240p~1080p 5단계
3. **세로 풀스크린 피드** — Swiper 기반, 미리 로드(prefetch) 2개
4. **시청 분석** — 0/25/50/75/100% 지점 도달률 + 평균 시청 시간
5. **광고 슬롯** — 영상 N개당 1회 광고, frequency cap 적용

## 경쟁사
- Mux 자체, Cloudflare Stream, Bunny Stream, Vimeo OTT, Brightcove

## 차별점
- Mux/Stream 위에 얹는 "재생 UI + 광고 + 분석" 레이어 (저비용 부가가치)
- 한국어 자막 자동 생성 + 단어 강조 스타일(시각적 후킹)
- 인스타그램 reels 임포트 (캡션·해시태그 보존)
- 임베드 코드 1줄로 자체 사이트에 풀스크린 피드 삽입

## KPI
- 업로드~피드 노출까지 평균 < 5분 (트랜스코딩 포함)
- Free → Creator 전환율 5% 이상
- 평균 시청 완료율 50% 이상 (피드 UX 품질)
- 광고 viewability(IAB MRC) 70% 이상
- ARR per active workspace $300 이상
