# 음성 입력 장보기 리스트 (VoiceCart)

## 개요
음성으로 "우유, 계란, 식빵" 한 번에 말하면 자동으로 리스트에 추가되는 빠른 장보기 앱.
가족과 실시간 공유 가능.

## 문제
- 마트에서 손이 더러워 폰 입력이 불편.
- 가족 구성원과 장보기 리스트 공유가 번거로움.
- 매번 새 리스트를 만들기 귀찮음 (단골 품목 반복).

## 솔루션
- 음성 인식으로 여러 항목 한 번에 추가.
- 자동 카테고리화 (채소, 유제품, 정육 등).
- 가족 그룹 실시간 공유.
- 자주 구매 품목 자동 추천.
- 마트 통로 순서대로 정렬.

## 타겟 사용자
- 주부, 부부, 자취생.
- 가족 단위로 장보는 사용자.
- 손이 자유롭지 않은 상황 (요리 중 등).

## 핵심 기능
1. 음성 입력 (한국어 STT).
2. 카테고리 자동 분류.
3. 가족 공유 (실시간 동기화).
4. 자주 구매 품목 즐겨찾기.
5. 마트 통로 순 정렬.
6. 체크리스트 (체크된 항목 흐리게).
