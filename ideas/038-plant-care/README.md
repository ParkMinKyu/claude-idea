# 식물 물주기 알림 (PlantPal)

## 개요
사용자가 키우는 식물을 등록하면 종류별 적정 물주기·일조량·온도를 기반으로 자동 알림을 보내는 반려식물 관리 앱.

## 문제
- 식물마다 물주기 주기가 달라 초보자가 자주 죽입니다.
- 인터넷 검색으로 매번 정보 찾는 것이 번거롭습니다.
- 여러 식물 관리 시 일정 헷갈림.

## 솔루션
- 200+ 식물 데이터베이스 (한국 기후 보정).
- 사진으로 식물 식별 (ML Kit + 외부 API).
- 식물별 맞춤 물주기/분갈이/비료 알림.
- 성장 일지(사진 타임라인).
- 위치 기반 날씨/일조량 보정.

## 타겟 사용자
- 식물 키우기 초보자.
- 여러 식물을 키우는 식집사.
- 인테리어 식물 관리자.

## 핵심 기능
1. 식물 등록 (이름, 사진, 종류 선택).
2. 물주기/분갈이/비료 일정 자동 생성.
3. 알림 + 캘린더 뷰.
4. 식물 식별 (사진 → 종 추천).
5. 성장 사진 일지.
6. 식물 도감(검색·즐겨찾기).

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩7,900: 무제한 식물 등록(무료 5개), 식물 식별 무제한.

### 구독
- 월 ₩1,900: 전문가 챗 상담 1회/월, 식물병 진단(사진), 클라우드 백업.

### 광고
- 무료 사용자에게 식물 도감 화면 배너 광고.

## 경쟁사
- Planta: 글로벌, 가격 비쌈.
- Picture This: 식별 중심, 관리 기능 약함.
- 가드닝(국내): UX 노후.

## 차별점
- 한국 기후/계절 데이터 반영.
- 한국 식물명/품종 데이터베이스 충실.
- 가벼운 앱, 한국어 푸시 카피.
- 식물 식별 + 관리 통합.

## KPI
- 평균 등록 식물 수 사용자당 3개 이상.
- 알림 응답률 50%+.
- 30일 리텐션 35%.
- 프리미엄 전환율 7%.
- 평점 4.6 이상.
