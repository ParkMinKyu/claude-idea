# 013 - 자연어 → SQL + 차트

## 개요
CSV 업로드 또는 DB 연결 후 "지난달 매출 상위 10개 제품은?" 같은 한국어 질문을 입력하면, Claude가 SQL을 생성하고 DuckDB로 실행해 결과 + 자동 차트까지 보여주는 데이터 분석 도구.

## 문제
- 비개발 직원이 데이터 보고서를 보려면 매번 데이터팀에 요청 → 며칠 대기
- Tableau/Looker는 학습 곡선 가파름 + 비쌈
- ChatGPT는 우리 DB 스키마를 모르고 부정확한 SQL 생성

## 솔루션
- CSV/Excel 업로드 또는 Postgres/MySQL 연결
- 스키마 자동 분석 → Claude 컨텍스트에 임베드
- 한국어 질문 → SQL 생성 → DuckDB 실행 → 결과 테이블 + 자동 차트 추천
- SQL 편집 가능 (사용자 검토)

## 타겟 사용자
- PM / 마케터 (데이터 자급)
- 영업 매니저 (CRM 데이터 조회)
- 데이터팀 (반복 질문 셀프 서비스화)
- 학생/연구자 (CSV 분석)

## 핵심 기능
1. CSV/DB 연결 + 스키마 자동 인식
2. 자연어 → SQL 생성
3. DuckDB로 안전한 쿼리 실행 (read-only)
4. 결과 + 자동 차트 (bar/line/pie)
5. (Pro) 대시보드 저장 + 공유, 정기 알림

## 리스크와 대응
- 쓰기 SQL 생성으로 데이터 파괴 → read-only 강제 + 키워드 차단 + 사용자 DB는 read-only 계정 권장
- 잘못된 SQL → 사용자 SQL 편집 + 결과 행 수 표시
- 대용량 쿼리 OOM → LIMIT 자동 추가 + 타임아웃
