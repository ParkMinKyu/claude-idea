# 056 - Cron Debugger (Cron 표현식 비주얼라이저)

## 개요
복잡한 cron 표현식을 사람이 읽기 쉬운 자연어 설명으로 변환하고, 다음 실행 시각을 시각적으로 보여주는 웹 기반 도구입니다. 개발자가 `0 */6 * * 1-5` 같은 표현식을 한눈에 이해하고, 캘린더 뷰로 다음 N개의 실행 시각을 확인할 수 있습니다.

## 문제
- Cron 표현식은 직관적이지 않아 실수가 잦음 (특히 `*/N`, day-of-week vs day-of-month)
- 프로덕션 배포 직전까지 잘못된 스케줄이 적용된 줄 모르는 경우 발생
- 타임존 변환을 머릿속으로 계산하기 어려움
- 팀원 간 cron 의도를 공유할 표준 도구가 부재

## 솔루션
- 실시간 cron 파싱 + 자연어 설명 ("매주 평일 6시간마다")
- 다음 10/30/100회 실행 시각 캘린더 시각화
- 다중 타임존 비교 뷰 (UTC / KST / PST)
- 공유 가능한 영구 링크 (`/c/{base64}`)
- 팀 워크스페이스 (Pro): cron job 라이브러리, 변경 이력, Slack 알림 통합

## 타겟
- 백엔드 / 데브옵스 엔지니어
- SRE / 플랫폼 팀
- 데이터 엔지니어 (Airflow, Argo Workflows)
- Kubernetes CronJob 관리자

## 핵심 기능
1. **표현식 파서**: 5/6/7 필드 cron, AWS / Quartz 확장 지원
2. **자연어 설명**: 한/영 다국어
3. **시각화**: 캘린더 그리드, 타임라인, 히트맵
4. **타임존 변환**: 동시 비교
5. **검증기**: 0회 실행, 과다 실행 경고
6. **공유**: URL 인코딩 영구 링크
7. **팀 라이브러리** (Pro): 저장/태그/검색
8. **CLI / API** (Pro): CI 검증 통합
