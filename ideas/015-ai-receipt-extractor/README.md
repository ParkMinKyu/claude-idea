# 015 - 영수증 OCR → 가계부 자동 입력

## 개요
영수증 사진을 찍어 업로드하면 Tesseract OCR로 텍스트를 추출하고, Claude가 가맹점/항목/금액/카테고리를 구조화해 가계부 앱(혹은 Notion/Google Sheets)에 자동 입력하는 도구.

## 문제
- 가계부 수기 입력은 귀찮아서 1주일 만에 포기
- 카드 명세서만으로는 "무엇을 샀는지" 파악 불가
- 사업자 경비 처리(연말정산, 부가세) 시 영수증 누락

## 솔루션
- 영수증 사진 1장 → Tesseract OCR (한국어 + 영문)
- Claude가 거친 OCR 결과를 구조화 (가맹점/날짜/항목/카테고리)
- Google Sheets/Notion/뱅크샐러드(API) 자동 전송
- 사업자용: 부가세/계정과목 자동 분류

## 타겟 사용자
- 가계부 챌린지 실패자 (대중)
- 1인 사업자/프리랜서 (경비 처리)
- 직장인 (법인카드 영수증 정리)
- 가족 공유 가계부 사용자

## 핵심 기능
1. 영수증 사진 업로드 (모바일 친화)
2. OCR + Claude 구조화 추출
3. 카테고리 자동 분류 (식비/교통/쇼핑 등)
4. Google Sheets/Notion 연동
5. (Pro) 부가세 자동 계산 + 월간 리포트

## 경쟁사
- 뱅크샐러드, 토스: 카드 명세서 자동, 영수증 X
- Expensify: 글로벌 경비 처리, 한국 미진입

- 네이버 가계부: 자동화 부족

## 차별점
- 한국어 영수증(편의점, 식당, 카드 영수증) 인식 정확도

- 1인 사업자용 부가세 자동 분류 (희소 기능)
- Notion 연동 (다른 가계부 앱 미지원)

- Sheets/Notion 연동 사용률
