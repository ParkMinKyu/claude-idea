# 020 · 노코드 폼 빌더

## 개요
드래그앤드롭으로 설문/리드 폼/주문 폼을 만들고 응답을 수집·분석하는 SaaS. Typeform보다 가볍고 한국어 친화적.

## 문제
- Typeform·Tally는 한국어 폰트·결제·세금계산서 발행 같은 한국 시장 요구를 만족하지 못한다.
- Google Forms는 디자인이 빈약하고 분기 로직이 약하다.
- 개발자가 폼을 직접 만들면 검증·스팸 방지·분석 대시보드까지 떠안게 된다.

## 솔루션
- dnd-kit 기반 빌더에 17종 필드(텍스트, 선택, 파일, 평점, 결제 등)
- 분기 로직(if A then go to B)과 변수 치환
- Toss·Stripe 결제 필드 내장
- 임베드·팝업·풀스크린 3가지 발행 모드

## 타겟 사용자
- 마케터, 운영팀(리드/이벤트 신청 폼)
- 강사·코치(수업 신청 + 결제)
- 인디 메이커(고객 인터뷰 신청)

## 핵심 기능
1. **드래그 빌더** — 필드 추가/정렬, 라이브 미리보기
2. **분기 로직** — 응답값 기반 페이지 이동
3. **결제 필드** — Toss Payments / Stripe 결제창 임베드
4. **응답 대시보드** — 필터, CSV 내보내기, Slack 알림
5. **테마/CSS 변수** — 브랜드 색상·폰트 일치

## 경쟁사
- Typeform, Tally, Jotform, Google Forms, Hubspot Forms

## 차별점
- Toss Payments 네이티브 통합
- 한국어 폰트/입력 패턴(주민번호 마스킹 등) 프리셋
- 무료 플랜에 분기 로직 허용 (Typeform은 유료)
- 결제 + 응답 데이터 단일 대시보드

## KPI
- 첫 폼 발행까지 평균 시간 < 4분
- 폼 평균 응답 완료율 65%+
- 결제 필드 도입 워크스페이스 비율 20%+
- 무료 → 유료 전환율 7%+
- 결제 GMV per workspace 월 $500+ (Pro 이상)
