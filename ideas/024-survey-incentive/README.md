# 024 · 토큰 보상 설문 플랫폼

## 개요
응답자에게 즉시 현금/기프티콘 보상을 지급하는 설문 SaaS. 리서치 회사가 결제 → 응답자가 응답 → 보상 자동 송금.

## 처음
- 일반 설문은 응답률이 5% 미만, 응답 품질이 낮다.
- 패널 리서치(Dynata 등)는 응답당 $10~30 비싸고 한국 패널 풀이 작다.
- 응답자에게 직접 보상을 주려면 정산·세무·송금 인프라가 필요하다.

## 솔루션
- 리서처: Stripe 결제로 보상 풀 충전 → 응답 1건당 X원 차감
- 응답자: 가입 후 설문 응답 → 카카오톡/계좌 송금 즉시 지급
- 사용자 검증(휴대폰 본인 인증)으로 다중 응답 방지
- 응답 품질 점수(소요 시간, 일관성)로 보상 자동 차등

## 타겟 사용자
- UX 리서처, 마케팅 리서치 팀
- 학술 연구자
- 스타트업 PMF 검증 단계

## 핵심 기능
1. **설문 빌더** — 객관식/주관식/NPS, 분기 로직
2. **보상 풀 + 자동 송금** — Stripe 입금 → 응답자 송금
3. **품질 점수** — 너무 빠른 응답·일관성 부족 자동 감점
4. **다중 응답 방지** — 휴대폰 본인 인증
5. **응답 대시보드** — 인구통계, 답변 분포, CSV 내보내기

## 수익 모델
- **거래 수수료 모델**: 응답자 보상 + 플랫폼 수수료 15%
- **구독 옵션**: $99/월에 수수료 10%, $299/월에 8% + 패널 풀 우선 노출
- 결제 풀 충전 최소 ₩100,000

## 경쟁사
- Prolific, Dynata, OpenSurvey(KR), Pollfish

## 차별점
- 응답자 즉시 송금(타사는 적립 후 출금)
- 카카오톡 기프티콘 송금 옵션
- 한국 패널 풀에 특화
- 본인인증 기반 1인 1응답 보장

## KPI
- 응답률(invite → submit) 35%+
- 응답 품질 점수 평균 80+
- 리서처 재구매율(3개월) 50%+
- 응답자 30일 잔존율 40%+
- 월 GMV per researcher ₩500,000+
