# 116 · README 배지 생성기

## 개요
shields.io 스타일의 flat 상태 배지를 SVG로 직접 렌더링하는 경량 도구입니다. 외부 API 호출
없이 라벨/메시지/색상만으로 픽셀 정렬된 배지를 생성하며, 코어는 의존성 0의 순수 함수라
CI·엣지·셀프호스팅 어디서나 동일한 SVG를 만듭니다.

## 문제
- shields.io는 편리하지만 외부 의존성·레이트 리밋·가용성 리스크가 있습니다.
- 사내/프라이빗 메트릭(커버리지, 빌드)을 외부 서비스에 노출하기 꺼려집니다.
- 커스텀 색상·라벨 규칙을 일관되게 적용하기 어렵습니다.

## 솔루션
- 텍스트 폭 추정 + flat 레이아웃으로 정렬된 SVG 배지 생성.
- 명명 색상/HEX 모두 지원, XML 이스케이프로 안전한 렌더링.
- 커버리지 임계값 자동 색상 등 도메인 헬퍼 제공.

## 타겟 사용자
- 오픈소스/사내 레포 관리자.
- 프라이빗 메트릭을 셀프호스팅하려는 DevEx 팀.
- 정적 사이트/문서에 배지를 임베드하는 개발자.

## 핵심 기능
1. SVG 배지 렌더러 — 라벨/메시지 2분할 flat 스타일, 접근성 aria-label.
   - shields.io 호환 레이아웃으로 README에 자연스럽게 어울림.
2. 색상 해석 — 명명 색상/HEX, 안전한 폴백.
3. 텍스트 폭 추정 — ASCII 메트릭으로 픽셀 정렬.
4. XML 이스케이프 — `<`,`&`,`"` 안전 처리로 인젝션 방지.
5. 도메인 헬퍼 — `coverageBadge()` 임계값 자동 색상.

## 사용 예시
```bash
# 빌드 상태 배지
node src/index.ts build passing brightgreen > build.svg

# 커버리지 배지(임계값 자동 색상)
node src/index.ts coverage 87 > coverage.svg
```
```ts
import { renderBadge } from './lib/badge';
renderBadge({ label: 'tests', message: '128 passed', color: 'green' });
```

## 도입 시나리오
- CI 빌드 후 배지 SVG를 아티팩트/리포지토리에 커밋.
- 프라이빗 메트릭(내부 커버리지)을 외부 노출 없이 렌더링.
- 정적 문서 사이트에 빌드 타임 배지 임베드.

## 수익 모델
- 오픈코어: 렌더러 + CLI는 MIT 오픈소스.
- SaaS Pro 가격 티어:
  - Free: CLI/라이브러리, 정적 배지.
  - Pro ($9/월): 동적 배지 엔드포인트(CI 웹훅 연동), 커스텀 테마.
  - Team ($39/월): 프라이빗 메트릭 수집, 조직 테마/브랜딩, 캐시 CDN.

## 경쟁사
- shields.io — 표준이나 외부 API 의존, 레이트 리밋.
- badgen — 유사하나 셀프호스팅/프라이빗 메트릭 약함.
- for-the-badge — 스타일 한정.
- custom badge GH actions — 워크플로 종속.

## 차별점
- 외부 의존성 0 — 빌드 타임/엣지에서 배지 생성으로 가용성 리스크 제거.
- 프라이빗 메트릭을 자체 인프라 안에서 렌더링.
- 코어가 순수 함수라 결정론적 출력, 테스트로 픽셀 안정성 보증.
- 도메인 헬퍼(커버리지 등)로 임계값 색상 자동화.

## KPI

- 커스텀 테마 적용 비율.
