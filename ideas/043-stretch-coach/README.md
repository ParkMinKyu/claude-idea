# 책상 스트레칭 알림 (DeskStretch)

## 개요
사무직 직장인을 위해 25~60분 간격으로 짧은 스트레칭(1-3분)을 가이드해주는 헬스케어 앱.
포모도로 식 알림 + 영상/이미지 가이드 + 진행 추적.

## 문제
- 장시간 앉아 일하면 거북목, 허리 통증, 손목 통증이 발생.
- 운동할 시간이 없는 직장인은 스트레칭마저 잊기 쉬움.
- 기존 영상 플랫폼은 매번 검색해야 함.

## 솔루션
- 사용자 지정 알림 간격 (30분 기본).
- 상황별 스트레칭 (목/어깨/허리/손목).
- 1~3분 짧은 영상 가이드.
- 알림 응답률 통계.
- 헬스커넥트 연동.

## 타겟 사용자
- 사무직 직장인, 개발자.
- 학생 (장시간 책상 학습).
- 거북목/허리통증 사용자.

## 핵심 기능
1. 시간 간격 알림 (사용자 설정).
2. 부위별 스트레칭 라이브러리 (20+).
3. 짧은 영상 가이드 (오프라인 저장).
4. 일일 스트레칭 기록 + 연속 일수.
5. 위젯에서 빠른 시작.
6. 회의 시간 자동 회피 (캘린더 연동).

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩7,900: 무제한 영상, 모든 부위, 광고 제거.

### 구독
- 월 ₩1,900: 새 영상 매주 추가, 개인 맞춤 프로그램, 클라우드 백업.

### 광고
- 무료 사용자에게 스트레칭 시작 전 보상형 광고 1회/일.

## 경쟁사
- StretchIt: 글로벌, 가격 비쌈.
- Daily Yoga: 일반 요가 중심.
- 자세요정: 한국, 좋으나 UX 노후.

## 차별점
- 사무실 친화 1~3분 초단시간.
- 캘린더 연동 (회의 회피).
- 한국어 가이드 + 사무직 특화.
- 가벼운 앱.

## KPI
- 알림 응답률 40%+.
- 일일 평균 스트레칭 5회.
- 30일 리텐션 30%.
- 프리미엄 전환율 5%.
- 평점 4.4 이상.
