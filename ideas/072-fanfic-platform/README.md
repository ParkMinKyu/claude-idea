# 072 · 팬픽션 구독 플랫폼

## 개요
한국어 팬픽션 작가가 마크다운으로 글을 쓰고 독자가 작가를 직접 후원·구독할 수 있는 플랫폼. 포스타입·노블피아·AO3의 한국형 대안으로, 강한 태그·트리거 워닝 시스템과 작가별 멤버십을 제공한다.

## 문제
- 포스타입은 일러스트/만화 중심이며 팬픽 정렬·태그 시스템이 약하다.
- AO3는 한국어 검색·태그 분류가 영어 작품에 비해 빈약하다.
- 노블피아·문피아는 상업 웹소설 중심이며 팬픽 게재가 제한적이다.
- 작가는 후원 채널이 없어 카카오뱅크 계좌 공개 등 비공식 방법으로 받는다.

## 솔루션
- 마크다운 + 자동 워드카운트 + 챕터별 발행
- 강한 태그 체계: 등장인물·관계(/), 장르, 분량, 완결/연재중, 19금 토글
- 트리거 워닝(폭력·자살·근친 등) 의무 표시, 독자가 차단 태그 설정
- 작가별 멤버십: 미공개 회차, 비하인드 노트, 코멘트 작가 답글

## 타겟 사용자
- 한국어 팬픽 작가 (특히 아이돌·게임·애니메이션 팬덤)
- 매주 새 팬픽을 찾는 헤비 리더 (10~30대 여성 비중↑)
- 18+ 작품을 안전하게 분리해서 읽고 싶은 성인 독자

## 핵심 기능
1. **마크다운 에디터** — 자동 저장 30초, 워드카운트, 챕터 분할
2. **태그·필터 시스템** — 인물/관계/장르 다중 선택, NOT 필터(차단)
3. **연령 확인 게이트** — 19금은 본인 인증 후 열람
4. **작가 멤버십** — 월 ₩4,900~ 자유 설정, 미공개·비하인드 잠금 해제
5. **코멘트 + 키스(좋아요)** — 챕터별 댓글, 추천 정렬, 작가 답글

## 수익 모델
| 채널 | 가격/수수료 |
|---|---|
| 독자 무료 | 광고 1개/세션 |
| 독자 Pro | ₩3,900/월 광고 제거 + 무제한 차단 태그 |
| 작가 멤버십 | 작가 자유 가격, 플랫폼 수수료 10% |
| 일회성 후원 | "커피 한 잔", 플랫폼 수수료 5% |
| 광고 | 비-성인 작품 페이지에만 노출 |

## 경쟁사
- 포스타입, 노블피아, 문피아, AO3, Wattpad, Tapas Korea

## 차별점
- 강제 트리거 워닝 + 차단 태그 (안전한 읽기 경험)
- 작가 멤버십 직결 (포스타입은 글쓰기에 후원이 분리)
- 한국 팬덤 특화 태그 사전 (그룹명·페어링 약어 자동 변환)
- 무료 작품도 작가 페이지에서 멤버십 유도

## KPI
- 가입 후 첫 작품 등록까지 평균 < 20분
- 작가당 평균 월간 키스(좋아요) 50+ (활성 기준)
- 작가 멤버십 활성화율 (Total Authors 대비) 8% 이상
- Reader Pro 전환율 4%
- 30일 잔존율 65%
- 평균 작품 평점 / 키스 비율 (퀄리티 시그널)

## 사용 시나리오
1. 아이돌 팬덤 작가가 본인 페이지에 무료 작품 + 멤버십 미공개 챕터 운영
2. 독자가 차단 태그(특정 페어링, 트리거)로 안전한 피드 유지
3. 행사·동인지 시즌에 일회성 후원 캠페인

## MVP 범위
- v0.1: 마크다운 에디터 + 작품 게재 + 태그 검색
- v0.2: 키스/댓글 + 차단 태그 필터
- v0.3: 작가 멤버십 + 후원 결제
- v1.0: 본인 인증 19금 + 트렌딩 + 작가 분석

## 리스크 / 가정
- 명예훼손/저작권 (실존 인물 팬픽): 약관 + 신고 처리 강화 필수
- 미성년자 보호: 본인 인증 게이트 + 부모 신고 대응
- 모더레이션 비용: 자동 룰베이스 + 휴먼 검수 혼합

## 운영 / 컴플라이언스
- 한국 청소년 보호법 + 통신심의위 가이드 준수
- 신고 → 7일 내 처리, 반복 위반자 차단
- 작가 정산 사업자 등록 가이드 (월 ₩100,000+)
