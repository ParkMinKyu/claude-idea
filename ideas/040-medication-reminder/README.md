# 약 복용 알림 + 재고 (PillMate)

## 개요
약 복용 시간 알림과 함께 약 재고 관리, 처방전 사진 보관, 약물 상호작용 경고를 제공하는
시니어·만성질환자 친화적 복약 관리 앱.

## 문제
- 만성질환자는 여러 약을 시간 맞춰 먹기 어려움.
- 약을 다 먹어서 다시 처방받아야 하는데 모르고 지나치는 경우.
- 약물 상호작용으로 인한 부작용 위험.

## 솔루션
- 약별 복용 시간/요일/식전식후 설정.
- 잔여량 관리, 떨어지기 전 알림.
- 처방전 사진 보관.
- 약물 상호작용 경고 (식약처 데이터 기반).
- 보호자 알림 (자녀가 부모님 복약 확인).

## 타겟 사용자
- 만성질환자 (당뇨, 고혈압).
- 시니어 사용자.
- 만성질환 부모를 둔 자녀 (보호자 모드).

## 핵심 기능
1. 약 등록 (이름, 용량, 시간, 식전식후).
2. 시간별 알림.
3. 잔여량 추적 + 부족 알림.
4. 처방전 사진 보관.
5. 약물 상호작용 경고.
6. 보호자 알림 공유.

## 수익 모델
### 앱 내 결제
- 프리미엄 ₩9,900: 무제한 약 등록(무료 5개), 광고 제거.

### 구독
- 월 ₩3,900: 보호자 공유, 클라우드 백업, 처방전 OCR.

### 광고
- 무료 사용자에게 약 등록 화면 네이티브 광고 (건강기능식품 카테고리).

## 경쟁사
- 굿닥 / 똑닥: 의료 예약 중심.
- Medisafe: 글로벌, 한국 약품 DB 부족.
- 약알리미: UX 노후.

## 차별점
- 식약처 약품 DB 연동.
- 한국 시니어 친화 UI (큰 글씨, 단순 화면).
- 보호자 모드.
- 약물 상호작용 경고.

## KPI
- 알림 응답률 80%+.
- 30일 리텐션 60% (만성질환 특성).
- 평균 등록 약 수 3개 이상.
- 프리미엄 전환율 5%.
- 평점 4.6 이상.
